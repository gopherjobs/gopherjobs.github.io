Product Description KernelCare provides automated live patching for Linux kernels without requiring reboots. Our Extended Lifecycle Support products keep end-of-life Linux distributions secure by backporting important security and bug fixes to older software versions used by enterprise customers.

Role and Team We are looking for a Kernel Developer to join the KernelCare ELS team. The team investigates upstream Linux kernel changes, backports fixes to supported enterprise kernels, builds distribution packages, and validates that patches are safe and reproducible.

The role is centered on practical patching and building work. You will also use automation and agentic development tools to accelerate investigation while retaining engineering ownership of every result.

Responsibilities

  • Investigate upstream security and bug fixes and identify their dependencies
  • Backport Linux kernel patches to older RPM- and Debian-based distributions
  • Resolve conflicts caused by differences between upstream and target kernel versions
  • Build and rebuild kernel source and binary packages in reproducible environments
  • Validate patched kernels through focused tests, build checks, and regression analysis
  • Improve patch preparation, build, and validation workflows with Python, Go, or Shell
  • Use agentic development tools responsibly and verify generated code, analysis, and documentation
  • Document technical decisions and participate in code review with the kernel team

Requirements Must Have

  • Strong C programming and Linux debugging skills
  • Practical Linux kernel development, patching, or backporting experience
  • Confident use of Git, GNU build tools, and standard Linux development utilities
  • Experience building Linux kernels or distribution packages
  • Automation experience with Python, Go, Shell, or a similar language
  • Some experience with agentic or AI-assisted development and a clear approach to validating generated output
  • English at an intermediate level or higher, both written and spoken
  • Strong ownership, careful technical judgment, and readiness to explain trade-offs

Nice to Have

  • Experience with RPM/SRPM or Debian kernel packaging
  • Security patching, CVE analysis, or extended lifecycle maintenance experience
  • Familiarity with Docker, QEMU, Jenkins, or other CI systems
  • Experience designing kernel tests or investigating core dumps and regressions
