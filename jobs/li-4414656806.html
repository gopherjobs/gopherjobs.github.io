Description

Logitech is the Sweet Spot for people who want their actions to have a positive global impact while having the flexibility to do it in their own way.

我们正在寻找一位具有架构师视野的创客（Super Builder），成为连接大模型智能与实体硬件交互的枢纽，主导构建具备自主决策能力的 AI Agent 系统，推动下一代人机交互（HCI）的落地。 岗位职责

  • 业务需求转化为交互能力： 深入洞察用户在桌面端与硬件端的交互痛点，将模糊的使用场景与用户意图，抽象为可执行的 Agent 决策逻辑与工具调用链路，确保技术方案能有效解决实际交互难题。
  • 下一代交互原型开发： 构建“硬件端 -> 实时语音 -> 系统自动化”的全新人机交互原型，推动用户体验从物理操作向自然语言交互平滑过渡。
  • 工业级任务编排（Orchestration）： 针对复杂、多步骤的系统级及硬件控制任务，设计高鲁棒性的有状态多智能体协同系统（Stateful Multi-Agent System），解决长链路任务中的分支、重试与无限循环死锁问题。
  • 闭环长期记忆系统搭建： 负责设计与落地 Agent 长期记忆架构，攻克“记忆漂移”与上下文污染难点，实现情节记忆与程序记忆的动态融合与智能衰减。
  • 统一软硬件上下文协议： 利用 Model Context Protocol (MCP) 及 Agent Skills 等最新标准与框架，打通硬件状态、本地应用上下文与云端大模型之间的无缝连接。
  • 安全控制与确认门禁： 在任务编排中设计严格的确定性安全边界，确保涉及隐私及关键系统操作时的回滚机制与用户人工确认机制（Human-in-the-Loop）。

任职要求 核心能力要求（Core Qualifications）

  • 扎实的软件工程基础： 5 年以上软件开发经验，精通 Python，并对 C/C++、Go 或 Rust 有实际工程经验（用于处理底层硬件通信与高性能音频流）。
  • 高阶 Agent 系统构建： 具备 1 年以上生产环境 Agent 系统设计经验，深刻理解并解决过 Agent 在复杂任务编排中的状态丢失、非确定性行为控制问题。
  • 深入理解 Agent 核心推理范式： 掌握 ReAct、Plan-and-Solve、Reflection 等主流推理架构，具备针对复杂任务场景设计多轮推理与自我修正链路的实战经验。
  • Agent Skills 与任务编排： 具备 Agent Skills 开发与优化经验，能设计高质量工具集以提升执行效率；具备使用 LangGraph、Temporal、CrewAI 等主流工具（或类似工具）的实际工程经验，能灵活设计有状态的、异步事件驱动的复杂图结构（DAG/Cyclic Graph）。
  • 多模态与语音工程： 熟悉实时音频流处理（WebSockets/WebRTC）、端到端语音模型、STT/TTS 技术的工程化缝合，有处理高并发、低延迟音频交互经验。
  • 记忆与上下文工程： 熟悉现代 Agent 长期记忆架构（情节与程序记忆的动态融合）及记忆工程，能熟练运用向量/图数据库进行数据持久化；熟练掌握 MCP 协议及上下文工程（如 Token 压缩）。
  • 系统级交互与认知： 具备深厚的系统级交互认知，熟悉操作系统底层接口（Windows/macOS API、RPA逻辑）及硬件通信协议，能够打通硬件、本地应用与云端大模型。
  • 软实力与极客精神
  • 敏捷迭代与安全边界： 具备极强的原型开发与敏捷迭代能力，同时对系统安全边界保持敬畏；在追求创新效率的同时，确保关键系统交互的鲁棒性与稳定性。
  • 卓越的跨界协作： 能够将前沿的 AI 算法需求高效转化为硬件工程师可理解的工程指标，在 AI 与硬件系统之间建立通畅的沟通桥梁。
  • 工程闭环与责任意识： 具备极强的交付责任心，能够通过系统化的测试、监控与验证手段，确保 Agent 在真实物理交互场景下的表现可度量、可复盘，对交付效果负责。
  • 主动探索与自驱力： 面对前沿领域模糊的课题，能够通过主动钻研技术前沿并快速构建验证方案（PoC），表现出极高的技术好奇心与解决复杂问题的韧性。
