Overview Zema Global is embarking on a transformational journey to modernize our data infrastructure through the Data Surface Programme with a strategic vision to build a cloud-native AWS Lakehouse architecture. Zema Global’s Data Surface will enable:

  • Unified data governance with full lineage, metadata visibility, and automated quality checks
  • Scalable, elastic architecture with decoupled compute and storage optimized for AI/ML workloads
  • Enhanced security, compliance, and multi-tenant support with RBAC and encryption
  • Real-time and batch data processing supporting both human-in-the-loop and fully automated AI workflows
  • Self-service analytics and ML capabilities through open data formats and extensible APIs
  • AI and machine learning on our own data through AWS platforms such as Amazon Bedrock and SageMaker, made possible by storing data in open source Apache Iceberg format

We are building a UK-based team to own the technical delivery of this programme. You will collaborate with our global engineering teams across the UK, US, Canada, and India, working with cutting-edge cloud-native technologies to shape the future of commodities data infrastructure as part of an ambitious, forward-thinking organization.

Our team operates using an innovative AI-driven development methodology, leveraging Claude Code to accelerate development cycles and enhance code quality. Working in weekly sprints, you will experience a modern, efficient approach to software engineering that combines the best of agile practices with AI-assisted development tools.

Position Overview We are looking for a Senior Software Engineer to be a key technical contributor to our Data Surface programme. You will implement critical components of our AWS Lakehouse infrastructure, working with modern cloud-native technologies including Apache Iceberg, Apache Spark, and AWS services to build scalable, reliable data pipelines.

As a Senior Engineer, you will have significant influence over technical decisions, mentor junior team members, collaborate with global colleagues across the UK, US, Canada, and India, and help establish engineering excellence for a greenfield data platform. Working in weekly sprints with Claude Code and AI-assisted development tools, you will contribute to the foundation for Zema Global’s next generation of products and services.

What You'll Be Doing

  • Design and implement data ingestion pipelines from DynamoDB and Oracle into Apache Iceberg tables on S3 using no-code capabilities. Use Claude Code to generate specifications and design documents, and review specifications produced by other team members to ensure AI-generated code accounts for all operational nuances of the technology
  • Develop Bronze-Silver-Gold data transformation layers using Apache Spark and AWS Glue
  • Build streaming data ingestion from Kinesis/Kafka into the Lakehouse with near-real-time processing
  • Implement data quality frameworks, schema validation, and automated monitoring systems
  • Create RESTful APIs and data access layers for consuming lakehouse data in downstream applications
  • Optimize query performance using Iceberg features (partitioning, clustering, compaction)
  • Build the data access and serving layers that allow AWS AI/ML services, including Amazon Bedrock and SageMaker, to consume Iceberg data directly
  • Integrate data governance capabilities including metadata management, lineage tracking, and access control
  • Collaborate on architectural decisions and contribute to technical design documentation
  • Mentor mid-level and junior engineers through code reviews and technical guidance
  • Implement infrastructure as code using Terraform, CloudFormation, or similar tools
  • Design and deploy containerized applications and data processing workloads on EKS
