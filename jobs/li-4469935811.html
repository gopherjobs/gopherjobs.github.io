Descripción del empleo

Development es la disciplina más grande de Endava. Nuestros desarrolladores diseñan, construyen y ponen en producción productos de software utilizando múltiples lenguajes de programación, frameworks y librerías. Trabajando en estrecha colaboración con equipos multidisciplinarios, aportan adaptabilidad, capacidad para resolver problemas y un fuerte enfoque en el cliente.

Responsabilidades:

  • Desarrollar componentes de software siguiendo estándares de la industria, herramientas y buenas prácticas.
  • Participar en el refinamiento del backlog, estimaciones, implementación y otras actividades de desarrollo.
  • Colaborar con distintos stakeholders para comprender los requerimientos, la arquitectura y las prioridades.
  • Escalar riesgos, problemas o inquietudes relacionados con las tareas de desarrollo.
  • Revisar el trabajo realizado por otros miembros del equipo de desarrollo.
  • Aprender y aplicar nuevas tecnologías, prácticas y herramientas según las necesidades del proyecto.
  • Participar en comunidades técnicas y eventos internos.

Requisitos

  • Más de 3 años de experiencia en desarrollo de software.
  • Sólidos conocimientos de C# y desarrollo backend utilizando .NET y ASP.NET Core.
  • Experiencia en el diseño, desarrollo y mantenimiento de APIs RESTful.
  • Conocimiento de principios de diseño orientado a objetos, SOLID, patrones de diseño y prácticas de código limpio.
  • Experiencia trabajando con Entity Framework Core y acceso a datos.
  • Experiencia práctica con bases de datos relacionales, preferentemente Microsoft SQL Server, incluyendo desarrollo y optimización de consultas SQL.
  • Experiencia con testing automatizado, incluyendo unit tests e integration tests, utilizando herramientas como xUnit, NUnit o similares.
  • Experiencia en desarrollo frontend utilizando React y JavaScript/TypeScript.
  • Conocimiento de tecnologías de contenerización, incluyendo Docker y Docker Compose.
  • Experiencia trabajando con sistemas de control de versiones como Git.
  • Familiaridad con prácticas y herramientas de CI/CD, preferentemente Azure DevOps y Azure Pipelines.
  • Conocimientos básicos de servicios cloud, preferentemente Microsoft Azure.
  • Conocimientos básicos sobre despliegues en Kubernetes y herramientas como Helm o Kustomize.
  • Conocimientos de prácticas de observabilidad, logging y monitoreo utilizando herramientas como Application Insights, OpenTelemetry, New Relic o similares.
  • Familiaridad con protocolos y estándares como HTTP, REST y JSON.
  • Experiencia utilizando herramientas de desarrollo asistido por IA, como GitHub Copilot, Codex, Claude Code o similares, como parte del ciclo de desarrollo de software.
  • Familiaridad con el uso de agentes de IA para tareas de desarrollo, incluyendo generación y modificación de código, análisis, testing, debugging y documentación.
  • Conocimiento de buenas prácticas para trabajar con IA generativa, incluyendo la definición efectiva de instrucciones y contexto, revisión y validación de resultados, y uso responsable de estas herramientas.
  • Conocimientos básicos de metodologías ágiles como Scrum o Kanban.
  • Sólidas habilidades para la resolución de problemas y el pensamiento analítico.
  • Excelentes habilidades de comunicación y trabajo en equipo.
