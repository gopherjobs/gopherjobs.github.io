Description

Job Title: Lambda - API Engineer

Job Type: 3 month Contract + Extension

Job Mode: Remote

Job Summary

The Lambda / API Engineer designs, builds, and supports secure APIs and serverless services that expose platform capabilities. The role turns business and integration needs into reliable, versioned, deployable, and observable solutions using AWS cloud services.

Key Responsibilities

  • Design and document REST APIs using clear, maintainable OpenAPI specifications.
  • Build and maintain serverless services using AWS Lambda with Node.js or Python.
  • Configure and manage APIs through Amazon API Gateway and the required exposure model.
  • Implement API security using OAuth 2.0, JSON Web Tokens, and approved access controls.
  • Plan API versioning and compatibility to support safe changes and reliable integrations.
  • Automate cloud deployments using Infrastructure as Code and delivery pipelines.
  • Set up monitoring, logging, and alerting to keep APIs observable and supportable.
  • Work with architecture, automation, quality, and delivery teams to release production-ready services.

Required Skills & Qualifications

  • Proven experience designing REST APIs and authoring OpenAPI specifications.
  • Hands-on experience developing AWS Lambda functions in Node.js or Python.
  • Experience with Amazon API Gateway and cloud-native API delivery.
  • Working knowledge of OAuth 2.0, JSON Web Tokens, and API security practices.
  • Experience with API versioning, compatibility management, testing, and troubleshooting.
  • Experience using Infrastructure as Code and monitoring tools for deployed services.
  • Strong communication, collaboration, and problem-solving skills.
  • Bachelor’s degree in Computer Science, Information Technology, Engineering, or equivalent practical experience.

Preferred Skills

  • Experience deploying web assets through Amazon S3 and CloudFront.
  • Experience with enterprise integration or shared API exposure platforms.
  • Familiarity with compliance, cloud security, or API governance requirements.
  • Relevant AWS cloud certification.

Other Notes

  • Full-time role requiring high proficiency in API and platform engineering.
  • Primary focus: API and platform services.
  • should be prepared to demonstrate a real OpenAPI contract, explain their versioning approach, and describe an end-to-end cloud deployment.
