LLM Engineer (Tools) at BairesDev

As an LLM Engineer (Tools), you will design and implement Model Context Protocol (MCP) servers to extend the capabilities of large language models. You will act as a link between generative AI models and external systems, enabling agents to interact seamlessly with APIs and data sources through standardized interfaces.

What You'll Do

  • Design, develop, and maintain production-grade MCP servers to provide LLMs with secure access to external tools and context.
  • Implement and optimize tool-calling logic and function schemas using Python or TypeScript.
  • Build robust API integrations that allow AI models to perform complex, multi-step actions in real-world environments.
  • Leverage Anthropic SDKs to develop agentic workflows and standardized communication protocols.
  • Define tool discovery mechanisms and ensure reliable, context-aware interactions between models and their environment.
  • Collaborate with engineering teams to integrate external data sources and improve the performance of tool-driven responses.

What We Are Looking For

  • 4+ years of experience in Software Engineering with a focus on AI or LLM application development.
  • Proven expertise in designing and implementing MCP servers and tool calling architectures.
  • Fluency in Python or TypeScript for building robust backend services and API integrations.
  • Strong proficiency with the Anthropic SDK and connecting models to external data sources.
  • Solid understanding of JSON schema design for function signatures and validation.
  • Advanced proficiency in English.
