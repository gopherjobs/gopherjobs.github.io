Job Description We are seeking a Junior Software Developer who is passionate about technology and eager to learn. This entry-level position is designed for a recent graduate with foundational knowledge in software development principles and a strong desire to start their professional career.

Key Responsibilities

  • Application Development: Write clean, efficient, well-documented, and scalable application in windows environment [e.g., Python, Java, JavaScript].
  • Feature Implementation: Assist in the development and implementation of new features, modules, and services across our platform.
  • Testing and Debugging: Participate in unit, integration, and system testing. Identify and resolve software defects and bugs.
  • Collaboration: Work within an Agile/Scrum framework, participating in daily stand-ups, sprint planning, and retrospectives.
  • Code Review: Participate in code reviews to maintain code quality and share knowledge.
  • Documentation: Assist in creating and maintaining technical documentation, design specifications, and user guides.
  • Learning and Growth: Proactively seek out new technologies, tools, and methodologies to improve skills and processes.

Basic Requirements

  • Education: Bachelor's degree in Computer Science, Software Engineering, or a related technical field completed within the last 12-18 months. Fresh Graduates are welcome to apply!
  • Programming Skills: Foundational knowledge and experience in at least one modern programming language (e.g., Java, Python, C#, JavaScript/TypeScript).
  • Core Concepts: Solid understanding of Object-Oriented Programming (OOP), data structures, algorithms, and software development lifecycle principles.
  • Problem-Solving: Strong analytical and problem-solving skills with attention to detail.
  • Communication: Excellent verbal and written communication skills and a desire to work in a team-based environment.
  • Tools: Familiarity with version control systems, particularly Git.
  • This role required travelling to Asia,Middle East and Africa regions
  • Knowledge on AI and Big Data

(Bonus) Qualifications

  • Experience with web development frameworks (e.g., React, Angular, Spring Boot, Django).
  • Knowledge of database technologies (e.g., SQL, PostgreSQL, MongoDB).
  • Familiarity with cloud platforms (e.g., AWS, Azure, GCP) or containerization tools (e.g., Docker, Kubernetes).
