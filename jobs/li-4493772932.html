About the Role

We are seeking experienced Software Engineers and Developers to complete, test, and document realistic software engineering tasks. In this flexible remote engagement, your practical coding, debugging, and Git workflows will directly contribute to training next-generation AI coding models on how engineers solve real-world problems.

Work completely on your own schedule, ideal for full-time engineers, freelance developers, and contractors looking for flexible, paid side projects with zero meetings.

What You’ll Do

Implement a self-contained feature or diagnose and fix a bug within a sample codebase.

Write or update unit/integration tests and debug any failing test cases.

Commit changes cleanly and open a well-documented Pull Request (PR) or Merge Request (MR) explaining your approach.

What We’re Looking For

Professional software development experience (any modern stack—e.g., Python, JavaScript/TypeScript, Java, C#, Go, Ruby, etc.).

Strong proficiency with Git workflows (branching, commits, PRs/MRs) and modern IDEs (such as VS Code, JetBrains IDEs, or Cursor).

Active access to VS Code and a GitHub or GitLab account (personal or sandbox accounts are completely fine).

Ability to read unfamiliar codebases, write clean tests, and explain technical trade-offs clearly.

Access to a Mac or Windows computer.

Must reside in and be authorized to work in the United States or Canada.

Why Apply?

100% Asynchronous & Flexible: Pick up and submit tasks entirely around your schedule.

No Standups, Sprints, or Code-Review Politics: Focus purely on clean code and problem-solving.
