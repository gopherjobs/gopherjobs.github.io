Full Stack Engineer, Python / React (DRWN)

Job title - Full Stack Engineer (Python / React)

Client Location - Amsterdam, Netherlands

Remote work offering - 100% (remote within Europe, CET ±2 hours; optional occasional office visits for Netherlands-based candidates)

Client Industry - Employee Benefits / HR Tech

Contract Length - 10 months (extendable)

Contract type - Freelance

Project focus

You'll join an established product engineering team working on a live employee benefits platform, splitting your time roughly evenly between Python backend and React frontend. The work centres on the self-service customer portal and internal tools: improving existing features, shipping new ones end to end, building REST APIs and partner integrations, and keeping the platform fast and reliable. You'll work directly with non-technical colleagues across marketing, customer success and finance, so clear communication and the ability to run independently are key.

Key skills and Experience required

  • 5+ years of commercial Python development with FastAPI, Django or Flask
  • 3+ years of frontend development in React (or Next.js) with TypeScript/JavaScript, HTML5 and CSS3
  • Proven delivery of full-stack features end to end, with a genuine balance across frontend and backend
  • Strong REST API design and third-party API integration experience
  • Relational database design and query optimisation, ideally PostgreSQL
  • Docker and containerised environments
  • CI/CD pipelines (GitHub Actions, GitLab CI or CircleCI)
  • AWS or a comparable cloud platform
  • Solid testing practice, including TDD
  • Fluent spoken and written English
  • Based in Europe within CET ±2 hours, set up to work as a freelancer and available to start ASAP
  • Dutch language skills are a bonus
