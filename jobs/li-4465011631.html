🤖 The Hopper crew

🎯 Mission :

  • Hopper is Alan's internal agentic AI platform and every Alaner's AI companion: one unified productivity tool for coding, data, automation, research, and everyday work.
  • It is a platform with a product on top. The product is the first and most demanding user of reusable components for agent orchestration, isolated execution, skills, connectors, permissions, audit, and evaluations.

It started as a coding agent. Watch how we built its first version and enabled anyone at Alan to ship code. Coding remains its most mature use case and the foundation we are expanding from.

🔭 Scope:

  • Product experience - durable AI sessions available from the web, Slack, Linear, and GitHub for coding, data analysis, automation, and general work
  • Agent runtime and orchestration - control plane, harness, model routing, long-running execution, recovery, and isolated sandboxes
  • Secure connectors - an MCP Gateway that manages identity, credentials, permissions, confirmations, sensitivity, and audit
  • Skills, automations, and artifacts - reusable workflows, scheduled or event-driven work, dashboards, and hosted tools
  • Trust and review - evaluations and product experiences that expose tests, screenshots, previews, queries, sources, and tool actions

👀 Focus for 2026: Coding proved that Alaners want to delegate meaningful work to agents. Our 2026 focus is to make it the AI companion every Alaner can rely on: faster and more durable sessions, safe access to company tools and data, HDS-compatible infrastructure for sensitive workloads, stronger evaluations, and results people can inspect before acting on them.

👀 Focus for 2026: In 2026, we're moving from "AI tools you monitor" to "AI agents you trust." That means scaling Hopper — Alan's own background coding agent — alongside the infrastructure that makes it reliable: managed agent pools, sandboxed environments, autonomous testing, and CI auto-fix. Engineers will routinely offload tasks to agents. Non-engineers will open pull requests after having easily tested their changes. Agents will validate their own work before it ships.
