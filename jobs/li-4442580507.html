Role Overview

We are looking for a Cocos2d-x Software Engineer to join our team!

At Tripledot, we work collaboratively in a productive, Agile team environment. You will be working primarily with the Cocos2d-x framework , collaborating with our product and design team to maintain the health of our legacy games, add new features, build tools, and ensure high performance on both iOS and Android. Please note: This role focuses on our legacy C++ codebases using Cocos2d-x rather than modern Cocos Creator.

  • Implement and update gameplay features using the Cocos2d-x (C++) framework.
  • Support live operations and maintain existing titles within our portfolio.
  • Optimize code and memory footprint for high performance on mobile platforms.
  • Write maintainable, clean code while adapting to established legacy architectures.
  • Review code and write unit tests to ensure stability.

Required Skills, Knowledge, And Expertise

  • 1–2 years of hands-on experience working with the Cocos2d-x framework using C++ (Experience with Cocos Creator is not applicable for this role).
  • Strong proficiency in C++ and memory management.
  • Experience working with and extending existing legacy codebases.
  • A "Can Do" mentality that drives improvement and helps meet project deadlines.
  • Strong fundamentals in OOP, basic design patterns, and code architecture.
  • Experience or strong interest in mobile gaming and liveops systems.
  • Familiarity with debugging, profiling, and memory optimization tools specific to C++ and mobile.
  • Solid understanding of Git or other source control systems.
  • Experience with Unity and C# is a strong plus (and highly valued as we manage various codebases).
  • Excellent English skills, both written and verbal.
