Description

Company Description : Seceon Inc. is a next-generation cybersecurity company delivering an AI-powered platform that helps enterprises, Managed Service Providers (MSPs), and Managed Security Service Providers (MSSPs) detect, respond to, and remediate cyber threats in real time.

Its unified cybersecurity platform brings multiple security capabilities together in a single solution, including SIEM, SOAR, UEBA, EDR, NDR, Threat Intelligence, Vulnerability Management, and Compliance. By reducing dependence on dozens of disconnected security tools, Seceon enables organizations to simplify security operations, improve visibility, and accelerate threat response.

Designed for scale, the platform can process more than 10 million events per second and supports multi-tenant environments through a centralized dashboard. This enables security teams and service providers to monitor multiple environments, identify threats, investigate incidents, and take action more efficiently.

Seceon also helps organizations strengthen compliance and security governance across frameworks and regulations such as NIST, ISO, HIPAA, PCI-DSS, CMMC, and NIS2. Its AI-driven approach can help organizations reduce cybersecurity costs by up to 60 percent while improving operational efficiency.

By correlating security logs, network flows, endpoint activity, and identity data, Seceon provides comprehensive situational awareness and actionable threat intelligence. This unified approach enables organizations to move beyond fragmented security monitoring and build a more proactive, scalable, and intelligent cybersecurity strategy.

Role Description: Seceon Inc. is hiring 25 Software Engineers for a full-time, remote opportunity. The ideal candidates will contribute to the design, development, testing, and maintenance of backend services and core platform features that power real-time threat detection, security analytics, and automated response.

In this role, Software Engineers will develop clean, efficient, scalable, and secure code , implement object-oriented designs, build and integrate data pipelines and APIs, and work closely with cross-functional teams, including product management and security operations.

Key responsibilities include participating in code reviews, optimizing application and platform performance, troubleshooting complex technical issues, and improving system reliability across high-throughput, multi-tenant environments. Engineers will also contribute to technical documentation and help continuously enhance the platform based on customer feedback, evolving cybersecurity threats, and emerging industry requirements.

This is an opportunity to work on a next-generation AI-powered cybersecurity platform and contribute to technologies that help organizations detect, investigate, respond to, and remediate cyber threats in real time.
