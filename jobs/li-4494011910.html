Description

Description Our client is a global leader in the automotive industry, headquartered in Sweden and renowned for its commitment to safety, sustainability, and modern mobility solutions. You will be joining their dynamic technology hub in Krakow, focused on developing cutting-edge software and next-generation vehicle infotainment systems.

The primary focus of this role is software development and automation engineering centered around Python. You will lead efforts to modernize existing tools, optimize software architectures, and align CI solutions across different generations of Infotainment products to simplify maintenance and ensure continuous code quality. The project also includes supporting system migrations (Azure to GCP) and maintaining pipeline infrastructure.

Requirements Main skill set:

  • Python (strong) and Bash scripting
  • Linux (advanced: troubleshooting, performance, networking basics)
  • Remote build infrastructure – deploying, configuring and operating
  • Buildbarn / Remote Build Execution (Bazel REAPI), including caching and scaling
  • CI/CD – Jenkins; GitOps with ArgoCD
  • Git and Gerrit
  • Kubernetes and Docker; Helm
  • Cloud computing – GCP preferred, Azure also valued
  • Infrastructure as Code – Terraform
  • Monitoring and observability – Prometheus, Grafana
  • Technical engineering degree (software or systems engineering) or equivalent experience
  • Strong communication, problem-solving and planning skills; ownership and ability to mentor others

Would be a plus:

  • Config Connector (KCC) – strongly preferred
  • Ansible
  • Crossplane
  • Airflow
  • Databases – AlloyDB / PostgreSQL, MongoDB

Job responsibilities

Job Responsibilities

  • Develop, test, and maintain internal automation frameworks, scripts, and software tools primarily written in Python.
  • Collaborate with development and infrastructure teams to integrate cloud services (GCP/Azure) and containerized applications into CI/CD workflows.
  • Monitor and analyze CI pipeline performance, implementing improvements to eliminate bottlenecks and enhance fault tolerance.
  • Design, implement, and maintain robust Jenkins pipelines, optimizing build, test, and deployment stages for faster and more dependable release cycles.
  • Spearhead code modernization and system optimization initiatives to streamline performance, improve maintainability, and support future scalability.
  • Systematically elevate code quality and infrastructure efficiency by introducing automation, standardizing configurations, and applying best software engineering practices across infrastructure and codebases.
