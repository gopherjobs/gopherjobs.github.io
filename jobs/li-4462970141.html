Full-stack Python AI Engineer at BairesDev

In this role, you'll own features end to end in an enterprise AI assistant serving thousands of employees, spanning agent and skill integrations, RAG pipelines, the API services behind them, and the interface built on top. The work leans backend, but you'll be in the frontend regularly, validating agent behavior against evaluation sets rather than spot checks. This is your opportunity to work across the full stack on a genuinely production-grade AI system, with room to grow from Senior through Principal scope depending on what you bring.

What You'll Do:

- Own features end to end, including agent and skill integrations, RAG pipelines, and supporting API services.

- Build and maintain frontend interfaces within an established design system.

- Validate agent behavior against evaluation sets rather than relying on spot checks.

- Balance work across the stack, with a backend lean of roughly 70/30.

What we are looking for:

- 5+ years of experience with Python, 8+ years for lead-level scope.

- Experience with LLM integration and RAG pipelines in production, using LangChain, LangGraph, or LlamaIndex.

- Working proficiency with React and TypeScript.

- Experience with AWS.

- Availability to work PST hours.

- Advanced proficiency in English.

Nice to have:

- Experience with LLM evaluation, including LangSmith, LLM-as-judge, offline evals, or golden datasets.

- Experience with Next.js.

- Experience with vector search and embedding strategy.

- Experience with containers and microservices.

- Prior experience leading a pod or owning a component end to end.
