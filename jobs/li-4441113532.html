Description

Job Description JOB MISSION: As a software developer, you will participate in the development of new projects, as well as create new features to improve and maintain existing software applications, all on Linux platforms. On these platforms, you will develop complete applications dedicated to the management of electrical power devices, including adding a web service that allows users to remotely access and control the electrical device via a web browser. You will always be responsible for protecting the technological infrastructure and ensuring the security of our clients' data.

Job Responsibilities

  • Use the official UTI-SW code development, version control, and code documentation tools.
  • Use collaborative work tools in accordance with the QoS plan
  • Execute SW development processes in accordance with QoS .
  • Follow the SW working methodology, as defined in QoS.
  • Responsibility for the quality of the software they develop
  • Responsibility for meeting development deadlines agreed upon in the Sprint Planning .
  • Responsibility for reviewing and approving code merges in GitLab, and compliance with code versioning rules, collaborative work in GitLab and ticket management in Redmine, in accordance with QoS.

Usual/Daily JOB FUNCTIONS :

  • Maintenance and improvement of existing applications
  • Backend software development
  • User interface development
  • Application deployment on Linux platforms
  • Implementation and maintenance of security measures, including firewalls, encryption, authentication, and authorization
  • Project documentation

Periodic/Occasional

  • Participation in Sprint Planning , Sprint Reviews and Retrospectives.
  • Support to other departments.
  • Analysis and testing at customer facilities in cases of support to other departments.
  • Training, supervision and mentoring of less experienced members.
