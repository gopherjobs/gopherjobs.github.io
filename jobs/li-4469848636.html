Job Description We are seeking a versatile and collaborative Java Software Engineer to join our Missions & Insights team. In this role, you will design, build, and maintain robust, scalable end-to-end applications. You will bridge the gap between elegant frontend user experiences and powerful, highly available backend architectures. This is an opportunity to work across the entire stack, utilizing modern cloud technologies to solve complex, real-world problems.

Tech stack: Java 17, Spring, MySQL, Redis, JMS, Linux Key Responsibilities

  • End-to-End Development: Design, develop, test, and deploy scalable frontend applications and robust backend services.
  • Architecture & Design: Contribute to system design and API contract definitions (RESTful/GraphQL) to ensure seamless integration between services.
  • Data Integration: Implement efficient data pipelines and optimize database queries to handle high-throughput, real-time data streaming.
  • UI/UX Collaboration: Partner with UX designers to translate wireframes into intuitive, responsive, and accessible web interfaces.
  • DevOps & Quality: Write clean, maintainable, and well-tested code (unit, integration, and E2E tests). Participate in CI/CD pipeline automation and monitor production system health.
  • Agile Collaboration: Participate actively in sprint planning, code reviews, and cross-functional team discussions to continuously improve engineering practices.

Basic Requirements

  • At least 5 years of software development experience working across the full application stack.
  • Strong proficiency in Java
  • Bachelor’s degree in Computer Science, Software Engineering, or a related technical field (or equivalent practical experience).
  • Experience with relational and non-relational databases (e.g., PostgreSQL, MongoDB, or Redis).

Preferred Qualifications

  • Experience building cloud-native applications on AWS, Azure, or GCP.
  • Familiarity with containerization and orchestration tools like Docker and Kubernetes.
  • Experience with real-time data streaming technologies (e.g., Apache Kafka, WebSockets).
  • Solid experience with modern frontend frameworks, preferably React, Angular, or Vue.js, along with HTML5, CSS3, and TypeScript.
  • Understanding of microservices architecture and secure coding practices.
