Senior Full Stack Developer (Netherlands)

(No Relocation provided)

We are looking for a Senior Full Stack Developer who enjoys solving complex technical challenges and building secure, scalable applications. You will work across front-end development, back-end services and cloud infrastructure, taking ownership from initial design through to deployment and ongoing improvement.

What you’ll be doing

  • Designing, building and maintaining scalable full-stack applications
  • Developing back-end services and APIs using Python , ideally with frameworks such as FastAPI
  • Building user-facing applications with React and TypeScript
  • Designing and optimising relational databases such as PostgreSQL
  • Integrating REST, GraphQL and other APIs across systems and platforms
  • Deploying and operating applications in Microsoft Azure
  • Building and improving CI/CD pipelines using tools such as GitHub Actions or Azure DevOps
  • Working with Docker, Kubernetes and Terraform
  • Writing automated tests using tools such as PyTest and Playwright
  • Improving application performance, observability, reliability and security
  • Supporting engineering best practices through code reviews, knowledge sharing and collaboration
  • Working closely with engineers, architects, product professionals and other stakeholders

What we’re looking for

  • At least 5 years of professional software engineering experience
  • Strong experience across both back-end and front-end development
  • Solid knowledge of Python and modern API development
  • Experience with React, TypeScript or similar front-end technologies
  • Hands-on experience with cloud platforms, preferably Microsoft Azure
  • Practical knowledge of CI/CD, containerisation and modern deployment practices
  • Experience working with SQL databases and optimising queries
  • A good understanding of automated testing and software quality
  • Strong communication skills and experience working in cross-functional or international teams
  • A proactive and pragmatic approach, with the confidence to take ownership and move work forward
  • The ability to explain technical decisions clearly to both technical and non-technical stakeholders

Nice to have

  • Experience with FastAPI, PostgreSQL, GraphQL, Kubernetes or Terraform
  • Exposure to AI-enabled applications, developer AI tools or Retrieval-Augmented Generation
  • Experience with monitoring, observability and production support
  • Experience collaborating with data science or machine learning teams
  • Knowledge of secure software development and cloud governance

Why join?

This is an opportunity to work on meaningful technical challenges across the complete technology stack. You will have the freedom to contribute ideas, challenge existing approaches and help shape reliable products and engineering practices within a collaborative environment.
