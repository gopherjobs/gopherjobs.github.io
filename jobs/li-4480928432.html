Software Testing Analyst (AI Training) About The Role What if your coding instincts could directly influence how AI writes software for millions of developers and businesses around the world? We're looking for Software Testing Analysts to put AI-generated code through its paces — running programs, hunting down bugs, and providing the kind of sharp, structured feedback that makes AI smarter.

This is a fully remote, flexible contract role open to anyone who can read and run code. No formal QA certification or software engineering degree required — just a logical mind, an eye for detail, and a basic comfort with code.

  • Organization: Alignerr
  • Type: Hourly Contract
  • Location: Remote
  • Commitment: 10–40 hours/week

What You'll Do

  • Run AI-generated code and evaluate whether it behaves as expected
  • Identify bugs, logic errors, edge cases, and unexpected outputs
  • Assess code readability, structure, and overall quality
  • Document test results clearly using structured evaluation formats
  • Suggest concrete improvements to help AI produce better, cleaner code
  • Work across a variety of programming languages and problem types
  • Complete task-based assignments independently on your own schedule

Who You Are

  • Comfortable reading and running simple programs in at least one programming language
  • Logical thinker who naturally spots when something doesn't add up
  • Detail-oriented and consistent — you don't let edge cases slip through
  • Clear written communicator who can explain issues concisely
  • Self-motivated and reliable when working independently
  • No formal QA, software engineering, or AI experience required

Nice to Have

  • Familiarity with multiple programming languages (Python, JavaScript, etc.)
  • Experience with code editors, IDEs, or online coding environments
  • Background in computer science, mathematics, or any technical discipline
  • Interest in AI tools or software development workflows

Why Join Us

  • Work on cutting-edge AI projects alongside leading research labs
  • Fully remote and flexible — work when and where it suits you
  • Freelance autonomy with the structure of meaningful, task-based work
  • Contribute directly to improving how AI writes and reasons about software
  • Potential for ongoing work and contract extension as new projects launch
