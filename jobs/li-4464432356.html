Description

About The Team

  • This role sits within the Website & Organic Growth team, a cross-functional team of engineers, designers, SEO specialists and conversion specialists within Employment Hero's Marketing organisation.
  • We build and operate Employment Hero's multi-region web platform, supporting applications and integrations, and newer products including Laravel and AI-enabled experiences.
  • Our current technology landscape includes PHP, Laravel, WordPress, React, TypeScript, JavaScript, APIs and AWS.
  • WordPress remains an important part of our platform, but this is not a WordPress-specialist role. We're looking for a well-rounded full-stack engineer who can work across different parts of the stack and learn unfamiliar systems when needed.

About The Role We're looking for an Intermediate Full-Stack Software Engineer who can take ownership of features from requirements through to production. You'll work across both established systems and newer products, which may include frontend development, PHP and Laravel applications, WordPress functionality, APIs, third-party integrations and AI-enabled features. You'll

  • Own features end-to-end, from understanding the requirement through implementation, testing, deployment and production validation
  • Work across frontend, backend and data layers depending on the needs of the problem
  • Build backend functionality using PHP and Laravel
  • Build frontend experiences using React, TypeScript, HTML, CSS and JavaScript
  • Develop APIs, integrations and WordPress functionality where required
  • Contribute to new AI-enabled products and services
  • Identify unclear requirements, edge cases, technical risks and scope changes early
  • Write automated tests and critically validate both human-written and AI-generated code
  • Investigate production issues using logs, monitoring and debugging tools
  • Participate in code reviews, technical discussions and documentation
  • Communicate progress, risks and blockers proactively

Essential Requirements

  • Strong full-stack web development experience
  • Solid commercial experience with PHP
  • Production experience with React, TypeScript and modern JavaScript
  • Strong HTML, CSS, HTTP and web fundamentals
  • Experience with APIs, databases and third-party integrations
  • Comfortable with Git, code review, automated testing, debugging and CI/CD
  • Able to take a medium-complexity feature from requirement to production without detailed step-by-step direction
  • Able to investigate ambiguity, make sound decisions and ask specific questions when needed
  • Good understanding of maintainability, performance, security and common web application risks
  • Practical experience using AI-assisted development tools, with the judgement to review and validate their output
  • Clear written and spoken English for working with an international remote team

Highly Regarded

  • Laravel or another modern PHP framework
  • AI or LLM application development
  • WordPress, Gutenberg or WordPress multisite
  • AWS or containerised applications
  • Observability and performance tooling
  • Technical SEO, Core Web Vitals or accessibility
  • Experience working with marketing or growth teams
  • Experience working from Figma designs
