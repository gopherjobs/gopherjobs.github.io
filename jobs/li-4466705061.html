About the Role

We are seeking experienced Test Engineers to join our nearshore delivery team in Poland on a short-term B2B engagement (6–9 months).

We are recruiting for three specialisations , and candidates may apply to one or more depending on their strengths:

  1. AI SDET — building intelligent, automated test frameworks and AI agents that transform the software testing lifecycle.

You will work within a collaborative, cross-functional QA team, contributing to high-quality software delivery for international clients.

Specialisation 1: AI SDET (AI Software Development Engineer in Test)

  • Create and maintain automated regression, integration, API, and end-to-end test suites .
  • Integrate test automation into CI/CD pipelines , enabling continuous testing and rapid feedback loops.
  • Collaborate with developers and data scientists to establish AI quality benchmarks and validation strategies.

Required Skills

  • 8+ years in software testing with strong test automation experience.
  • Proven experience building test automation frameworks from scratch.
  • Hands-on experience with AI/ML technologies — LLMs, prompt engineering, LangChain, or similar frameworks.
  • Strong programming skills (Python, Java, C#, or JavaScript).
  • Experience with CI/CD tools (Azure DevOps, GitHub Actions, Jenkins).
  • API testing and test automation tools (Selenium, Playwright, Cypress, Postman, REST Assured).
  • Understanding of AI-specific testing challenges — model validation, data drift, hallucination detection, bias testing.

Specialisation 2: Performance Tester

  • Design performance test strategies and test plans aligned with business objectives and SLAs.

  • Create realistic workload models and test scenarios based on production data and usage patterns.
  • Execute performance tests across applications, APIs, and infrastructure.
  • Analyse and report performance test results — identifying bottlenecks, providing root cause analysis, and recommending optimisations.
  • Collaborate with development, infrastructure, and architecture teams to drive performance improvements.

Required Skills

  • 8+ years in software testing with significant performance testing focus.
  • Expert-level experience with performance testing tools — JMeter, k6, LoadRunner, Gatling, or Neoload .
  • Strong experience in performance test result analysis and bottleneck identification.

  • Proficiency in scripting/programming (Java, Python, JavaScript).
  • Ability to translate technical findings into clear business-level recommendations.
