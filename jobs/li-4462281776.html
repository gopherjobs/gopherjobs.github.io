JOB DESCRIPTION & REQUIREMENTS

Department/Reporting Line:

Works directly with customers to convert their problem statements into production-ready applications — a customer-facing, full-lifecycle engineering role (not purely internal-facing like the Backend Developer role).

Job Purpose/Summary:

Junior Fullstack/Forward Deployed Engineer responsible for building full-stack, production-ready applications directly with customers, from problem statement through to deployment. Combines full-stack development with applied AI/ML and AI-native tooling to deliver working systems, not just prototypes.

Key Responsibilities:

  • Convert customer problem statements into production-ready applications.
  • Build full-stack: Python backend, React frontend, real database, auth — deployed and running.
  • Integrate and orchestrate LLM systems for production: retrieval, agent workflows, structured outputs, evaluation, guardrails.
  • Use AI-native development tools (Claude Code, Codex, Cursor, or equivalent) as the default workflow, with judgment to review and correct agent output.
  • Apply system design and architecture optimization.
  • Handle production applications through full lifecycle development.

Required Qualifications/Skills:

  • 1–3 years of experience
  • Full-stack: Python (backend), React (frontend), real database, auth, deployment experience.
  • Applied AI/ML: integrating/orchestrating LLM systems (retrieval, agent workflows, structured outputs, evaluation, guardrails).
  • AI-native development workflow (Claude Code, Codex, Cursor, or equivalent).
  • Solid grounding in system design and architecture optimization.
  • Experience handling production systems, full lifecycle development.
  • Singapore-hours overlap (GMT+8).

Preferred Qualifications (Optional):

  • Vector databases
  • Docker
  • A cloud platform
  • Workflow automation (n8n/Make)
  • Regulated-industry exposure

Work Environment/Location:

Remote (SEA), working Singapore hours (GMT+8), full-time.

Company Values/Culture Note:

Customer-facing, hands-on delivery culture — expects engineers to work directly with customers and own the full build-to-production cycle, with heavy reliance on AI-native tooling as a core way of working (not optional/nice-to-have).
