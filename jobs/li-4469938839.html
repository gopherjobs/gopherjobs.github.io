What You’ll Do

  • Design, develop, and maintain scalable and efficient full-stack applications
  • Build backend services and APIs using Python
  • Develop modern, responsive user interfaces using Vue.js and JavaScript
  • Create and maintain reusable, component-based frontend solutions
  • Write automated tests and follow software-development best practices
  • Diagnose and resolve technical issues efficiently
  • Develop and maintain microservices and micro-frontend architectures
  • Work with relational databases, including PostgreSQL

  • Participate in code reviews and contribute to improving development standards
  • Stay current with emerging technologies and software-engineering practices

What You Bring

  • Professional full-stack development experience using Python, Vue.js, and JavaScript
  • Strong knowledge of backend development and API design
  • Hands-on experience developing modern, component-based frontend applications
  • Experience with Golang and Node.js
  • Knowledge of Angular and Quarkus
  • Experience with Apache Airflow and workflow orchestration
  • Experience designing and developing microservices
  • Knowledge of modern micro-frontend architecture
  • Experience working with relational databases, preferably PostgreSQL
  • Familiarity with public cloud environments, preferably AWS
  • Understanding of modern DevOps practices, CI/CD, and infrastructure as code
  • Strong knowledge of software-design principles and architectural patterns
  • Experience building modular, resilient, and scalable applications
  • Proficiency with Git and version-control best practices
  • Familiarity with Agile methodologies, including Scrum and Kanban
  • Strong analytical and problem-solving skills
  • Excellent communication and interpersonal skills
