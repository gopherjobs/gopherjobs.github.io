Senior Full Stack Engineer - Claude Code

£500-550 per day | Outside IR35 | Predominantly Remote

Contract: November 2026 – March 2027

Location: Remote-first | Occasional London attendance if required

We're working with a client on an exciting opportunity for an experienced Senior Full Stack Engineer to support the development and delivery of modern, scalable applications within a highly regulated enterprise environment.

This is a hands-on engineering role, suited to someone who enjoys writing production-quality code, building reliable backend services and contributing to frontend development where required.

You'll be joining an established engineering environment where AI-assisted development is actively encouraged, with Claude Code playing an important role in day-to-day delivery.

The Role

You'll work across the application stack, taking ownership of backend development while supporting frontend functionality, system integrations and ongoing improvements.

Key responsibilities include:

  • Designing, building and maintaining backend services using Python and FastAPI.
  • Developing scalable REST APIs, including asynchronous workflows, middleware and data validation.
  • Working with PostgreSQL to manage database structures, optimise queries and implement schema changes.
  • Supporting frontend development using React and TypeScript.
  • Implementing secure authentication and access controls, including SSO, JWT and role-based permissions.
  • Writing automated tests and maintaining high standards of code quality.
  • Using Claude Code to accelerate development while reviewing and validating AI-generated code.
  • Working within established GitHub workflows, CI pipelines and enterprise engineering standards.
  • Collaborating with technical stakeholders to deliver secure, maintainable solutions.

What We're Looking For

Essential experience:

  • Strong commercial Python development experience.
  • Hands-on expertise with FastAPI, Pydantic and PostgreSQL.
  • Experience with Alembic or equivalent database migration tooling.
  • Working knowledge of React and TypeScript.
  • Experience implementing authentication, authorisation and secure API integrations.
  • Automated testing using pytest and JavaScript testing frameworks.
  • Strong understanding of Git, GitHub, pull requests and CI processes.
  • Practical experience using Claude Code within commercial software development.
  • Ability to critically review, test and improve AI-generated code.
  • Experience delivering software within regulated or process-driven enterprise environments.
  • Strong understanding of secure coding practices and change management processes.

Desirable Experience

  • Azure services, including App Service, Key Vault and Application Insights.
  • PingFederate or equivalent enterprise SSO solutions.
  • Rules engines, workflow automation or configurable business logic.
  • Data integrity, concurrency management and audit logging.
  • Advanced Claude Code capabilities, including custom skills, subagents and parallel development workflows.
  • Experience using GitHub Copilot for code review.
  • Accessibility standards and enterprise design systems.

Why Consider This Opportunity?

This is an opportunity to contribute to a technically interesting project where modern software engineering and AI-assisted development come together.
