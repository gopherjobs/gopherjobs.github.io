Position Overview

We are building a cutting-edge Platform that will transform the way our customers identify, protect and govern their data. This will revolutionize how customers secure their data by placing identity at the core — providing unparalleled visibility and control.

We are seeking a Senior Backend Engineer to design, build, and operate the services powering our enterprise SaaS security platform. You will work across a microservices architecture spanning ASP.NET Core APIs, Azure Functions, SQL Server, and Azure CosmosDB — shipping capabilities that serve Fortune 500 customers in hybrid cloud and on-prem environments at high scale.

This is a hands-on engineering role where strong technical execution, distributed-systems fluency, and a security-first mindset are essential. You will independently own features and services end-to-end, collaborating closely with product, architecture, and fellow engineers to deliver scalable, multi-tenant solutions that meet enterprise and regulatory standards.

This is a hybrid role with visits to our Kraków office.

Key Responsibilities

Backend Service Development

  • Design and implement backend features end-to-end: from ASP.NET Core REST APIs and Azure Functions through to SQL Server and CosmosDB data layers.
  • Develop and extend .NET services within a microservices architecture composed of independently scalable, per-service function hosts.
  • Write and maintain Azure Functions for asynchronous processing workloads.
  • Build resilient, idempotent message-driven workflows using Azure Service Bus.

Data & Cloud Engineering

  • Work with SQL Server and Azure CosmosDB to implement performant, secure data access patterns at scale.
  • Own data access patterns that respect multi-tenant isolation boundaries and comply with security and privacy requirements, including RLS policy management.
  • Leverage Azure platform services including Service Bus, Blob Storage, Azure App Configuration, Application Insights, and Entra ID integration.

Quality & DevOps

  • Write comprehensive backend tests: xUnit, Moq, and FluentAssertions for unit and integration coverage.
  • Participate in CI/CD pipeline maintenance using GitHub Actions and Azure DevOps.
  • Contribute to infrastructure-as-code (Terraform) and containerized local development (Docker Compose, Azurite).
  • Proactively identify and resolve performance bottlenecks, security vulnerabilities, and technical debt across services.

Collaboration & Growth

  • Independently break down and deliver complex backend work, owning full project lifecycles from design through production.
  • Participate in architecture discussions, code reviews, and technical design decisions; enforce best practices across the codebase.
  • Partner with product managers and frontend/full-stack engineers to define clean, well-documented API contracts.
  • Mentor junior and mid-level engineers through pairing, code review, and knowledge sharing.
  • Champion the use of AI-driven approaches within the development process to enhance quality, speed, and innovation.

Qualifications

  • 6-8 years of professional software engineering experience, with a strong backend/distributed-systems focus.
  • Strong proficiency in **C# / .NET 8/10** (ASP.NET Core APIs, Azure Functions, isolated worker model).
  • Hands-on experience with **SQL Server** (T-SQL, Entity Framework Core, relational modelling, Row-Level Security) and at least one NoSQL database (CosmosDB preferred).
  • Experience building and operating **Azure-hosted** services (Functions, Service Bus, Blob Storage, App Configuration, Application Insights).
  • Solid understanding of **authentication and authorization** patterns (OAuth 2.0, JWT, Auth0 or similar identity providers).
  • Experience with **multi-tenant SaaS** architectures and the data isolation patterns they require.
  • Comfortable designing and debugging **asynchronous, message-driven systems** (queues, event-driven processing, idempotency, retries).
  • Familiarity with **CI/CD pipelines** (GitHub Actions or Azure DevOps) and infrastructure-as-code (Terraform).
  • Familiarity with **Docker and Kubernetes**.
  • Strong testing discipline (unit, integration) using xUnit/Moq/FluentAssertions or equivalent.
  • Excellent communication skills and ability to work effectively in a cross-functional team.

Preferred Qualifications

  • Exposure to enterprise security domains (identity security, data security posture management, compliance).
  • Experience with **Azure CosmosDB** (SQL API and/or Gremlin graph API), including partitioning and throughput tuning.
  • Experience designing service boundaries in a **microservices architecture** with independent scaling and deployment.
  • Experience building compliance-ready products (e.g., SOC 2, FedRAMP, HIPAA, ISO 27001).
