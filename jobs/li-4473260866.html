Description

Senior Cloud Architect

Location: Remote

Language: English

We are currently looking for an experienced Senior Hands-On Cloud Architect / Developer to join a highly skilled engineering team responsible for the development, scalability and reliability of a complex cloud application ecosystem.

This position combines cloud architecture with hands-on software development and would suit an experienced engineer who is comfortable working across design, implementation and production operations.

Key Responsibilities

  • Design and develop scalable, resilient cloud-native applications and microservices
  • Hands-on development primarily using Python and Go (Golang)
  • Design, provision and maintain cloud infrastructure using Infrastructure as Code
  • Build and operate Docker and Kubernetes environments
  • Develop and optimise automated CI/CD pipelines
  • Support the scalability, availability and performance of distributed systems
  • Diagnose and resolve complex issues within production environments
  • Implement security, authentication and identity-management standards
  • Contribute to monitoring, observability and automated alerting
  • Collaborate with senior engineers on architectural and technical decisions

Technical Requirements

  • Strong production experience with Azure, AWS and/or GCP
  • Advanced Python development experience
  • Strong knowledge of Go/Golang , or proven ability to quickly become proficient
  • Excellent knowledge of Docker and Kubernetes
  • Experience with Infrastructure as Code, automation and CI/CD
  • Strong understanding of SRE principles, high availability and fault tolerance
  • Experience designing and supporting distributed systems and microservices
  • Strong understanding of modern cloud security practices
  • Experience with Azure / AKS, GitHub Actions and OAuth2 would be a plus

If you are an experienced Cloud Architect or Senior Cloud Engineer who would like to remain technically hands-on while contributing to architecture and solution design , I would be very pleased to discuss the opportunity with you in more detail.
