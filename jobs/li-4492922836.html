Senior Backend Engineer – AI Security

London | Remote | £80k - £110k base range depending on experience + equity

Have you ever wanted to help shape a product that some of the world’s largest companies are already using, while you can still influence how it’s built?

This venture-backed start-up helps global businesses understand how new tools are being used across their workforce. Behind the product is a distributed backend that processes high volumes of activity and makes that data available to both the customer-facing application and customers’ own systems.

You’ll own features from design through to production. That could mean deciding how to model a new type of event, building the Java service that processes it and exposing the result through an API or webhook.

The work includes:

  • Designing Java microservices and the event-driven workflows that connect them.
  • Making decisions about how services store, query and share the data they own.
  • Building REST APIs for the product and webhooks that let customers trigger workflows in their own systems.
  • Keeping cloud services reliable as event volumes grow, including handling spikes in traffic and working through production issues.

You’ll bring hands-on experience with Java, distributed systems and API design, plus experience running services on AWS, GCP or Azure. Familiarity with Spring is a plus.
