Job Description: Essential Job Functions: This role requires strong hands-on experience in Java technologies and the ability to communicate effectively in English for remote collaboration.

Job Description

  • Design, develop, and maintain backend applications using Java technologies
  • Work on enterprise-level systems using Core Java and Java EE
  • Develop and optimize SQL queries, stored procedures, and database functions
  • Collaborate with cross-functional teams, including onshore stakeholders
  • Troubleshoot, debug, and enhance system performance
  • Ensure code quality and best practices

Job Requirements

Must-Have

  • Bachelor’s degree in Computer Science, Software Engineering, or related field
  • Minimum 3 years of experience in Java Development
  • Strong experience in: o Core Java o Enterprise Java (e.g., WebLogic)
  • Hands-on experience with Java EE technologies: o EJB, JSP, JPA
  • Experience with Relational Databases: o Oracle preferred o MySQL or similar databases are acceptable
  • Strong skills in: o SQL queries o Stored procedures / functions
  • Familiarity with Linux/Unix environments
  • Good English communication skills – able to work with onsite teams

Nice-to-Have

  • Experience with Java frameworks (e.g., Spring) – generally expected based on experience level
  • Exposure to DevOps tools (e.g., Jenkins) is a plus
  • Familiarity with front-end / full-stack technologies is a bonus: Vue.js / React.js / Angular
