For our long-standing client in the energy sector, we are looking for an Cloud Backend & Edge DevOps Engineer (m/f/d) who implements the backend integration of Mender Enterprise SaaS into the e.IoT platform for secure fleet-wide software updates.

Only Nearshore!

Current Situation The IoT platform landscape faces three primary operational bottlenecks for which we currently lack capacity in the internal team: Azure IoT Hub requires automated device registry backups and a validated recovery procedure; frontend development capacity cannot ingest UI designs fast enough to meet demand; and remote edge devices lack a proper managed central enterprise-grade Over-The-Air (OTA) deployment mechanism.

Project Objective Deliver a unified engineering initiative to establish automated IoT Hub disaster recovery, expand frontend capacity to rapidly implement dlab UI assets, and integrate Mender Enterprise for secure fleet-wide software updates.

Project Scope

  • Frontend — Capacity Scaling & dlab Ingestion: Onboarding dedicated React/Angular developer(s) to work alongside the core devops team and the new hire in a paired delivery model. Direct translation of dlab Figma designs, design tokens, and UI components into reusable code to accelerate frontend feature delivery.
  • DevOps — IoT Hub Disaster Recovery (DR): Implementation of automated, continuous device registry and twin state backups to secure Azure Blob Storage (excluding ADR). Creation of operational recovery runbooks and mandatory execution/verification of full device state restoration in a Dev environment as Acceptance Criteria (AC).
  • Backend & Edge — Mender Enterprise OTA Integration: Deployment and backend API integration of Mender Enterprise SaaS for secure, fleet-wide Over-The-Air updates, software package signing, progressive rollout orchestration, and fail-safe automatic rollbacks.
  • Deployment and backend API integration of Mender Enterprise in e.IoT for progressive rollout orchestration
  • Setup of software package signing pipelines and fail-safe automatic rollback rules for edge updates
  • API integration expertise
  • Proficient scripting skills (Python, Bash, PowerShell)
  • Experience with software supply chain security, code signing, and secrets management
