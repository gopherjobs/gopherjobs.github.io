Description

Are you a full stack engineer who wants real ownership of a product, not just a feature? How about owning the self-service cloud portal for a leading data integration platform, from the Python backend to the Angular frontend?

My client is a major data integration platform provider with over 2,000 customers globally, looking for a skilled Full Stack Software Engineer to help build out their cloud services. You will join the Cloud Engineering team, working alongside platform and DevOps engineers who manage AWS hosting, Terraform, Ansible, and Packer, but don't have dedicated software development skills in-house. You will be the software engineering expert on this team, with real ownership.

What you'll do:

  • Own the customer-facing self-service cloud portal end to end, currently handling login, monitoring, firewall rule management, and service restarts
  • Build the next phase of self-service functionality: API-driven cloud environment provisioning, VPN and VPC peering setup, and firewall configuration, so customers can manage their own environments without raising a support ticket
  • Work toward a long-term vision of a full self-service admin portal comparable to the MongoDB Atlas UI
  • Build across the full stack in a roughly 50/50 split: Python with FastAPI on the backend, Angular and TypeScript on the frontend
  • Take ownership of what you build all the way into production: deployment, monitoring, and debugging, not just writing code and handing it off
  • Bring your own ideas and judgement to the product, since there's no other software engineer on the team to shape these decisions with you

Your profile:

  • Strong experience with a Python web framework such as FastAPI and practical knowledge of asyncio
  • Proficiency with Angular and TypeScript on the frontend, with the ability to build new components
  • Familiarity with relational databases, schema design, and an ORM like SQLAlchemy

Furthermore:

  • You have a "you build it, you run it" production mindset and think about pipelines, testing, and maintainability
  • Working knowledge of Docker for building containerized, stateless services
  • Experience with cloud platforms, specifically AWS, and an infrastructure as code mindset using tools like Terraform
  • You enjoy having the freedom to take end-to-end ownership of features and bring your own ideas to product management
  • A natural instinct for security and an eye for the user experience

Benefits:

  • Competitive base salary in EUR
  • 30 vacation days per year, plus paid days off on Christmas Eve and New Year's Eve
  • Company pension plan (bAV)
  • Personal learning and development budget
  • Bike leasing scheme (JobRad)
  • Option to work remotely from any EU country for up to 30 days per year
  • Weekly team evenings

Salary: up to 80,000€/year
