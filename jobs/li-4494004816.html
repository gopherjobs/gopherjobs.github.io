Position Description We are looking for a talented and experienced Sr Java/Go Developer to join our team in Argentina to build and maintain backend services and APIs that connect to supply systems, including primary API operations and legacy API integrations. The role is backend-focused, with Java/Kotlin as the primary language and Go for modern API services and microservices. The work includes modernizing legacy C#/.NET applications, so experience with migrations is a strong plus. The position requires 7+ years of software engineering experience, independent work, and strong ownership of production quality and monitoring. Frontend work (React) is occasional and optional.

In this role you will own complex full-stack initiatives while mentoring engineers and helping shape technical direction. Senior Engineers are expected to engineer solutions, challenge assumptions, and drive technical excellence. The project focuses on building, maintaining, and scaling backend services and APIs that connect directly to supply systems, supporting both primary API operations and legacy API integrations. Engineers on this project will focus on core backend API services and may also collaborate on cross-functional initiatives.
