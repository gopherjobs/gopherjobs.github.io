Description

Logitech is the Sweet Spot for people who want their actions to have a positive global impact while having the flexibility to do it in their own way.

The Role 罗技苏州工厂的核心业务系统——ERP、MES、QMS、WMS、PLM——由 IT 团队全面负责。我们也持续开发贴合产线真实需求的自研应用，把生产、质量、物料与供应链流程中大量还在靠人工支撑的环节，变成真正好用的系统。

我们希望你以实习生的身份加入这项工作，参与自研应用的开发与交付。这不是一个观摩学习或做课题研究的岗位——你会拿到真实的需求、写会被员工使用的代码、并对自己交付的功能负责。你的工作成果会直接出现在车间和办公室的日常流程里。

这个岗位需要的是动手能力。 我们期待你在入职第一周就能读懂一段业务代码、写出一个能跑的接口、查清楚一条 SQL 为什么返回了错误的结果。

Key Responsibilities

  • 开发面向产线和职能部门的内部应用：在指导下承接边界清晰的功能模块，完成从数据模型设计、后端接口、前端页面到联调测试的开发工作，交付后与使用者一起在真实场景中验证并修复问题。
  • 把手工流程自动化：工厂里存在大量靠人工导出、核对、汇总 Excel 的重复流程。你会识别并改造其中一部分，用 Python 脚本或定时任务替代人工操作，处理好数据清洗、异常情况和结果核对。
  • 支撑数据处理与系统集成：编写系统间的数据同步与对账脚本、日志解析工具和异常告警，协助排查接口和数据一致性问题，逐步理解 ERP、MES、WMS 之间的数据是怎么流动的。
  • 参与团队的工程实践：按照 Git 工作流提交代码并接受代码评审，为自己写的功能补充自动化测试，整理部署与使用文档。你会在真实项目里习得这些做法，而不只是听说过它们。

Qualifications Required

  • 计算机、软件工程或相关专业在读。能够连续实习 6 个月及以上，每周到岗 4 天及以上，工作地点为罗技苏州工厂。
  • 扎实的编程能力。 能独立写出可运行、结构清晰的程序，熟悉常用数据结构、文件与数据处理、异常处理。编程语言不限，Python、Java、C#、C++、Go 等均可；我们的自研应用以 Python 为主，已经能熟练使用 Python 的更佳，其他语言背景则需要能在短期内迁移过来。
  • 关系型数据库与 SQL 能力。 能设计基本的表结构，熟练编写多表 JOIN、分组聚合和子查询，理解索引、事务和基本的性能问题。在 MySQL、PostgreSQL 或同类数据库上有实际使用经验。
  • Web 应用开发经验。 使用 Django 完成过后端接口开发，理解 HTTP 与 REST API 的基本概念；能使用 Vue 编写可交互的前端页面。有 Flask、FastAPI、Spring Boot、React 等同类技术栈经验，并能快速迁移到 Django + Vue 的，同样欢迎。
  • 至少一个你真正做出来过的项目。 课程设计、竞赛作品、个人项目或实习成果均可，但它应当是一个能够实际运行、由你本人主导完成的东西，而不是停留在文档和设想里的构思。投递时请附上代码仓库链接或压缩包。我们看重"做出来过"，不看重项目的规模和话题的前沿程度。
  • Git 的基本使用能力。 理解分支、提交、合并与冲突解决。
  • 使用 AI 编程工具的意愿和判断力。 我们在日常开发中使用 Claude Code、Codex 等工具，也鼓励你使用。但你要对提交的每一行代码负责：能解释它做了什么、为什么这么写，并能识别出 AI 给出的错误或不合适的方案。只会复制粘贴而无法判断对错的，不适合这个岗位。
  • 沟通意愿与责任心。 需求不清楚时主动问，遇到卡点及时暴露，对交付的功能负责到底。

Preferred

  • 有使用 Linux 和 Docker 的实际经验，能独立完成简单的应用部署
  • 有 AWS 使用经验。我们的应用部署在 AWS 上，因此在 EC2 上部署过应用，或使用过 RDS、S3 等基础服务的，会有明显优势
  • 写过单元测试或自动化测试
  • 有过完整交付并部署上线的个人项目（哪怕只有几十个用户）
  • 使用 LLM API 做过实际可用的小工具
  • 了解制造或供应链业务流程，或有工厂、制造企业的实习经历

关于面试 我们的面试以动手能力为核心，会包含以下内容：

  • 现场编码。其中一部分不允许使用 AI 工具，考察编程与 SQL 的基本功；另一部分允许使用 AI 工具，完成一个贴近我们真实工作的小需求，并定位和修复代码中的问题。
  • 关于项目经历、技术认知、工作方式和实习安排的沟通。
