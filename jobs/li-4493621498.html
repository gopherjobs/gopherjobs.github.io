Description

DVT is a leading software development and technology consulting company that partners with organisations to design, build, test and deliver high quality digital solutions. Our teams work across diverse client environments, giving technology professionals exposure to modern platforms, complex projects and opportunities to continuously develop their technical expertise.

DVT is looking for a Senior Quality Engineer, AI & Automation who combines strong Quality Engineering and test automation experience with practical knowledge of AI enabled testing.

The ideal candidate will have a strong foundation in frontend and API testing, hands on automation experience with Playwright or comparable modern frameworks, JavaScript or TypeScript, and experience integrating automated testing into CI/CD pipelines.

Importantly, this is not an AI or Machine Learning development role. We are looking for a Quality Engineer who can use AI to improve the testing lifecycle while also contributing to the testing of AI enabled products and features .

Relevant experience may include using tools such as GitHub Copilot, Cursor, ChatGPT or similar technologies for test generation, automation development, debugging, defect analysis, test optimisation and maintenance. Experience validating AI or LLM based functionality for accuracy, consistency, reliability, bias or unexpected behaviour is particularly relevant.

Frontend Testing & Quality Assurance

  • Design, develop and execute test strategies and test plans for modern web applications
  • Validate functionality, usability, accessibility, responsiveness and cross-browser compatibility
  • Work closely with developers, business analysts and UX teams so quality requirements are built in early in the development lifecycle
  • Perform exploratory, regression, integration and end-to-end testing
  • Validate frontend behaviour across desktop and mobile platforms [responsive web / native mobile apps]
  • Identify, document and track software defects through to resolution using [Azure DevOps / Jira / other]

Test Automation & Playwright Development

  • Design, build and maintain scalable automation frameworks using Playwright (or a similar modern tool)
  • Develop reliable end-to-end and API automated test suites for web applications
  • Implement automated regression testing within CI/CD pipelines
  • Create reusable automation components, libraries and testing utilities
  • Establish and enforce automation standards, best practices and coding guidelines
  • Increase test coverage while reducing execution time and maintenance overhead

AI-Driven Quality Engineering

  • Use AI tools such as [GitHub Copilot / Cursor / ChatGPT / other] to improve test case generation, maintenance and execution
  • Use AI-assisted development tools to speed up automation implementation
  • Apply AI-powered techniques to defect analysis, root cause investigation and test optimisation
  • Test AI-enabled features and products, including validating outputs for accuracy, consistency, bias and reliability
  • Evaluate emerging AI testing technologies and recommend which ones to adopt
  • Drive initiatives that improve productivity and software quality through responsible and secure AI usage
  • Champion modern quality engineering approaches that bring automation and AI together

CI/CD, Reporting & Continuous Improvement

  • Produce clear test reports and quality dashboards for technical and non-technical stakeholders

Leadership & Mentoring
