Fiche De Poste We are seeking a Senior Application Developer to design, develop, and support Guidewire applications operating within AWS infrastructure. This role will contribute to solution design, cloud optimization, and application enhancements while ensuring performance, scalability, and reliability.

Key Responsibilities

Application Development

  • Develop and enhance Guidewire Policy Center components (Gosu, Rules, Plugins, Batch Jobs, PCF, Integrations).
  • Build and maintain RESTful services and system integrations.
  • Implement application configuration and integration enhancements.
  • Perform performance tuning and troubleshooting.
  • Develop and maintain applications deployed on EC2/ECS/EKS with RDS (SQL Server).
  • Support application logging, monitoring, and alerting via CloudWatch.
  • Optimize application performance within AWS-hosted environments.
  • Work with infrastructure teams to resolve environment-related issues.

DevOps & Release Support

  • Contribute to CI/CD pipeline configurations.
  • Participate in build validation, deployments, and post-production checks.
  • Support on-call rotation for production incidents.

Collaboration

  • Participate in Agile ceremonies.
  • Provide effort estimates and support enhancement planning.
  • Conduct peer code reviews.

Required Qualifications

  • 6–9 years of application development experience.
  • Strong experience with Guidewire Policy and claim Center.
  • Java/J2EE and SQL Server expertise.
  • Experience working in AWS-hosted application environments.
  • Familiarity with CI/CD tools and automated deployments.
