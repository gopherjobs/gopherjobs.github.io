Description

En Transborder creemos en el poder del comercio internacional para conectar personas, ideas y oportunidades alrededor del mundo. Nuestro propósito es impulsar el crecimiento de las empresas y abrir caminos para el talento que quiere dejar huella en esta industria.

Hoy queremos invitarte a postularte a nuestra nueva vacante: Desarrollador/a Java Spring Boot . Esta es tu oportunidad de ser parte de un equipo dinámico, apasionado y comprometido con la innovación en el sector de Agentes de carga.

¿Qué buscamos? Profesional con 1 a 2 años de experiencia en desarrollo de software, con sólidos conocimientos en Java y Spring Boot, idealmente con experiencia Full Stack y participación en proyectos basados en microservicios.

Requisitos

  • 1 a 4 años de experiencia en desarrollo de software.
  • Sólidos conocimientos en Java y Spring Boot.
  • Experiencia desarrollando microservicios.
  • Experiencia en desarrollo Frontend con Angular, idealmente en versiones recientes.
  • Experiencia desarrollando y consumiendo APIs RESTful y conocimientos en servicios SOAP.
  • Manejo de bases de datos relacionales.
  • Experiencia en despliegues en la nube, preferiblemente Azure o AWS.
  • Conocimientos en procesos de Integración y Despliegue Continuo (CI/CD).
  • Manejo de herramientas como Postman, Visual Studio Code y sistemas de control de versiones.
  • Deseable experiencia utilizando herramientas de desarrollo asistidas por IA como GitHub Copilot, IntelliJ AI Assistant, Azure AI o similares.

Funciones

  • Resolver incidencias y realizar mantenimiento evolutivo de las aplicaciones.
  • Desarrollar funcionalidades tanto en Backend como Frontend.
  • Diseñar e implementar microservicios con Java y Spring Boot.
  • Desarrollar interfaces interactivas y escalables utilizando Angular.
  • Integrar aplicaciones mediante APIs RESTful y SOAP.
  • Trabajar con bases de datos relacionales, asegurando la correcta persistencia de la información.
  • Participar en despliegues en ambientes Cloud y procesos de integración continua.
  • Trabajar de manera interdisciplinaria con el equipo de desarrollo y líderes técnicos para construir soluciones de alta calidad.

Condiciones Contrato: Término indefinido.

Modalidad: Híbrido. Durante los primeros 2 meses: presencial con 1 día de trabajo remoto por semana. Posteriormente: 2 días de trabajo remoto por semana.
