Job Description Key Responsibilities

  • Requirement Analysis: Collaborate with product managers and cross-functional teams to translate business requirements and user needs into technical specifications and testable features.
  • Web Development: Assist in developing robust frontend interfaces and scalable backend services. Contribute to building responsive, user-friendly, and secure web applications.
  • AI Integration: Research, evaluate, and implement AI solutions. This includes connecting applications to Large Language Models (LLMs) via APIs, exploring Retrieval-Augmented Generation (RAG) pipelines, and utilizing AI development tools.
  • Cloud Operations: Deploy and manage application components on cloud infrastructure, ensuring high availability, security, and performance.
  • Debugging & Troubleshooting: Monitor application performance, investigate bugs, and write automated tests to ensure code reliability and smooth user experiences.

Basic Requirements

  • Bachelor’s degree in Computer Science, Software Engineering, Information Technology, or a related technical field (recent graduates are encouraged to apply).
  • Web Development Foundations: Understanding of modern web architectures (RESTful APIs, MVC) and proficiency in at least one core programming language (e.g., Python, JavaScript/TypeScript, Java, or C#).
  • Good with frontend frameworks (e.g., React, Vue, Angular) and backend frameworks (e.g., Node.js, Django, FastAPI).
  • Familiarity with containerization (Docker) and CI/CD pipelines.
  • Understanding of vector databases or AI agent frameworks (e.g., LangChain).
  • AI Knowledge: Fundamental understanding of machine learning concepts, Generative AI, and prompt engineering. Experience consuming AI APIs (e.g., OpenAI, Anthropic) through academic or personal projects is highly valued.
  • Cloud Fundamentals: Basic knowledge of cloud computing concepts and services (AWS, Google Cloud Platform, or Microsoft Azure).
  • Problem-Solving Skills: Strong analytical skills with a proactive approach to debugging code, diagnosing system issues, and finding efficient technical solutions.
  • Tools & Workflows: Familiarity with Git version control, basic SQL/database concepts, and software development methodologies (Agile/Scrum).
