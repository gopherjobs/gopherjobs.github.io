Department: Software / Industrial IoTAbout the Role:

* About the Role: *

We are looking for an experienced Edge Application Software Engineer to build, package, and deploy containerized microservices on industrial edge computing platforms.

In this role, you will bridge shop-floor operational data with enterprise IT systems. You will design microservice architectures, integrate industrial telemetry into local time-series databases, and manage edge hardware container lifecycles.

If you love working on Linux, Docker, IoT protocols, and real industrial machines, this role is for you.

* What You Will Do :*

* Develop, package, and maintain containerized applications using Docker & Docker Compose for Linux edge hardware

* Build backend microservices in Python / Go / C++ / Node.js and RESTful / gRPC APIs for data processing and edge analytics

* Connect edge applications with plant machinery and industrial controllers using OPC UA, MQTT, Modbus TCP

* Configure local message brokers (Mosquitto MQTT) and time-series databases (InfluxDB, TimescaleDB, SQLite)

* Deploy app packages, monitor container resource limits (CPU/RAM), and manage software updates across remote edge fleets

* Implement secure communications (mTLS, TLS/SSL, X.509) and set up CI/CD pipelines for edge devices

* What We Are Looking For :*

* Bachelor's degree in Computer Science, Software Engineering, Computer Engineering, or related field

* 3+ years of experience in software engineering with focus on containerized Linux microservices, IoT, or edge software

* Advanced expertise in Docker, multi-stage Dockerfile builds, multi-architecture builds (x86_64 vs ARM64), Docker Compose

* Hands-on experience in at least two languages: Python, Go, C++, Node.js / TypeScript

* Strong knowledge of Embedded Linux / Ubuntu, systemd, Bash scripting, non-root container security

* Deep working knowledge of OPC UA client/server and MQTT pub/sub messaging

* Solid understanding of subnets, reverse proxies (NGINX), firewall, TLS/SSL, REST API authentication

* Good to Have :*

* Experience with Node-RED, Grafana, InfluxDB Dashboards

* Exposure to AWS IoT Core / Azure IoT Hub

* Experience with Git, GitHub Actions / GitLab CI/CD

* Why Join Us ?*

Work on real Industrial IoT products, cloud architectures, and cutting-edge containerized deployments used in live plants.
