Description

Role Description As a Senior Software Engineer (SDE 2), Backend — Engineering at Redacto, you will design, build, and maintain backend services that power our data privacy command center. You will architect and implement scalable APIs, optimize system performance, and ensure reliability and security across microservices and data pipelines. Day-to-day responsibilities include writing high-quality code, performing code reviews, collaborating with product managers and other engineers, and troubleshooting production issues. You will contribute to technical decisions, mentor junior engineers, and help define best practices for backend development. This is a full-time, on-site role based in Bengaluru.

  Employment Type: Full-time onsite (This is not a remote job)

What You'll Do

  • Design and implement scalable, high-performance backend systems.
  • Architect robust APIs and microservices.
  • Lead technical design and implementation.
  • Ensure code quality via testing and reviews.
  • Optimize performance and troubleshoot issues.
  • Collaborate with product teams.
  • Mentor junior engineers.
  • Implement data protection and privacy-enhancing technologies.

You Bring

  • 3+ years of professional backend engineering experience.
  • Bachelor's/Master's in Computer Science (preferred).

Skills

  • Languages & Frameworks: Expert Golang & Python Frameworks
  • APIs: Strong REST API design.
  • Data: SQL/NoSQL databases.
  • Cloud & Infra: Cloud platforms (AWS, Azure, GCP); Docker/Kubernetes.
  • Delivery: CI/CD, automated testing.
  • Engineering: Problem-solving, debugging, and security best practices.

Qualifications

  • Strong foundation in Computer Science, including data structures, algorithms, and systems design.
  • Hands-on experience in Back-End Web Development and Software Development for scalable, production-grade systems.
  • Proficiency in Programming and Object-Oriented Programming (OOP), with expertise in at least one modern backend language (e.g., Java, Go, Python, or Node.js).
  • Experience designing and consuming RESTful or GraphQL APIs, and working with databases (SQL and/or NoSQL).
  • Familiarity with cloud platforms (e.g., AWS, GCP, or Azure), containerization, and CI/CD pipelines.
  • Strong problem-solving skills, ability to debug complex issues, and write clean, testable, maintainable code.
  • Effective communication and collaboration skills, with experience working in cross-functional engineering teams.
  • Bachelor’s or Master’s degree in Computer Science or a related technical field, or equivalent practical experience.
  • Experience in security, data privacy, or building enterprise SaaS products is a plus.
