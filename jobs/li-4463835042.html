Job Title: Google cloud Infrastructure SME (Containerization & Cloud SME)

Required Skills: Google cloud, Google Kubernetes Engine (GKE), Docker, microservices architectures and system observability, logging, and monitoring

Location : Krakow Poland (Remote)

Type : B2b/Uop

Position Description

We are looking for a highly skilled Google cloud Infrastructure SME to join Client and act as a Subject Matter Expert (SME) in cloud infrastructure and containerization. In this role, you will be the main technical driver responsible for defining and executing the containerization strategy for our core systems. You will work closely with development and architecture teams to ensure a seamless transition of our applications into a modern, cloud native environment.

Information About the Project

  • You will be working on a robust data platform designed for processing, sharing, gathering, and analyzing data for airlines, integrating information from various disparate systems.
  • Project Status: This is a brand-new position. We are expanding our team specifically to tackle the modernization of this product, transitioning it from a legacy monolith application into a scalable microservices architecture.
  • Project Duration: The project is planned for one year with a strong potential for extension. The current intensive phase focuses directly on the containerization of the product on GKE (Google Kubernetes Engine). The core product itself has been successfully operating for years and has a rich roadmap for continuous expansion.
  • Team Structure: You will be joining an international, mixed Polish and Indian collaborative environment. Currently, we have two teams based in Poland and one in India, and we are actively working towards fully integrated, mixed agile teams. Daily communication and documentation are strictly in English.

Duties and Responsibilities

  • Act as the Subject Matter Expert (SME) for containerization, taking full technical ownership of the transition to Google Kubernetes Engine (GKE).
  • Design, build, and maintain scalable cloud infrastructure on GCP using Terraform and Ansible.
  • Create and optimize advanced CI/CD pipelines utilizing Jenkins and Github Actions to ensure smooth and automated delivery.
  • Write reliable automation scripts and internal tools using Python.
  • Collaborate closely with Java backend developers to assist in adapting Core Java and Spring Boot applications for containerized environments.
  • Monitor, troubleshoot, and resolve infrastructure, deployment, and performance issues within the GKE clusters.
  • Drive best practices for cloud security, infrastructure as code (IaC), and DevOps culture across the engineering teams.

Must Have Attributes:

  • 7+ years of overall engineering experience with a strong focus on Cloud, DevOps, or Infrastructure.
  • Deep, hands-on expertise as a Subject Matter Expert in containerization technologies (Docker) and orchestration, specifically Google Kubernetes Engine (GKE) and the broader GCP ecosystem.
  • Strong practical experience with Infrastructure as Code (IaC) and configuration management tools, primarily Terraform and Ansible.
  • Proven track record of designing and managing complex CI/CD pipelines using Jenkins and Github Actions.
  • Solid programming and scripting skills in Python.
  • Good understanding of Core Java and Spring Boot to effectively communicate and collaborate with the backend development team.
  • Fluent English (B2/C1 minimum) to ensure seamless communication in our international Polish and Indian teams.

Nice to Have Attributes:

  • Official Google Cloud certifications (e.g., Professional Cloud Architect, Professional Cloud DevOps Engineer).
  • Previous experience in migrating legacy monolithic applications to microservices architectures.
  • Strong background in system observability, logging, and monitoring within Kubernetes environments.
