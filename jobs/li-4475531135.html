Cloud Security Analyst (AI Training) About The Role We're partnering with leading AI research labs to build smarter, safer AI systems — and we need cloud security practitioners who know how cloud environments fail in the real world.

This isn't a theoretical exercise. You'll be working with real cloud security scenarios across AWS, GCP, and Azure, helping to evaluate and improve AI reasoning around misconfigurations, IAM failures, blast radius, and incident response. Your expertise directly shapes how the next generation of AI understands cloud security.

  • Organization: Alignerr
  • Type: Hourly Contract
  • Commitment: 10–40 hours/week
  • Location: Fully Remote

What You'll Do

  • Analyze cloud security scenarios across AWS, GCP, and Azure to identify real-world risks and failure patterns
  • Review and assess IAM, networking, storage, and container security issues
  • Classify security gaps, misconfigurations, and cloud-related failures based on real-world impact
  • Validate and improve AI-generated security reasoning so it accurately reflects how cloud incidents actually unfold
  • Provide structured, expert feedback that helps frontier AI models reason more accurately about cloud threats

Who You Are

  • 2+ years of hands-on experience working with cloud environments in production
  • Solid understanding of cloud IAM, networking, storage, and container security
  • Familiar with real-world misconfigurations and how cloud security incidents develop
  • Able to reason clearly about blast radius, risk exposure, and business impact
  • Clear and structured communicator — you can explain complex security concepts in writing

Nice to Have

  • Experience with cloud security tools (e.g., AWS Security Hub, GCP Security Command Center, Azure Defender)
  • Background in penetration testing, red teaming, or cloud incident response
  • Familiarity with frameworks like CIS Benchmarks, MITRE ATT&CK for Cloud, or CSA CCM
  • Certifications such as AWS Security Specialty, CCSP, or equivalent

Why Join Us

  • Work directly on frontier AI systems with top research labs
  • Fully remote and flexible — work on your own schedule
  • Freelance perks: autonomy, variety, and global collaboration
  • Your real-world expertise shapes how AI understands and reasons about cloud security
  • Potential for ongoing work and contract extension
