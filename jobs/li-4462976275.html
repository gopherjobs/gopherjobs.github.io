Software Engineer (gRPC) at BairesDev

As a Software Engineer specializing in gRPC, you will develop high-performance service-to-service communication solutions using Protocol Buffers. You will be responsible for building scalable and efficient APIs that ensure seamless data exchange across distributed systems while maintaining low latency and high throughput.

What You'll Do:

- Design and implement high-performance APIs and microservices communication using gRPC.

- Define and maintain efficient data schemas and service interfaces using Protocol Buffers.

- Implement advanced streaming patterns, including unary, server-side, client-side, and bidirectional streaming.

- Optimize service communication through effective load balancing and connection management strategies.

- Automate code generation and integrate gRPC services into existing polyglot environments.

- Ensure the reliability and performance of internal service communication through rigorous testing and observability.

What we are looking for:

- 4+ years of experience in Software Engineering with a focus on API development.

- Proven expertise in developing high-performance service-to-service communication using gRPC and Protocol Buffers.

- Hands-on experience with streaming, load balancing, and code generation within gRPC frameworks.

- Strong understanding of microservices architecture and distributed systems.

- Advanced proficiency in English.
