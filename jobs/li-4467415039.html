Description

Company

Go10 Limited is a rapidly growing UK-based value-added distributor of consumer products, known for its focus, speed and agile operations. Technology is central to how we operate, with our internally developed Gateway platform supporting commercial, operational, ecommerce, supply chain and data workflows across the business.

Go10 is looking for a Senior Full Stack Engineer to help build and scale Gateway, our internally developed business platform. Gateway is a growing suite of applications used across the business, covering commerce, data, workflow and automation. This is a hands-on engineering role. You will own features end to end, from database schema and backend services through to the finished React interface.

We are looking for someone comfortable working on complex applications, making sound technical decisions and delivering production-quality software. This role is focused on the Gateway application estate and its supporting services. It is not an AI, machine learning or data science position.

What you'll do

  • Build applications using TypeScript, React and Next.js.
  • Develop backend services, APIs and business logic using TypeScript and Node.js.
  • Design and maintain PostgreSQL/Supabase schemas, queries and migrations.
  • Build complex application interfaces including dashboards, tables, forms, workflows and data visualisations.
  • Turn designs into responsive, accessible production interfaces.
  • Build reusable UI components and contribute to the Gateway design system.
  • Implement authentication, permissions, RBAC, oAuth, OIDC, WIF and secure multi-tenant functionality.
  • Build integrations with external APIs, webhooks and data services.
  • Develop background jobs, queues and asynchronous workflows.
  • Build features that behave correctly under retries, concurrency and partial failure, following established platform patterns.
  • Improve testing, performance, observability and platform reliability.
  • Review code and work within the established engineering standards and architecture.

What we're looking for

  • Typically 5+ years of professional software engineering experience.
  • Strong TypeScript experience across frontend and backend.
  • Strong React and modern frontend development skills.
  • Strong Node.js and API development experience.
  • Strong PostgreSQL and relational data-modelling knowledge.
  • Experience building complex, data-heavy web applications.
  • Experience taking functionality from database through backend, API and UI to production.
  • Experience with authentication, permissions and application security.
  • Experience integrating third-party APIs and services.
  • Understanding of asynchronous processing, transactions, concurrency and data integrity.
  • Experience with testing, Git, CI/CD and production deployments.
  • Strong written English and the ability to work directly with a UK-based team.

Experience with Next.js, Supabase, Vercel, SaaS platforms, multi-tenant applications, ecommerce or workflow systems is a must.

The person we're looking for

You should be comfortable being given a business problem rather than a fully specified development ticket. You will need to understand the requirement, work with product and design, determine the appropriate technical approach and then build the complete experience.

You should think beyond whether the code works, to consider security, permissions, data integrity, performance, failure states, usability and maintainability. We are particularly interested in engineers who have built substantial applications rather than primarily websites or marketing frontends.

This is a genuine full-stack role. We need strong React capability because you will build the interfaces our users interact with, but equally strong backend fundamentals because you will also build the systems underneath them. You will work closely with our Product and Digital team and have significant ownership over the applications you build.

Working at Go10

Fully remote, with direct access to the Head of Digital Platforms and genuine influence over how the Gateway platform evolves.

This role offers the opportunity to work on software that directly affects how the business operates. Engineers are expected to understand the purpose of the applications they build, not simply implement tickets.

Core overlap with the UK team is 9:00am to 5:00pm UK time.
