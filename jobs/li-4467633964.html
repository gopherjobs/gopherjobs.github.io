🚀 We’re Hiring: Web GIS Developer

Metavystic (Pvt.) Ltd. is looking for an experienced Web GIS Developer with 2+ years of professional experience to join our growing geospatial technology team.

If you have hands-on experience building Web GIS applications, interactive maps, spatial data solutions, GIS dashboards, and geospatial APIs , we’d love to hear from you.

📍 Location: Islamabad

🏢 Work Arrangement: Onsite

💼 Employment Type: Full-Time

🕘 Working Hours: 9:00 AM – 6:00 PM, Monday–Friday

🗺️ What You’ll Do

  • Develop and maintain Web GIS applications and interactive mapping platforms
  • Build interactive maps with layers, markers, popups, filters, search and spatial visualization tools
  • Integrate GIS data, REST APIs and external geospatial services
  • Work with WMS, WFS and OGC-compliant services
  • Develop and integrate solutions using GeoServer
  • Work with spatial formats including GeoJSON, Shapefile, KML/KMZ, GeoTIFF, CSV and Excel
  • Develop GIS dashboards and data visualization interfaces
  • Integrate frontend applications with backend APIs
  • Work with PostgreSQL/PostGIS and spatial databases
  • Process and analyze geospatial data using GDAL, ArcPy and other GIS tools
  • Optimize applications for large spatial datasets and high-performance map rendering
  • Debug and resolve frontend, API, database and GIS-related issues
  • Collaborate with GIS specialists, frontend/backend developers, QA engineers and project managers
  • Participate in code reviews, technical discussions and project planning
  • Write and maintain technical documentation

🛠️ Required Skills

Web Development

  • 2+ years of professional web development experience, preferably with Web GIS
  • Strong knowledge of JavaScript, HTML and CSS
  • Experience with React.js or another modern frontend framework
  • Experience consuming and integrating REST APIs
  • Good understanding of frontend/backend integration
  • Experience with Git and collaborative development workflows
  • Understanding of responsive web application development

GIS / Geospatial

  • Strong practical understanding of GIS concepts and spatial data
  • Hands-on experience with at least one web mapping library:
  • Leaflet, OpenLayers, Mapbox GL JS or CesiumJS
  • Experience working with WMS/WFS
  • Understanding of Coordinate Reference Systems (CRS), projections and spatial transformations
  • Experience working with GeoJSON, Shapefile, KML/KMZ, GeoTIFF and other spatial formats
  • Experience with GeoServer is preferred
  • Basic to intermediate knowledge of PostgreSQL/PostGIS

Geospatial Processing

  • Experience with GDAL / GDAL utilities
  • Experience with ArcPy / ArcGIS geoprocessing
  • Understanding of raster and vector data processing
  • Experience with spatial analysis and geospatial data conversion
