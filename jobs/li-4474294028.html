Description

Position: Software Test Engineer / Quality Engineer

Location: Madrid & Barcelona - position available in both locations

Job Type: Permanent

Job Mode: Hybrid - 3 days onsite and 2 days remote in a week

Responsibilities:

  • Define and implement Quality Engineering strategies aligned with engineering standards, delivery objectives, and overall quality goals.
  • Drive shift-left testing practices by identifying quality risks early and embedding testing activities throughout the software development lifecycle.
  • Design, develop, maintain, and execute automated test suites for web, API, integration, and end-to-end testing using industry-standard tools and frameworks.
  • Identify test automation opportunities to maximize coverage, improve efficiency, and support continuous testing initiatives.
  • Collaborate with development and DevOps teams to integrate automated tests into CI/CD pipelines, enabling faster and more reliable software releases.
  • Develop and execute functional, integration, system, regression, and user acceptance testing activities to ensure product quality.
  • Perform basic performance, scalability, and reliability testing to validate application responsiveness and stability under expected workloads.
  • Conduct accessibility testing using automated and manual techniques to ensure applications meet accessibility standards and provide an inclusive user experience.
  • Validate APIs, microservices, cloud-native applications, and distributed systems through comprehensive quality assurance and testing practices.
  • Analyze test results, identify defects, quality risks, and trends, and provide meaningful metrics and reporting to stakeholders.
  • Participate in root cause analysis, defect prevention, and continuous improvement initiatives to enhance overall product quality.
  • Evaluate testing tools, frameworks, and emerging technologies, and contribute to proof-of-concept activities that improve quality engineering capabilities.
  • Create and maintain test documentation, test strategies, standards, and best-practice guidelines.
  • Collaborate closely with Product Owners, Architects, Developers, DevOps Engineers, and Delivery Managers to ensure quality is built into products from design through deployment.

Skills Required:

  • Strong experience in functional, integration, system, regression, and end-to-end testing across web, API, and distributed applications.
  • Good understanding of test automation principles and hands-on experience with tools such as Cypress, Playwright, Selenium (Preferably C#), or equivalent automation frameworks.
  • Solid experience in API testing using Postman, SoapUI, REST API testing tools, API contract testing, and service validation.
  • Experience designing test strategies, test plans, test scenarios, and risk-based testing approaches to ensure comprehensive quality coverage.
  • Proficiency with Git, CI/CD tools including Jenkins, Azure DevOps, GitHub Actions, or GitLab CI, and integrating quality controls within delivery pipelines.
  • Strong understanding of microservices architecture, distributed systems, synchronous/asynchronous integrations, cloud platforms (AWS/Azure), and cloud-native application testing.
  • Experience in non-functional testing areas including performance, accessibility, reliability, resilience, observability, and security testing.
  • Familiarity with Agile/Scrum methodologies and quality management tools such as Jira, Confluence, Azure DevOps, and Test Management solutions.
  • Strong analytical, defect management, root cause analysis, problem-solving, and risk assessment skills with the ability to provide actionable quality insights.
  • Excellent communication, collaboration, stakeholder management, and leadership skills with the ability to drive a quality-first culture across cross-functional teams.
