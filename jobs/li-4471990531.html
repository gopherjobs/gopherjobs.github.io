Integration & API Gateway Developer

We are looking for an experienced Integration & API Gateway Developer to join our Enterprise Integration Platform team. The role will focus on developing, enhancing and supporting enterprise integration services across Oracle Service Bus (OSB) and Broadcom Layer7 API Gateway , including internal and external API integrations.

This is a hands-on development role covering API development, enterprise integration, troubleshooting, testing, deployment and platform enhancements . The successful candidate will also contribute to the organization's transition towards an API-led architecture and leverage approved AI-assisted tools to improve development productivity and quality.

Key Responsibilities

Development & Integration

  • Develop, enhance and maintain Oracle Service Bus (OSB) services and enterprise integrations.
  • Develop and maintain Broadcom Layer7 API Gateway APIs and security policies.
  • Design and implement REST and SOAP integrations , including routing, transformation and orchestration.
  • Integrate APIs with backend systems across the enterprise technology landscape.
  • Implement API security and authentication using OAuth/OAuth2, API keys, SSL/TLS and digital certificates .
  • Perform unit testing, technical validation and debugging of integration services and API policies.
  • Investigate and resolve development defects and integration issues.

Production Support & Enhancement

  • Support OSB and API Gateway platforms , including minor enhancements, fixes and new integration services.
  • Troubleshoot and resolve production incidents, integration defects and performance issues .
  • Support application and platform teams during SIT, UAT and integration testing .
  • Participate in deployment, release and post-production validation activities.
  • Maintain technical documentation, support procedures and operational runbooks.

Automation & DevOps

  • Identify opportunities to automate repetitive development, deployment and support activities.
  • Work with Git, Jenkins and CI/CD pipelines to support efficient software delivery.
  • Support monitoring, logging, alerting and application health checks .
  • Use approved AI-assisted development tools to improve coding, troubleshooting, testing and technical documentation.

Mandatory Requirements

  • 5–7 years of experience in Integration, API Development or Enterprise Integration.
  • Hands-on experience with Oracle Service Bus (OSB) or a similar enterprise integration platform.
  • Experience with Broadcom Layer7 API Gateway or equivalent API management platforms such as Apigee, Kong, MuleSoft, Axway, AWS API Gateway or Azure API Management .
  • Strong hands-on experience with REST, SOAP and API development .
  • Good knowledge of XML, JSON and XQuery/XSLT or equivalent transformation technologies.
  • Strong understanding of API security, OAuth/OAuth2, SSL/TLS and certificate management .
  • Good troubleshooting, debugging and production support skills.
  • Basic knowledge of Linux/Unix and relational databases .
  • Strong communication, documentation and stakeholder management skills.

Preferred Skills

  • Experience with JMS and messaging-based integrations .
  • Understanding of API lifecycle management and API Management concepts .
  • Experience with Git, Jenkins and CI/CD .
  • Exposure to AWS or other cloud platforms .
  • Scripting or automation experience using Python, Shell or similar technologies .
  • Knowledge of Kafka or other event-driven/messaging technologies .
  • Exposure to Docker/Kubernetes and containerised environments.
  • Knowledge of OpenAPI/Swagger and API-first design .
  • Experience using AI-assisted development tools .
  • Experience in banking, insurance, financial services or other regulated environments .
