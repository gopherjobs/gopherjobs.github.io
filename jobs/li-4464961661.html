Role Overview:

We are hiring for one of our clients, seeking a Senior Software Engineer to work on a contract basis. The role involves designing and implementing scalable software solutions for a platform serving global users. Responsibilities include developing and maintaining backend services, optimizing system performance, and collaborating with cross-functional teams to deliver high-quality software.

Key Responsibilities:

• Design, develop, and maintain backend services using modern programming languages and frameworks.

• Optimize system performance to ensure scalability and reliability for a growing user base.

• Collaborate with product managers, designers, and other engineers to define and implement new features.

• Write clean, maintainable, and well-documented code following best practices and coding standards.

• Troubleshoot and resolve issues in production environments to minimize downtime and improve user experience.

Required Skills & Qualifications:

• Proficiency in at least one backend programming language such as Python, Java, or Go.

• Experience with cloud platforms such as AWS, GCP, or Azure.

• Strong understanding of data structures, algorithms, and system design principles.

• Familiarity with databases including SQL and NoSQL systems.

• Experience with containerization and orchestration tools like Docker and Kubernetes.

• Knowledge of CI/CD pipelines and DevOps practices.

• Ability to write unit and integration tests to ensure software reliability.

• Strong problem-solving skills with the ability to work in a fast-paced environment.

More About the Opportunity:

This role offers a unique opportunity to work with a global leader in the Software Development industry, contributing to the development of a platform serving millions of users worldwide. The contract includes flexibility to work from anywhere, with competitive compensation based on experience and expertise.
