Position Overview

We are seeking a Software Engineer II (SE 2) to join our Core Platform team. In this role, you will implement, maintain, and optimize the real-time data pipelines, distributed storage layers, and backend microservices that drive our enterprise AI/ML Platform.

This role is focused on hands-on backend software engineering, real-time distributed systems, and leveraging modern AI development workflows. Working closely with senior engineers, you will write clean, well-tested code using Golang and Python to process high-throughput data streams via Kafka and Apache Spark. You will manage polyglot persistence models, utilizing Apache Cassandra for massive, low-latency event logs and PostgreSQL for relational metadata and transactional flows. We expect our engineers to build efficiently by incorporating AI-assisted development practices into their daily workflows. Applications are deployed and scaled within a cloud-native ecosystem powered by Amazon EKS (Kubernetes) and AWS.

Key Responsibilities

  • Backend Development: Write and maintain robust microservices using Golang for high-performance execution and Python for data processing layers.
  • AI-Assisted Engineering: Accelerate software delivery, code documentation, and unit test generation by effectively incorporating modern AI development practices into your daily programming workflow.
  • Polyglot Data Storage Management:
  • Develop and maintain scalable NoSQL data persistence layers using Apache Cassandra, optimizing data modeling and CQL queries for high-volume storage.
  • Design, query, and optimize relational schemas using PostgreSQL, managing indexes, configuration settings, and transactional data integrity.
  • Stream & Pipeline Implementation: Build and maintain scalable, event-driven data streaming pipelines utilizing Apache Kafka and real-time data processing workflows using Apache Spark.
