Role Overview:

We are looking for a Java Backend Developer to build and maintain REST APIs and microservices. The role involves asynchronous programming, database development, cloud services, and delivery through CI/CD pipelines.

Your responsibilities:

  • Design, develop and maintain backend services using Java 21, Spring Boot and Vert.x.
  • Build, maintain and integrate REST APIs, ensuring they are scalable, reliable and well documented using Swagger/OpenAPI.
  • Develop asynchronous workflows and integrate backend services with internal and external systems.
  • Design, develop and optimise MySQL databases, including supporting deployments and database management using Amazon RDS.
  • Package and containerise applications using Docker.
  • Support automated build, testing and deployment processes through CI/CD pipelines.
  • Use Git and GitLab for version control, code collaboration and source management.
  • Work with Jira to manage development tasks, track progress and support effective delivery across projects.
  • Deploy, monitor and troubleshoot backend services across AWS and GCP environments.
  • Investigate and resolve production issues, identifying root causes and implementing effective solutions to maintain system reliability and performance.
  • Work closely with other engineering and technology teams to support integrations, resolve technical issues and deliver backend solutions.

Technical Requirements:

  • 4–7 years of experience in Java backend development or a similar software engineering role.
  • Strong hands-on experience with Java 21, Spring Boot, REST APIs and microservices.
  • Practical experience with Vert.x and asynchronous programming.
  • Strong understanding of backend application development, API design and service integration.
  • Experience working with MySQL, including database design, optimisation and Amazon RDS.
  • Working knowledge of AWS and GCP cloud environments.
  • Experience with Docker and CI/CD pipelines.
  • Experience using Git, GitLab and Jira within a software development environment.
  • Experience with Swagger/OpenAPI for API documentation.
  • Strong troubleshooting and debugging skills, with the ability to investigate and resolve production issues effectively.
  • Ability to work independently while collaborating effectively with wider engineering and technology teams.
  • Strong communication and problem-solving skills with a proactive approach to identifying and resolving technical issues.
