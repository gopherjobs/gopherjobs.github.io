Senior API & Integration Engineer (E-Wallet, Cloud & AI)

Are you a senior backend engineer who excels at designing complex API orchestration layers and driving strategic cloud migrations? We are looking for a Tech Lead / Senior Engineer to own the API mediation layer, cloud-native evolution, and AI integration for a high-throughput global mobile money platform.

What you will build:

  • API Orchestration & Mediation: Design and implement intelligent mediation layers connecting modern web/mobile apps, telecom networks (USSD/SMS), and core e-wallet ledger engines.
  • Cloud Migration & Architecture: Lead the backend re-architecting of core e-wallet infrastructure, breaking down monolithic systems into scalable, containerized microservices on Kubernetes.
  • AI & LLM Workflows: Build the integration endpoints and application logic for AI capabilities, orchestrating LLM workflows, RAG pipelines, and vector databases into the fintech ecosystem.
  • Fintech Security & Resilience: Write highly concurrent code featuring bulletproof transaction rollbacks (Saga pattern), circuit breakers, and fintech-grade security protocols (mTLS, OAuth2, PCI-DSS).

What we are looking for:

  • Deep mastery of backend development ( Go, Java, Python, or C# ) in high-throughput, low-latency financial or telecom systems.
  • Proven track record in API Architecture & Enterprise Integration Patterns (EIP) , with hands-on experience using orchestration tools (Temporal, Camunda) or custom mediation layers.
  • Strong background in cloud migration (AWS/GCP/Azure), Kubernetes, Docker, and IaC (Terraform/OpenTofu).
  • Expertise in relational databases (PostgreSQL/MySQL) and event-driven streaming (Kafka/RabbitMQ).
  • Exposure to telecom protocols (USSD, SMSC) or enterprise e-wallet engines (Ericsson MFS, Huawei Mobile Money, Telepin) is a major plus.

📍 Location: Remote (Poland)
