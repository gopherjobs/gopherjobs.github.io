Position Summary

At Miovision, we are paving the road for the future of smart transportation, and our Platform Engineering team is the ultimate interchange connecting it all. We are looking for a Senior Software Developer to take the wheel and build our unified API gateway—the high-speed express lane that powers everything from our web apps to our AI-driven workflows. You will act as the master traffic controller for our API ecosystem, ensuring data routes securely, seamlessly, and at scale without hitting a bottleneck. If you are ready to lay the concrete for our unified front door, write high-performance code, and keep our rapidly expanding product ecosystem running on all cylinders, green means go!

Objectives And Responsibilities

  • Build the Gateway: Design, build, scale, and maintain our stateless API gateway, serving as the highly performant front door for all Miovision applications and services.
  • Architect for Scale: Keep architectural boundaries crisp by maintaining domain business logic in owning services, utilizing the platform API layer strictly for routing, access control, and formatting standards.
  • Commercialize the API: Embed usage tracking, billing hooks, tenant-aware access control, and rock-solid observability into the platform from day one.
  • Govern and Standardize: Partner with Architecture, Product, Security, and domain teams to enforce strict API governance, including versioning, backward compatibility, API linting, and contract testing.
  • Enable AI & Automation: Design machine-readable, agent-friendly API contracts that empower our AI chatbot (Mateo), MCP servers, and future AI agents to safely discover and invoke Miovision capabilities.
  • Drive Consensus: Champion cross-team alignment on complex domain modeling, resource naming, and API structures, transforming tough debates into clean, durable API contracts.
  • Publish & Document: Create crystal-clear service catalog entries and developer-friendly documentation so consumers can easily discover, understand, and adopt platform capabilities.
  • Code & Mentor: Roll up your sleeves to write high-quality code (primarily in Kotlin or Go), actively utilize AI-assisted development tools (like AMP), and mentor peers through deep technical design and code reviews.

The Ideal Profile

  • The API Architect: You have successfully designed, deployed, and scaled a centralized API gateway within a highly complex, multi-service production environment.
  • The Domain Modeler: You bring deep experience in Domain-Driven Design (DDD) and API-first methodologies (using OpenAPI), with a proven track record of driving cross-team consensus on complex data structures.
  • The Platform Builder: You know how to take fragmented internal services or APIs and beautifully transform them into a cohesive, commercially ready developer platform or service catalog.
  • The Code Craftsman: You boast expert-level proficiency in Kotlin, perfectly paired with extensive hands-on experience in cloud-native ecosystems including Kubernetes, Docker, and AWS.
  • The Security Sentinel: You have successfully implemented and enforced robust authentication and authorization patterns at the edge, utilizing modern protocols like OIDC, OAuth 2.0, and platforms like Auth0.
  • The AI Enthusiast: You demonstrate a strong understanding of—or a highly active interest in—how AI agents, LLMs, and frameworks like MCP (Model Context Protocol) interact seamlessly and securely with APIs.
