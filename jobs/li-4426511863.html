Position Overview This role ensures the quality and reliability of Netwrix Privilege Secure Discovery product, Netwrix's on-prem privileged access management platform. The SDET builds and owns test automation, quality infrastructure, and CI gates across the API, worker, and web tiers, working closely with engineers on design reviews and with the system-tests/emulator environment that validates real target-system behavior (Windows/Linux/RADIUS).

Key Responsibilities

  • Design, build, and maintain automated test suites (unit, integration, system/E2E) for the Node/Express API, Python worker services, and AngularJS web UI
  • Own and expand test coverage and quality gates (lint, unit, integration, system tests) in the Docker Compose–based CI pipeline
  • Maintain and extend the pytest-based system-tests suite that runs against emulated Windows/Linux systems and RADIUS
  • Write test infrastructure covering MongoDB and PostgreSQL data layers, including migrations and data integrity checks
  • Participate in technical design discussions to identify testability gaps and quality risks early
  • Investigate, triage, and root-cause test failures and production defects; drive fixes to closure with development
  • Develop test coverage for privileged-access workflows: credential rotation, session management, discovery/classification of privileged accounts
  • Champion test strategy, coverage metrics, and quality standards across the team

Required Skills

  • 5+ years of professional experience in software test automation or SDET roles
  • Proficiency in Python (pytest) and JavaScript/Node.js for writing test automation
  • Hands-on experience with REST API testing and test framework design
  • Experience testing against MongoDB and/or PostgreSQL (schema validation, data integrity, queries)
  • Proficiency with Docker/Docker Compose for building and running test environments
  • Strong debugging, root-cause analysis, and problem-solving skills

DevOps
