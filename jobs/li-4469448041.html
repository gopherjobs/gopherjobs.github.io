Overview Of The Role Flutter Functions' AI & Automation team is seeking a talented and curious AI Developer to join our mission of building next-generation enterprise AI solutions that transform how our global workforce operates. You'll play a central role in developing and evolving Flutter's enterprise AI assistant and agent platforms — intelligent systems that leverage our vast internal data assets to enhance productivity and decision-making across our sports betting and gaming operations.

As part of an industry-leading team, you'll contribute to intelligent solutions that serve over 20 million customers across 20+ regulated markets, working in a hybrid environment that blends the flexibility of remote work with collaboration in our modern Hyderabad offices.

What You'll Do

  • Enterprise AI Platform Development: Design, build, and evolve Flutter's enterprise AI assistant and multi-agent platforms, creating intelligent systems that integrate seamlessly with internal applications, data sources, and workflows across the organisation.
  • LLM Inference & Integration: Work hands-on with LLM inference systems — including LiteLLM and AWS Bedrock — to build responsive, scalable, and cost-efficient AI applications, navigating model selection, routing, and deployment trade-offs.
  • Context Engineering & Prompt Architecture: Go beyond basic prompt engineering to architect sophisticated context pipelines — designing retrieval strategies, memory systems, and context windows that maximise model performance within real-world constraints.
  • Model Tokenomics & Performance Trade-offs: Apply a deep understanding of token economics — balancing latency, cost, context length, and model capability to make informed architectural decisions across production AI systems.
  • Guardrails & Safety Systems: Implement robust model constraint and guardrail frameworks to ensure AI outputs are safe, compliant, and aligned with Flutter's Responsible AI Policy and regulatory obligations across 20+ markets.
  • Agentic AI Development: Build and deploy sophisticated agent architectures using frameworks such as LangChain, LangGraph, Strands, ADK (Agent Development Kit) , and similar tools — creating multi-step reasoning systems, tool-using agents, and orchestration layers that solve complex enterprise problems.
  • Full-Stack AI Solutions: Deliver end-to-end AI applications, owning the problem from model integration through backend services to user-facing interfaces — demonstrating the ability to work across the full stack when the problem demands it.
  • API & Integration Development: Design and implement integrations using AWS services (Bedrock, Lambda, API Gateway) and modern protocols including Model Context Protocol (MCP) and REST/streaming APIs.
  • Security-First Development: Bring a security-oriented mindset to all AI development — considering prompt injection risks, data leakage vectors, authentication flows (OAuth, JWT), access control, and safe handling of sensitive enterprise data from the ground up.
  • AI-Augmented Engineering Practices: Embrace and champion agentic development practices, using tools such as Claude Code, OpenCode, GitHub Copilot , and similar AI coding assistants to accelerate delivery, improve code quality, and explore new approaches to software development.
  • Cross-Functional Collaboration: Partner with product managers, data scientists, and engineering teams across Flutter's global organisation to deliver AI solutions that drive measurable business impact.

What You'll Need

  • Education & Experience: Bachelor's degree in Computer Science, AI, or a related STEM field, with 3–4 years of hands-on AI/ML or software development experience.
  • Core Python Skills: Solid Python proficiency, including experience with frameworks such as FastAPI or Flask, async programming patterns, and clean, maintainable code practices.
  • LLM Inference Systems: Practical experience working with LLM inference platforms — particularly AWS Bedrock and/or LiteLLM — including model routing, API integration, and managing inference at scale.
  • Context Engineering: Demonstrated understanding of context window management, retrieval-augmented generation (RAG), prompt structuring, and the trade-offs involved in designing effective context pipelines.
  • Model Tokenomics Awareness: Ability to reason about token costs, latency, context limits, and model capability differences when making architectural and design decisions.
  • Agentic AI Frameworks: Working knowledge of at least one agent framework such as LangChain, LangGraph, Strands, or Google ADK , with an understanding of agent orchestration patterns, tool use, and multi-agent coordination.
  • Guardrails & Responsible AI: Familiarity with model constraint mechanisms, content filtering, guardrail systems, and responsible AI principles as applied in production environments.
  • Security-Oriented Mindset: Genuine awareness of AI-specific security risks — including prompt injection, data exfiltration, and misuse vectors — alongside standard software security practices (OAuth, JWT, least-privilege design).
  • AI-Augmented Development: Comfortable using AI coding tools (e.g. Claude Code, GitHub Copilot, OpenCode ) as genuine productivity multipliers, not just as novelties — with an understanding of how to validate and own AI-generated code.
  • Development Fundamentals: Solid understanding of the software development lifecycle, version control with Git, API design principles, and collaborative engineering workflows.
  • Communication Skills: Able to work effectively in cross-functional teams and articulate complex technical concepts clearly to both technical and non-technical stakeholders.

Highly Desirable Skills

  • Full-Stack Experience: Demonstrated ability to work across the full stack — experience with React, TypeScript , and modern frontend patterns alongside backend and AI integration work, with examples of end-to-end problem ownership.
  • Advanced Agent Frameworks: Deeper experience across multiple agentic frameworks (LangChain, LangGraph, Strands, ADK, CrewAI) and an understanding of the architectural trade-offs between them.
  • Vector Databases & RAG Systems: Experience designing and implementing retrieval systems using vector databases (e.g. Pinecone, pgvector, OpenSearch) as part of production RAG architectures.
  • Model Context Protocol (MCP): Understanding of MCP and its role in standardising tool and context integration across modern AI agent systems.
  • Regulated Environment Experience: Familiarity with the gaming, sports betting, or financial services industry, or prior experience working within regulated technology environments where compliance and safety are non-negotiable.
  • Curiosity & Adaptability: A genuine appetite for staying at the leading edge of AI development — comfortable with rapid technological change, eager to explore emerging tools and frameworks, and able to form and share informed opinions on where the field is heading.
