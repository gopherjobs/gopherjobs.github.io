Description

Procom is searching for a Platform & Integration Software Engineer for a permanent, full-time role.

This can be a remote or hybrid position (Toronto, Ontario).

This intermediate-level, hands-on role will build the APIs, data contracts, and enterprise integrations that connect a new document-extraction and validation pipeline to production systems. The engineer will independently deliver well-defined integrations; design the services that move documents from intake through processing, review, and export; and make sure downstream systems can rely on stable, well-documented interfaces. The engineer will work closely with the Document Intelligence & AI Engineer on architecture, cross-system decisions, and translating discovery findings into secure, testable, maintainable software.

Responsibilities:

  • Design and implement APIs and service interfaces for document-package submission, processing status, results, validation, review actions, and export.
  • Define stable data contracts covering documents, extracted fields, source evidence, confidence indicators, validation results, and corrections.
  • Build integration adapters that reduce dependency on any one processing provider's internal data structures.
  • Select and implement the right processing and recovery patterns – queues, retries, sync vs. async – based on actual volume, latency, and availability needs.
  • Persist original machine output separately from corrected values, reviewer decisions, reason codes, and audit events.
  • Integrate with applicable enterprise systems, including application platforms (e.g., Salesforce), document repositories, storage, and identity services.
  • Apply practical security, privacy, least-privilege, and encryption practices appropriate for sensitive financial documents and PII.
  • Contribute to automated testing, deployment, configuration management, logging, and monitoring.

Mandatory Skills:

  • Demonstrated experience building production APIs, services, or data-processing integrations, using modern languages such as Python, Java, or C#/.NET – strong Python capability preferred.
  • Experience designing data contracts, authentication schemes, and error handling for enterprise integrations.
  • Working knowledge of reliability patterns (queues, retries, sync vs. async tradeoffs) and sound judgment on when each is warranted.
  • Experience implementing security and least-privilege practices for sensitive data.
  • Strong collaboration skills – comfortable partnering with a document-intelligence/AI specialist and a range of business, security, and infrastructure stakeholders.

Nice-to-Have Skills:

  • Experience with document processing, OCR, or content-services platforms.
  • Familiarity with IBM watsonx or Unstructured.io.
  • Salesforce integration experience.
  • Experience in regulated, PII-intensive environments such as finance, insurance, or healthcare.
