Senior Python Engineer (A2A Integration)

Location: Remote from Spain (an indefinite Spanish employment contract)

We are looking for a Senior Python Backend Engineer to build and integrate agent-to-agent communication capabilities on AWS AgentCore platforms. The role focuses on Python backend development, A2A protocol implementation, agent discovery and registration, event-driven communication, and scalable multi-agent interactions. The ideal candidate has strong backend engineering experience, expertise in asynchronous systems, and hands-on knowledge of modern API and agent integration patterns.

Project Overview:

Our customer is a multinational corporation with more than a century of history and offices in over 180 countries. Their most ambitious goal at the time is to introduce a range of Reduced-Risk Products (RRPs). The target audience is more than 1 billion consumers around the globe. IT platform hosts 700+ applications.

Intellia's mission is to help the client with the engineering of a comprehensive software ecosystem for a game-changing IoT product on the margin of innovative consumer experience and cutting-edge technology. Our teams are involved in the engineering of core platform components for best-in-class eCommerce, Digital Marketing and IoT solutions. As an Engineer, you will become a part of Core Architecture Team and be responsible for the architecture, implementation of best practices in our Digital Engineering Enterprise Platform.

The Platform is a set of services and internet applications that accelerate the development and delivery of software applications by taking care of common SDLC challenges. The Platform provides access and consumption for engineering teams to a set of services, technologies, practices for their development and for operating their application, ensuring a set of compliance and best practices.

Requirements:

• 5+ years Python or Go backend engineering

• API integration and routing

• Agent or microservice communication patterns

• REST API implementation (building endpoints, not just consuming them)

• Understanding of async/event-driven patterns (SSE, webhooks)

• Python (async, AgentCore SDK, REST)

• AWS AgentCore Runtime and Gateway (agent card registration, target configuration)

• A2A agent invocation patterns (caller and target template integration)

• A2A protocol wire format (JSON-RPC 2.0, SSE task lifecycle events, push notifications)

• Agent Card JSON schema authoring and /.well-known/agent.json endpoint implementation

Will be a plus:

• AWS AgentCore Gateway template integration validation

• AWS Bedrock multi-agent invocation patterns

• SSE event streaming (task lifecycle events, push notifications)

• OpenTelemetry trace propagation across A2A agent hops (ADOT)

Responsibilities:

  • Design and implement backend services using Python and AWS AgentCore SDK.
  • Build and maintain A2A integrations using AWS AgentCore Runtime and Gateway.
  • Implement agent registration, target configuration, and agent discovery workflows.
  • Develop and maintain Agent Card definitions and .well-known/agent.json endpoints.
  • Implement A2A communication patterns using JSON-RPC 2.0 and event-driven architectures.
  • Design and support agent invocation workflows between caller and target agents.
  • Build asynchronous communication flows using SSE, webhooks, and push notifications.
  • Develop REST APIs and backend services that enable reliable agent interaction and routing.
  • Implement event lifecycle handling, task status tracking, and agent execution monitoring.
  • Ensure secure and scalable communication between distributed agents and services.
  • Collaborate with AI, platform, and security teams to support multi-agent ecosystem integration.
  • Troubleshoot, test, and optimize backend services for performance, reliability, and scalability.
  • Produce technical documentation for integration standards, APIs, and agent connectivity patterns.
