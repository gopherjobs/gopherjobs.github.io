Senior Software Engineer - Java, React & AWS - Contract Build software that matters. Shape the future of engineering.

We’re looking for an experienced Senior Software Engineer - Java, React & AWS who is passionate about building scalable, high-quality software and helping teams grow. This is more than a hands-on engineering role. You’ll influence technical direction, mentor other engineers, drive architectural decisions, and help us embed AI and automation into the way we deliver value for our clients.

You’ll thrive here if you enjoy solving complex problems, challenging assumptions, collaborating openly, and taking pride in delivering software that makes a real business impact.

What You’ll Do As a Senior Software Engineer - Java, React & AWS, you will:

  • Design, build and maintain scalable, secure and resilient applications, from backend services using modern Java and the Spring ecosystem to responsive, accessible front ends built with React.
  • Build and run cloud-native services on AWS, using Lambda, S3, RDS and CloudWatch to deliver solutions that are secure, observable and cost-effective.
  • Lead technical design and architectural discussions, ensuring solutions are maintainable, performant and aligned with best practices.
  • Develop and evolve RESTful APIs with a focus on security, versioning, performance and reliability, and integrate them seamlessly with React applications.
  • Champion engineering excellence through clean code, automated testing, documentation and code reviews.
  • Drive delivery across multiple initiatives while balancing speed, quality and commercial value.
  • Mentor engineers through coaching, pairing and constructive feedback, helping raise capability across the team.
  • Collaborate with cross-functional teams to solve problems together and deliver outstanding outcomes for clients.
  • Research and evaluate emerging technologies, frameworks and AI capabilities that improve how we build software.
  • Promote automation wherever possible, removing repetitive work so teams can focus on solving meaningful problems.
  • Contribute to a culture of continuous learning, innovation and technical excellence.

What You’ll Bring Technical Expertise You’ll Have Strong Commercial Experience With

  • Modern Java (Java 8+) including Streams, Lambdas and Optional
  • Spring Boot and the wider Spring ecosystem
  • React, including hooks, component design and state management
  • JavaScript and TypeScript
  • Spring Data JPA / Hibernate
  • Spring Security including OAuth2 and JWT
  • REST API design and implementation
  • Microservices and distributed system design
  • SQL databases with strong query optimisation skills
  • NoSQL databases
  • Messaging technologies such as Kafka or RabbitMQ
  • Docker and containerised application development
  • CI/CD pipelines using tools such as Jenkins or GitLab CI
  • Git and modern software development workflows
  • Observability tooling including logging, metrics and distributed tracing
  • Comprehensive testing across unit, integration and functional layers, including front-end testing with tools such as Jest and React Testing Library
  • Maven or Gradle
  • Java concurrency and JVM performance fundamentals

AWS You’ll have hands-on experience building and running production workloads on AWS, including:

  • AWS Lambda: designing event-driven, serverless functions triggered from API Gateway, S3, SQS or EventBridge, including running Java on Lambda and reducing cold starts (for example with SnapStart)
  • Amazon S3: bucket design, access control, lifecycle policies and event notifications
  • Amazon RDS (PostgreSQL or MySQL): connection management, read replicas, backup and restore, and performance tuning
  • Amazon CloudWatch: structured logging, custom metrics, dashboards and alarms, and using Logs Insights to diagnose production issues
  • IAM: least-privilege access for services and people
  • Infrastructure as Code: CloudFormation, CDK or Terraform

Experience With The Following Would Be Advantageous

  • Python, Next.js, Spring Cloud, WebFlux or reactive programming
  • Amazon Bedrock: integrating foundation models into applications, including prompt design, retrieval-augmented generation (Knowledge Bases) and guardrails
  • Amazon Bedrock AgentCore: building, deploying and running AI agents in production, including runtime, memory, tool integration and observability
  • Amazon SageMaker: deploying, hosting or integrating machine learning models into applications
  • Snowflake or Databricks: building data integrations between AWS services and modern data platforms
