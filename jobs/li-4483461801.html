The project and the team

We develop modern Software Defined WAN (SD-WAN) and Network Operating systems-based solutions for the leading networking equipment manufacturers. We work with cloud-native, containerized software and services, as well as with user-space and kernel-space drivers for advanced network equipment such as switches, routers, and smart network interface cards (smartNICs).

What else you should know:

  • The team consists of developers, QA automation, and DevOps engineers
  • We often work using client-supplied hardware and tools
  • Our projects may be managed by our EMs or directly by the client
  • We use the Agile approach (kanban/scrum) whenever possible
  • We work with clients from the US and Europe

Your role

As a part of the project team, you will be responsible for:

  • Developing test automation using Python
  • Developing UI test automation using Playwright
  • Contribute to Python-based test framework functionalities
  • Designing and automating new environment configurations to extend existing testbed capabilities
  • Working with client’s architects to ensure that your validation methods meet their expectations
  • Maintaining project documentation in Confluence

Do we have a match?

As QA Engineer with Networking and UI automation, you must meet most of the following criteria:

  • Have Python programming skills & experience with Python test frameworks (e.g. PyTest, PyATS)
  • Hands-on expertise and practical understanding of UI automation, ideally with Playwright
  • Practical use of AI-powered tools to accelerate test automation development, test design, code review, and troubleshooting activities.
  • Experience with SD-WAN
  • Advanced knowledge of computer networking, including switching and routing at Cisco CCNA level, extended by hands-on expertise in advanced routing protocols (BGP, iBGP, eBGP), ECMP, link aggregation technologies, and tunnelling solutions such as VXLAN, GRE, and VPNs.
  • Experience in working with Linux and Git
  • Have Experience with CI/CD tools and processes
  • English (B2 level at minimum, but preferably C1 or C2)

Beyond the criteria above, we would appreciate the nice-to-haves:

  • Cisco CCNP certification or equivalent knowledge
  • Experience in configuring network hardware (routers, switches, NICs)
  • Experience with handling traffic generators such as IXIA and/or Spirent
  • Knowledge of network tools with an emphasis on network virtualization (OVS, GoBGP, FRRouting, etc.)
  • Understanding of virtualization technologies (Containers, Virtual Machines, Orchestrators, virtual networks) with emphasis on Docker, KVM, OpenStack, and Kubernetes
