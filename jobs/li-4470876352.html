About the Opportunity

micro1 is seeking Application Security Engineers (AppSec) to help train next-generation AI systems through high-quality, real-world software engineering and cybersecurity tasks.

In this role, you'll use your expertise in backend development, application security, debugging, and software engineering to create realistic and challenging coding tasks for AI systems. You’ll also develop deterministic verifiers that accept reasonable valid solutions while rejecting incorrect implementations.

No prior AI experience is required — your technical and cybersecurity expertise is what matters.

Key Responsibilities

  • Create realistic and challenging coding tasks involving feature implementation and bug fixes.
  • Develop and implement deterministic verifiers to evaluate AI-generated solutions.
  • Work with backend technologies including Java, Node.js, Go, Rust, TypeScript, Python, and C++ or similar languages.
  • Build and evaluate scalable services and APIs .
  • Perform debugging, performance optimization, and automated testing .
  • Review code and identify issues related to quality, security, maintainability, and performance .
  • Apply secure coding and application security principles to software engineering tasks.
  • Identify and address vulnerabilities, security risks, and system bottlenecks .
  • Refactor codebases and implement complex features across large-scale applications.
  • Provide clear technical reasoning and high-quality solutions that can help improve AI model performance and reliability .

Required Qualifications

  • Strong backend development experience with Java, Node.js, Go, Rust, TypeScript, Python, C++ , or similar technologies.
  • Experience building scalable services and APIs .
  • Strong debugging and performance optimization skills.
  • Experience with automated testing and software quality practices.
  • Strong code review and software engineering judgment .
  • Solid understanding of algorithms, data structures, and foundational computer science concepts .
  • Strong analytical, problem-solving, and technical communication skills .

Preferred Qualifications

  • Professional background in cybersecurity, Application Security (AppSec), or SecOps .
  • Experience with penetration testing, vulnerability assessment, security audits, or security-focused code reviews .
  • Familiarity with OWASP and CWE or similar security frameworks.
  • Proven ability to identify and resolve software bugs and system bottlenecks .
  • Experience with codebase refactoring and implementing complex features in large-scale applications.
  • Experience with secure coding practices and vulnerability remediation .
