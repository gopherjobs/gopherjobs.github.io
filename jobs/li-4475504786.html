Do našeho DevSecOps týmu hledáme posilu, která se bude věnovat především vývoji webových aplikací v Pythonu a zároveň jí nejsou cizí ani témata jako CI/CD, kontejnerizace nebo security.

Nemusíš být expert(ka) – hledáme především někoho, kdo má dobrý technický základ, aktivně využívá AI nástroje, dokáže převzít odpovědnost a pracovat samostatně.

Pokud tě láká prostředí, kde se učíš praxí, čti dál!

Čemu se budeš věnovat:

  • Vývoji backendu webových aplikací v Pythonu a návrhu REST API
  • Návrhu datových modelů a práci s databází MongoDB
  • Zpracování a generování tabulkových dokumentů
  • Automatizaci vývoje, testování a nasazování
  • Řešení problémů napříč backendem, frontendem, databází i provozním prostředím

Budeme si rozumět, pokud:

  • Máš praktické zkušenosti s Pythonem a backendovým vývojem webových aplikací
  • Znáš Django nebo obdobný Python framework a rozumíš návrhu REST API
  • Umíš pracovat se strukturovanými daty (validace, serializace, tabulkové dokumenty)
  • Už jsi pracoval(a) s dokumentovou databází (ideálně MongoDB) a zvládneš navrhnout datový model i efektivní dotazy
  • Ovládáš velmi dobře Git včetně týmového workflow a dokážeš automatizovat vývoj, testování i nasazování
  • Prakticky používáš Docker ke kontejnerizaci aplikací a pohybuješ se v Linuxu/Unixu (stačí i WSL)
  • Orientuješ se v CI/CD a principech DevSecOps a zajímá tě bezpečnost aplikací, závislostí, konfigurace i citlivých údajů
  • AI nástroje využíváš jako pomocníka k vyšší efektivitě, ne jako náhradu vlastní práce – rozumíš tomu, co s AI vytváříš, a odpovídáš za finální výsledek
