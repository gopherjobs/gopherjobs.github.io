About the Opportunity

micro1 is engaging expert Senior Software Engineers to support a customer project focused on training and improving next-generation AI systems.

In this role, you will apply your software engineering expertise to create Reinforcement Learning (RL) environments that evaluate AI models on complex software engineering problems involving bug fixing, feature implementation, code refactoring, and performance optimization. You will create reproducible environments and golden reference solutions that enable consistent and reliable evaluation.

Prior AI experience is not required —your software engineering expertise and technical judgment are the primary focus.

Responsibilities

  • Create realistic and challenging software engineering tasks for AI models to solve.
  • Develop reproducible Reinforcement Learning environments for evaluating software engineering capabilities.
  • Create golden reference solutions that provide reliable benchmarks for AI-generated implementations.
  • Contribute expert-level code samples, debugging strategies, and development insights across Python3, Java, Rust, Go, C++, and TypeScript.
  • Analyze, troubleshoot, and resolve complex software defects and performance bottlenecks.
  • Implement robust features while maintaining scalability, reliability, and software engineering best practices.
  • Refactor and optimize legacy code to improve clarity, efficiency, maintainability, and long-term reliability.
  • Review and validate peer-contributed code and technical submissions for correctness and clarity.
  • Document technical reasoning, solution approaches, implementation decisions, and edge cases.
  • Provide high-quality technical input to improve AI training and evaluation datasets.
