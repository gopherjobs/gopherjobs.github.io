Description

NextLink Group is seeking an experienced Software Engineer – EKG Semantic Layer & MCP Server to join a strategic enterprise AI and data platform initiative for a leading global pharmaceutical client.

You will play a key role in developing and operating an Enterprise Knowledge Graph (EKG) platform, connecting semantic models, AI Agents, Large Language Models (LLMs), and enterprise data platforms. The objective is to enable business users to ask complex, cross-domain questions in natural language and receive trusted, governed answers without writing SQL.

Duration: Long-term contract

Location: Spain and Poland

Work Type: Remote

Rate: 320 - 380 Euros per day (all -inclusive)

🔑 Key Responsibilities

  • Own the architecture, development, scalability, and reliability of the EKG Semantic Layer's MCP Server.
  • Develop and maintain Python-based backend services using FastAPI and REST APIs.
  • Optimise SPARQL queries, multi-hop graph traversals, and caching mechanisms for high-performance responses.
  • Develop semantic models using OWL, RDF, SKOS, SHACL, and R2RML technologies.
  • Integrate AI Agents and LLMs with enterprise knowledge graphs and data platforms.
  • Manage CI/CD deployments across OpenShift environments and implement automated testing.
  • Implement enterprise security controls, including OAuth 2.0, OIDC, RBAC, and On-behalf-Of authentication.
  • Ensure API performance, monitoring, structured logging, and operational reliability.

🎯 What We're Looking For

  • Experience: 5+ years of professional software engineering experience developing and operating production backend services.
  • Python Expertise: Strong hands-on experience with Python 3, FastAPI, Pydantic, async/await, REST APIs, and microservices architecture.
  • Knowledge Graphs: Practical experience with RDF data modelling, SPARQL, graph databases, and multi-hop graph traversals.
  • Cloud & DevOps: Experience with Docker/Podman, OpenShift/Kubernetes, Git, Jenkins or equivalent CI/CD tools, Linux, and Terraform.
  • Data Platforms: Strong SQL skills and experience with Snowflake or comparable cloud data warehouses.
  • Security: Knowledge of OAuth 2.0, OIDC, RBAC, API security, caching, and performance optimisation.
  • Communication: Fluent written and spoken English, with the ability to work independently and collaborate within international Agile/Scrum teams.

⭐ Nice to Have

  • Experience developing Model Context Protocol (MCP) Servers .
  • Familiarity with LLM tool-calling and Text-to-SQL.
  • Exposure to Agentic AI and enterprise conversational analytics solutions.
