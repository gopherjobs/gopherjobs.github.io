Buscamos un/a Senior Frontend Developer con sólida experiencia en la construcción de aplicaciones web modernas utilizando al menos uno de los principales frameworks JavaScript: Angular, React o Vue.js. La persona deberá contar con un dominio sólido de JavaScript, TypeScript, HTML y CSS, así como experiencia en arquitectura frontend, integración con APIs, testing, rendimiento, accesibilidad, seguridad y ciclo de vida del software.

El rol requiere autonomía, capacidad para asumir ownership técnico de funcionalidades o áreas del frontend, aportar ideas, proponer mejoras y participar activamente en decisiones de diseño y arquitectura. También deberá colaborar con equipos multidisciplinares y clientes, realizar estimaciones, identificar riesgos, mentorizar a otros profesionales y contribuir al crecimiento y a la calidad del equipo.

¿Cuál es el reto?

  • Colaborar con responsables funcionales, UX/UI, arquitectura, backend, QA y otros equipos para entender los requisitos del proyecto y traducirlos en soluciones técnicas viables.
  • Diseñar, desarrollar y mantener aplicaciones web modernas y de alta calidad utilizando Angular, React o Vue.js, junto con JavaScript y TypeScript.
  • Participar en el diseño técnico de nuevas funcionalidades y arquitecturas frontend escalables, incluyendo microfrontends cuando el contexto lo justifique.
  • Desarrollar componentes reutilizables, librerías compartidas y Design Systems, utilizando Storybook o herramientas equivalentes.
  • Personalizar interfaces y funcionalidades según las necesidades del cliente, manteniendo criterios de usabilidad, accesibilidad, rendimiento, seguridad y mantenibilidad.
  • Definir e implementar la integración del frontend con APIs REST y, cuando aplique, GraphQL, colaborando con backend en contratos, modelos de datos, autenticación y gestión de errores.
  • Aplicar patrones de gestión de estado adecuados, como Redux, Context, NgRx, Zustand o equivalentes, según el framework y las necesidades de la solución.
  • Asegurar la calidad mediante clean code, análisis estático, pull requests, code reviews y pruebas unitarias, de integración y end-to-end con herramientas como Jest, Vitest, React Testing Library, Cypress o Playwright.
  • Optimizar tiempos de carga, renderizado, bundle size y Core Web Vitals, y garantizar funcionamiento responsivo y compatibilidad entre navegadores.
  • Aplicar estándares de accesibilidad WCAG y buenas prácticas de seguridad frontend, incluyendo prevención de XSS y CSRF, consumo seguro de APIs y gestión adecuada de sesiones y tokens.
  • Participar en procesos de integración y despliegue continuo, observabilidad, monitorización y gestión de errores en producción.
  • Analizar incidencias, realizar diagnóstico de causa raíz y proponer soluciones sostenibles que reduzcan recurrencias y deuda técnica.
  • Participar en la planificación, estimación y seguimiento de iniciativas, identificando dependencias, riesgos e impactos técnicos.
  • Utilizar de forma responsable herramientas de IA generativa para mejorar la productividad y la calidad del desarrollo, manteniendo siempre revisión humana y criterio técnico sobre el resultado.
  • Utilizar GitHub Copilot o herramientas equivalentes para generación, explicación, refactorización, documentación y pruebas de código, proporcionando instrucciones y contexto adecuados.
  • Revisar críticamente las sugerencias generadas por IA y validar su corrección funcional, seguridad, rendimiento, accesibilidad y mantenibilidad antes de incorporarlas a la solución.
  • Cumplir las políticas corporativas y del cliente sobre IA, confidencialidad, propiedad intelectual, datos personales, credenciales y uso de código autorizado.
  • Guiar y mentorizar a otros miembros del equipo, compartir conocimiento y promover estándares de ingeniería comunes.
  • Mantenerse al día en tendencias, herramientas y prácticas frontend y de desarrollo asistido por IA, evaluando su aplicabilidad y valor para los proyectos..
