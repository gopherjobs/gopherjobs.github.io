Staff Software Engineer - Agentic Development & AI-Augmented Engineering

About the Role:

We're looking for a Staff Software Engineer who can define and scale how our engineering organization builds simulation software with AI agents. This role requires deep fluency in "loop engineering" with tools like Claude Code: designing the feedback loops, guardrails, and workflows that let AI agents safely and effectively contribute to production codebases. You'll need to understand the full agentic software development lifecycle, from context design through evaluation, deployment, and observability, while also being a hands-on expert across our core stack.

This is a staff-level role: you'll collaborate with Other engineers to set technical direction, define best practices for agentic development across teams, and remain deeply hands-on in architecture and code.

Responsibilities:

  • Design and implement "loop engineering" workflows using Claude Code and similar tools, defining how agents plan, execute, test, and iterate on code changes

  • Architect Model Context Protocol (MCP) servers and tool schemas that are legible and safe for LLM agents to use

  • Define human-in-the-loop checkpoints, autonomy boundaries, and rollback strategies for agent-driven changes

  • Build evaluation harnesses and observability practices to measure agent output quality and catch regressions

  • Design and review microservice and microfrontend architecture using C4 diagrams and Domain-Driven Design principles

  • Drive test-driven development practices across teams, including contract testing between services

  • Own technical decisions across our Java microservices, Node.js services, React/microfrontend UI, and Python tooling
