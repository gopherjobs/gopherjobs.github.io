Description

Únete a un entorno internacional y puntero, donde tu trabajo sostiene servicios críticos sobre AWS.

Lo que harás

🔹 Diseñar, construir y mantener infraestructura en AWS (Lambda, ECS, API Gateway, S3).

🔹 Trabajar networking AWS avanzado: Transit Gateway, VPC (subnets, route tables, peering), PrivateLink, Route 53, ELB, NAT Gateway, Security Groups/NACLs.

🔹 Automatizar despliegues con pipelines CI/CD (GitHub Actions, GitLab CI, AWS CodeBuild).

🔹 Definir infraestructura como código con CDK y CloudFormation.

🔹 Asegurar la observabilidad de la plataforma con Grafana y Datadog.

🔹 Automatizar y integrar herramientas (GitHub Enterprise, APIs de Atlassian, bots de Slack).

🔹 Trabajar sobre arquitecturas event-driven y microservicios.

Requisitos principales

🔸 Experiencia sólida como DevOps / SRE / Platform Engineer .

🔸 AWS avanzado con fuerte componente de networking .

🔸 Python y Bash imprescindibles; Node.js o Go a nivel de trabajo.

🔸 Dominio de CI/CD e IaC (CDK/CloudFormation).

🔸 Inglés fluido (cliente UK) — imprescindible.

🔸 Experiencia con arquitecturas event-driven y microservicios .
