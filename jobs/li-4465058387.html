Job Title: Senior Backend Engineer - Node.js , Java & Kafka

Location: 100% Remote, Canada

Job Type: T4 Contract

Experience: 7-10 Years

Rate: CAD 70 to 80 per hour

Role Overview

We are looking for a strong Senior Backend Engineer with deep hands-on experience in Java, Apache Kafka, AWS , distributed systems, and data-processing platforms .

The project operates across a modern cloud and data ecosystem including Java, Apache Flink, Apache Spark, Apache Iceberg, Snowflake, Kafka, AWS , and Node.js / TypeScript .

This is a hands-on engineering role requiring strong backend development, data-pipeline experience, system design, production troubleshooting, and technical ownership.

Key Responsibilities

  • Design and develop scalable backend services and distributed applications using Java .
  • Build and support Kafka-based event-driven systems and data pipelines .
  • Develop and maintain streaming and large-scale data-processing solutions using technologies such as Apache Flink and Apache Spark .
  • Work with Snowflake, Apache Iceberg, and modern data lake/lakehouse architectures .
  • Design and operate cloud-native services and data solutions on AWS .
  • Build and support REST APIs , microservices, and integrations across Java- and Node.js / TypeScript -based services .
  • Participate in system design and make technical trade-offs across scalability, performance, reliability, security, and cost.
  • Monitor and troubleshoot production applications, pipelines, and distributed systems using Splunk and related observability tools.
  • Contribute to automated testing, CI/CD, production support, and application reliability.
  • Provide technical guidance and collaborate with engineering, data, DevOps, SRE, security, and product teams.

Must-Have Skills

  • 7–10 years of software engineering experience
  • Strong hands-on Java
  • Strong Apache Kafka
  • AWS / cloud-native development
  • Distributed systems and event-driven architecture
  • Experience building or supporting data pipelines / large-scale data processing
  • REST APIs and microservices
  • System design and architecture
  • SQL and database technologies
  • Production troubleshooting and root-cause analysis
  • Hands-on experience with Splunk or comparable production monitoring/log-analysis tools
  • Experience working across interconnected backend, data, and cloud platforms

Strongly Preferred Skills

  • Apache Flink
  • Apache Spark
  • Snowflake
  • Apache Iceberg
  • Spring Boot / Spring Framework
  • Data lake / lakehouse architectures
  • Node.js / TypeScript
  • Dynatrace and/or New Relic
  • Docker / Kubernetes
  • CI/CD
  • Terraform / Infrastructure as Code
  • OpenTelemetry / Grafana / Prometheus
  • SRE / observability practices

This is primarily a hands-on individual contributor role with technical leadership responsibilities .
