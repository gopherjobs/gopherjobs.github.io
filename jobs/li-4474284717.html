Fully Remote - Full Stack Engineer

Candidates must live in and have the right to work in Germany

A Full Stack role that asks you to build the product layer.

You'd be joining an early stage team building proactive, AI native applications — the kind of software that handles errands, organising and multi-step workflows on its own.

Over 5 billion people use basic tools like email, notes and calendars every day, and almost none of those tools think for themselves.

That's the gap this team is closing, and the engineering problem underneath it is genuinely hard: getting agents to plan, use tools, fail, recover and still deliver something the user can trust.

You'd own the product layer end to end — frontend, backend and the AI integrations that connect them.

That means designing how agents behave when things go wrong, not just when they go right. You'll build real-time interactions with streaming and partial results under tight latency constraints, integrate LLMs, memory and external tools into systems that hold up under real world conditions, and build the fallback and recovery logic that keeps a multi step workflow from quietly falling apart.

You'll work closely with ML, backend and product.

You'll need:

  • Strong full-stack experience across frontend and backend
  • Solid system design and API architecture skills
  • Experience with LLMs, RAG systems or AI-powered applications
  • Strong ownership, taking features from idea to live production
  • Comfort working in a fast-moving environment with shifting requirements

If you've shipped full-stack features from idea to production, you're comfortable with ambiguity, and you want to work on AI systems that go further than a chatbot, this is built for you.

Fully remote, but you'll need to be based in and have the right to work in Germany.

If that sounds like your kind of problem, get in touch and we can talk through where it might go.
