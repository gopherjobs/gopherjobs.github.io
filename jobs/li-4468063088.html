Position Description The AI Technical Lead is a hands-on technical leadership role responsible for designing, developing, and delivering production-grade AI solutions. The role combines strong software engineering and solution architecture expertise with hands-on experience in Generative AI, LLMs, RAG, Agentic AI, Model Context Protocol (MCP), AI-enabled SDLC, and Microsoft Azure.

The Technical Lead will translate business requirements into scalable AI solutions, provide technical direction to engineering teams, establish reusable patterns and guardrails, and ensure solutions meet enterprise requirements for security, reliability, performance, observability, cost, and Responsible AI.

Key Responsibilities & Technical Skills

  • Design and deliver enterprise AI solutions using LLMs, RAG, Agentic AI, enterprise knowledge retrieval, and intelligent automation
  • Strong hands-on experience with Azure OpenAI, Microsoft Foundry/Azure AI services, and frameworks such as LangChain/LangGraph, Semantic Kernel, LlamaIndex, or comparable technologies
  • Design prompt and context engineering, structured outputs, tool/function calling, agent orchestration, memory, and human-in-the-loop workflows
  • Design and implement MCP servers/clients to securely connect AI agents with enterprise applications, APIs, data, and tools
  • Strong understanding of Microsoft Azure architecture, including Azure AI services, AI Search, API Management, App Services/Functions/Containers, Service Bus, Storage, databases, Key Vault, Entra ID, networking, monitoring, and CI/CD
  • Design secure, scalable, resilient, observable, and cost-effective cloud architectures using appropriate Azure patterns
  • Strong software engineering experience with Python, C#/.NET, and/or TypeScript/JavaScript, including APIs, microservices, distributed systems, SQL/NoSQL, event-driven architecture, automated testing, Git, and CI/CD
  • Leverage AI-assisted development tools such as GitHub Copilot, Claude Code, OpenAI Codex, or equivalent tools across design, development, testing, debugging, code review, documentation, and modernization
  • Establish AI evaluation practices covering accuracy, groundedness, relevance, hallucination, retrieval quality, safety, latency, and cost
  • Implement AI security and guardrails addressing prompt injection, sensitive-data leakage, insecure tool execution, excessive agency, authentication/authorization, RBAC, and least privilege
  • Apply Responsible AI, OWASP LLM security guidance, and NIST AI RMF principles as appropriate
  • Establish observability for model/API performance, token consumption, cost, retrieval quality, agent/tool execution, failures, and AI quality
  • Provide technical leadership to AI, software, and data engineers; translate architecture into implementable components and conduct architecture, design, and code reviews
  • Mentor engineers, establish AI engineering standards and reusable patterns, identify technical risks, and balance rapid experimentation with production engineering quality
  • Evaluate emerging AI models, frameworks, protocols, coding agents, and open-source/commercial technologies through prototypes and technical assessments
  • Support client discussions, technical workshops, solutioning, demonstrations, and pre-sales activities as required

Work Location: This is a remote role open to candidates based in LATAM and supporting US-based clients.
