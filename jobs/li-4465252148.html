About the Role

We are seeking an experienced EHR Integration Engineer to design, build, and deploy a multi-tenant healthcare integration layer using MuleSoft Anypoint Platform. You will be responsible for building reliable outbound (push) data pipelines and inbound (pull) query capabilities to seamlessly exchange clinical data between standardized JSON internal structures and major EHR/clinical systems.

Key Responsibilities

  • Build configuration-driven outbound flows to transform standardized clinical JSON into FHIR R4 (HTTPS), HL7 v2.5 (HTTPS), and HL7 v2.5 (MLLP) formats.
  • Implement query/retrieve capabilities to extract clinical data (patient records, encounters, observations) from major EHR systems (Epic, Cerner/Oracle Health, Athena, Allscripts) via FHIR R4 and HL7 v2, normalizing it into standard platform schemas.
  • Develop Kafka consumers to process incoming standardized clinical event streams.
  • Design and implement tenant routing schemas to ensure new destinations and partners can be onboarded via configuration without code changes.
  • Build robust error-handling, retry/backoff mechanisms, and delivery status tracking to ensure zero silent message loss.
  • Deliver solution design documents, unit/integration test evidence, and operational runbooks for seamless internal handover.

Required Qualifications & Skills

  • Proven experience with MuleSoft Anypoint Platform, DataWeave transformations, and MuleSoft EHR connectors.
  • Hands-on experience integrating with major EHR platforms (Epic, Cerner/Oracle Health, AthenaHealth, or Allscripts).
  • Strong technical working knowledge of FHIR R4, HL7 v2.5, and MLLP transport protocols.
  • Hands-on experience with Apache Kafka event-stream design patterns.
  • Expertise in multi-tenant, configuration-driven integration architectures.
  • Deep understanding of healthcare data security and privacy standards (e.g., HIPAA) for data-in-transit.
