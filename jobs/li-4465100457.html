About The Role We are looking for a Senior DevOps Engineer to build and operate highly available, scalable, and secure cloud infrastructure supporting blockchain services and distributed systems. You will be responsible for designing cloud-native platforms, automating infrastructure, improving system reliability, and collaborating with engineering teams to deliver production-grade services across multiple cloud providers.

This role is ideal for someone who enjoys solving infrastructure challenges at scale, has strong software engineering fundamentals, and is passionate about automation and platform engineering.

Responsibilities

  • Design, build, and maintain highly available cloud infrastructure across AWS, GCP, and Azure.
  • Operate and optimize Kubernetes clusters in production environments.
  • Manage cluster autoscaling and capacity planning using Karpenter and Kubernetes native technologies.
  • Build and maintain Infrastructure as Code (IaC) using Terraform.
  • Design and improve CI/CD pipelines for application and infrastructure deployment.
  • Deploy and operate middleware platforms such as Kafka, Redis and NGINX.
  • Automate operational tasks using Golang and Python.
  • Improve observability through monitoring, logging, alerting, and distributed tracing.
  • Ensure platform reliability, scalability, security, and disaster recovery.
  • Troubleshoot production incidents and perform root cause analysis.
  • Work closely with software engineers to improve deployment processes and platform
  • developer experience.
  • Participate in on-call rotations and incident response.

  • Strong experience with Terraform for infrastructure automation.
  • Experience administering Linux systems and networking fundamentals.
  • Experience operating middleware technologies such as: Kafka / Redis / NGINX
  • Strong scripting and programming skills in: Golang / Python
