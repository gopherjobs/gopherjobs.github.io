Backend Engineer (Node) at BairesDev

As a Backend Engineer (Node), you will build and maintain server-side applications within the Node.js ecosystem. You will act as a key contributor in developing high-performance APIs and event-driven services, ensuring seamless integration between frontend components and backend logic.

What You'll Do

  • Design and develop scalable REST and GraphQL APIs using Node.js and TypeScript.
  • Build and optimize event-driven services and asynchronous processing patterns.
  • Manage and interact with database systems such as PostgreSQL or MongoDB to ensure data integrity and performance.
  • Deploy and maintain cloud-based services using AWS Lambda or ECS.
  • Write comprehensive unit and integration tests using frameworks like Jest or Vitest to ensure code quality.
  • Collaborate with cross-functional teams to define architecture requirements and technical specifications.

What We Are Looking For

  • 4+ years of experience in Backend Engineering, Software Engineering, or a related field.
  • Proven expertise in building scalable APIs and event-driven services using Node.js and TypeScript.
  • Proficiency in designing and implementing REST or GraphQL APIs with asynchronous patterns.
  • Hands-on experience with database technologies such as PostgreSQL or MongoDB.
  • Experience deploying and managing applications on AWS using Lambda or ECS.
  • Advanced proficiency in English.
