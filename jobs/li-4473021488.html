Senior Backend Engineer - Go / Agentic Integrations

Location: Remote – UK / Europe

Employment Type: Permanent

We're partnering with a global enterprise software company building a new generation of AI-native integration technology designed to connect complex enterprise systems, data and workflows.

This is an early-stage, highly technical initiative where you'll help design and build a new integration layer from the ground up. The platform will connect previously disconnected enterprise systems, orchestrate workflows across them, and enable both human users and AI agents to securely interact with enterprise tools and data.

We're looking for an experienced backend engineer who combines deep Go/Golang software engineering experience with enterprise integrations, distributed systems and an interest in modern agentic AI.

You'll join a small, senior engineering team with significant ownership over architecture, technology choices and the direction of the platform.

What You'll Be Working On

  • Designing and building backend services primarily in Go/Golang
  • Building reusable system-to-system and B2B integrations across complex enterprise platforms
  • Designing APIs and integration architecture rather than simply building individual point-to-point connectors
  • Building durable, event-driven and distributed workflows
  • Using orchestration technologies such as Temporal, n8n, Apache Camel, MuleSoft or Boomi
  • Designing reliable systems around retries, failures, asynchronous processing and workflow state
  • Building capabilities that allow AI agents to securely access enterprise tools, APIs and data
  • Working with modern cloud-native infrastructure including Kubernetes and Docker
  • Helping shape architecture and engineering standards in a genuinely greenfield environment

What We're Looking For

  • Strong commercial Go/Golang experience - ideally Go is or has recently been one of your primary backend languages
  • Strong backend/software engineering fundamentals
  • Experience building enterprise, B2B or system-to-system integrations
  • Experience designing distributed and/or event-driven systems
  • Experience with workflow or integration orchestration technologies such as Temporal, n8n, Apache Camel, MuleSoft or Boomi
  • Experience building multi-tenant SaaS/B2B platforms
  • Strong API design and integration architecture experience
  • Experience working with cloud-native environments and technologies such as Kubernetes, Docker and CI/CD
  • Strong architectural judgment and the ability to explain the trade-offs behind technical decisions

Particularly Interesting

Experience in any of the following would be highly valuable:

  • Agentic AI / AI agents
  • Model Context Protocol (MCP)
  • Tool calling and agent-accessible APIs
  • RAG or production GenAI applications
  • AI-native software development using tools such as Claude, Cursor or similar
  • API gateways such as Kong or Tyk
  • Identity, authorization or secure tool access
  • Industrial, enterprise asset, IoT or other complex enterprise software environments

The Opportunity

This isn't a maintenance role or an incremental extension of an established platform.

You'll be joining during the early stages of a new initiative and helping determine how the integration platform should actually be designed .

The broader goal is to move beyond traditional point-to-point integrations and create a unified platform that can combine enterprise data, orchestrate workflows and support increasingly sophisticated agentic AI use cases . That's consistent with the actual project description you've been given.
