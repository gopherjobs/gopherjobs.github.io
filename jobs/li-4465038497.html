Role Overview:

We are hiring for one of our clients, seeking a Senior Software Engineer to work on a contract basis to design, develop, and deploy scalable software solutions for a global platform. The role involves building high-performance backend systems and optimizing cloud infrastructure to support a rapidly growing user base.

Key Responsibilities:

• Design and implement backend services using modern programming languages and frameworks to ensure high availability and performance.

• Collaborate with cross-functional teams to define system requirements and deliver scalable solutions aligned with business objectives.

• Optimize existing codebases for efficiency, reliability, and maintainability while reducing technical debt.

• Write and maintain comprehensive unit, integration, and end-to-end tests to ensure software quality.

• Monitor system performance, debug issues, and implement improvements to enhance user experience.

Required Skills & Qualifications:

• Proficiency in at least one backend programming language such as Python, Java, or Go.

• Experience with cloud platforms including AWS, GCP, or Azure and containerization technologies like Docker and Kubernetes.

• Strong understanding of data structures, algorithms, and system design principles.

• Familiarity with CI/CD pipelines, version control systems (e.g., Git), and Agile development methodologies.

• Ability to write clean, maintainable, and well-documented code with a focus on scalability and security.

More About the Opportunity:

This role offers a unique opportunity to work with a global leader in the Software Development industry, contributing to the enhancement of a platform serving millions of users worldwide. Candidates will have the chance to solve complex technical challenges in a fast-paced, collaborative environment.
