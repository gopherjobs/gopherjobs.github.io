Description

Hirely is recruiting GitHub Contributors / Senior Software Engineers on behalf of a hiring partner for an AI training project.

You'll create challenging software engineering environments that test AI models on real-world development tasks such as bug fixing, feature implementation, codebase refactoring, and performance optimization .

Strong, verifiable open-source contributions are required.

What You'll Do

  • Create reinforcement learning environments that test AI models on software engineering tasks
  • Build reproducible environments for complex coding problems
  • Develop and validate golden reference solutions
  • Create expert-level coding and debugging scenarios
  • Diagnose and resolve complex software defects
  • Implement robust features across existing codebases
  • Refactor legacy code to improve maintainability and reliability
  • Optimize software performance and identify bottlenecks
  • Work with algorithms, data structures, and complex codebases
  • Document technical reasoning and solution approaches
  • Review and validate peer-contributed code and technical submissions
  • Ensure solutions are accurate, reproducible, and aligned with project requirements

Who We're Looking For

  • Significant hands-on experience with at least one of:
  • Python 3, Java, Rust, Go, C++, TypeScript
  • Strong understanding of algorithms and data structures
  • Proven experience debugging complex software
  • Strong software engineering fundamentals
  • Experience implementing features in existing codebases
  • Experience with refactoring and legacy code modernization
  • Strong performance optimization and troubleshooting skills
  • Ability to clearly document technical decisions and reasoning
  • Strong written communication skills
  • Clear, verifiable open-source contributions on GitHub or GitLab
  • Interest in AI and software engineering challenges is a plus
  • Previous AI experience is not required

Compensation & Terms

  • $50-100/hour
  • Independent contractor
  • Fully remote

Application Process

  1. Submit your application and screening questions
  2. Complete an approximately 30-minute AI interview
  3. Complete a technical assessment if required
  4. Hiring manager review
  5. Selected candidates can typically begin within 24-48 hours after onboarding

Important Requirement

Applicants should have publicly verifiable open-source contributions that demonstrate their software engineering ability. GitHub or GitLab profiles are preferred, particularly contributions involving Python, C++, Java, Go, TypeScript, or Rust.
