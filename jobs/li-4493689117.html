Job Description Own a production software component from design through release and support. Use coding agents to build and test software, and integrate models where they improve a client workflow. At L5 you make component-level design decisions, mentor engineers, and take responsibility for how your software performs after release.

Level 5 Core Responsibilities

  • Translate client workflows into acceptance examples with product and QA. Define how the component should behave when inputs are incomplete or a dependency fails.
  • Give coding agents bounded implementation tasks. Review their changes and independently verify behavior with unit, integration, and regression tests.
  • Build model-backed services with explicit contracts. For example, when extracting fields from documents, define the output schema, evaluate against representative samples, and route uncertain results for review.
  • Trace failed requests, monitor latency and cost per successful task, and use release data to diagnose regressions.
  • Lead component design and code reviews. Pair with less experienced engineers and explain trade-offs to client stakeholders.

Qualifications

  • Typically 5–8 years of professional software engineering experience, including ownership of a production component.
  • Hands-on experience shipping changes with a coding agent. Be prepared to describe a defect the agent introduced, how you found it, and how you verified the fix.
  • Fluency in a production language such as Python, TypeScript, Java, or C#, with experience designing APIs, writing automated tests, and maintaining CI/CD pipelines.
  • Depth in at least one engineering discipline such as DevOps, analytics, front-end development, database engineering, or security. Bring an example of how that expertise shaped a design decision.
  • Bachelor’s degree in computer science or engineering, or equivalent practical experience.

Preferred Experience

  • Approximately 3–4 years of AI-assisted development experience with progression into agentic

coding. Comparable depth demonstrated through shipped work is welcome.

  • One to two years of applied machine learning is valuable for assignments involving model

selection, evaluation, or inference.

Technical Skills

  • Use tools such as Claude Code, GitHub Copilot, or Cursor in a reviewed Git workflow.
  • Integrate model APIs, validate structured outputs, and test permissions and failure handling.
  • Deploy and observe services with tools appropriate to the project, such as Docker, Kubernetes,

Helm, Prometheus, and Grafana.

Certifications

  • Preferred AI credentials cover agentic coding workflows, AI application architecture, or

production data pipelines using tools such as Databricks. Candidates should be able to connect

a credential to a component they owned and explain how they verified generated code,

evaluated model outputs, or recovered a failed pipeline.

  • Relevant stack certifications from Claude, Microsoft (Azure), AWS, SUSE, or CNCF are also

welcome. Candidates should be able to explain a design or operating decision they made on the

certified stack and what happened after release.

Soft Skills

  • Explain design decisions in language clients can act on. Raise delivery risks early and present

practical options.

  • Give specific review feedback and help teammates verify agent-generated changes

independently.
