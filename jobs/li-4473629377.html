Description

A Jungle Gaming cria jogos originais e tecnologia para operações globais de iGaming. Estamos contratando Backend Developer Júnior para começar a construir serviços de produção com acompanhamento próximo de pessoas mais experientes do time.

Experiência profissional anterior não é obrigatória. Projetos pessoais, acadêmicos e open source contam como evidência do que você sabe fazer. Você trabalhará em uma arquitetura existente com NestJS, TypeScript, MikroORM, PostgreSQL, Docker, DDD e microsserviços, expondo REST APIs e comunicação em tempo real por WebSockets. O ambiente também utiliza AWS — SQS, SNS, S3 e Secrets Manager —, Git e ferramentas de IA agêntica.

Como será o sucesso na função

Você começa a entregar mudanças pequenas e bem delimitadas em produção com orientação, e seu trabalho fica mais fácil de revisar a cada iteração. Você consegue acompanhar uma requisição pela API, domínio e banco de dados, escrever ou atualizar os testes relevantes, explicar o que mudou e reconhecer quando pedir ajuda antes que um risco cresça.

O que você fará

  • Implementar endpoints REST e fluxos com WebSockets em NestJS e TypeScript
  • Evoluir modelos, consultas e migrações com MikroORM e PostgreSQL
  • Contribuir com microsserviços e fluxos assíncronos usando SQS e SNS
  • Conteinerizar serviços com Docker e investigar logs e erros de execução
  • Usar S3 e Secrets Manager com orientação e práticas seguras
  • Trabalhar com Git, revisar mudanças e validar criticamente conteúdo gerado por IA

O que você precisa trazer

  • Boa base de JavaScript ou TypeScript demonstrada em projetos
  • Conhecimento inicial de backend, APIs REST e algum framework como NestJS
  • Noções de SQL, bancos relacionais e persistência de dados
  • Curiosidade para aprender DDD, microsserviços, WebSockets e serviços AWS
  • Capacidade de investigar problemas, pedir contexto e aplicar feedback
  • Você não precisa dominar todas as tecnologias do stack antes de se candidatar. Procuramos uma base consistente e capacidade de aprender no trabalho.

Diferenciais — não obrigatórios

Você não precisa ter experiência com estas tecnologias para se candidatar:

  • Conhecimento de Terraform
  • Conhecimento de Kubernetes
  • Conhecimento de tecnologias Web3

Faixa salarial mensal: R$ 2.500–R$ 5.000.

Modelo de trabalho: posição remota.

Ao se candidatar, inclua um GitHub ou links para projetos que mostrem como você estrutura e explica seu código.
