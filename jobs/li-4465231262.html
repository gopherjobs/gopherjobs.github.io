Role Overview

We are seeking a Senior C++ / ChromeOS Platform & Kernel Engineer to build, optimize, and maintain the low-level platform architecture powering ChromeOS and Chrome for Meetings (CfM) hardware solutions.

In this role, you will be deeply hands-on—tracing system bottlenecks, diagnosing complex OS/kernel bugs, and directly authoring production-grade C++ code patches and Linux kernel modules. You will work at the intersection of userspace daemons (DBus, Mojo), display drivers, hardware peripherals (AV devices, cameras, microcontrollers), and the Linux kernel core.

Core Responsibilities

  • C++ Systems Development: Design, write, and maintain low-level C++ code for ChromeOS system daemons (Chromium/ChromeOS userspace), hardware abstraction layers (HALs), and enterprise management services.

  • Linux Kernel Engineering: Debug, patch, and up-stream Linux kernel drivers (USB, display, audio, V4L2, power management, PCI) for next-generation ChromeOS and CfM hardware platforms.

  • Root-Cause Diagnostics: Utilize advanced system debugging tools (gdb, perf, ftrace, ebpf, strace, crashdump analysis) to troubleshoot panics, memory leaks, high latency, and hardware edge cases.

  • Chrome for Meetings (CfM) Integration: Solve real-time video/audio hardware integration issues, ensuring zero-latency media delivery, seamless USB-peripheral hotplugging, and high system reliability for enterprise conference room environments.

  • Upstream & Open-Source Collaboration: Work within the Chromium OS open-source codebase, submitting clean, well-tested code patches, conducting peer code reviews, and maintaining build scripts (Gentoo/Portage, ebuilds).

  • Performance & Stability Optimization: Profile system boots, optimize resource utilization (RAM/CPU/Power), and prevent platform-level regressions across diverse hardware configurations.

Requirements & Qualifications

  • Advanced C++: 5+ years of hands-on experience in modern C++ (C++14/17/20) systems programming, including smart pointers, asynchronous execution (Mojo, libchrome), memory safety, and multi-threading primitives.

  • Linux Kernel Expertise: Proven track record writing, patching, and debugging Linux kernel drivers, module development, and working with device trees (DTS).

  • Debugging Expertise: Mastery of diagnostic tools like gdb, perf, ftrace, valgrind, strace, and reading kernel ring buffers (dmesg).

  • ChromeOS / Chromium Stack: Hands-on experience with the ChromeOS platform architecture, Chromium builds, Portage/ebuild systems, DBus, Mojo, or shill/cros_healthd/powerd.

  • CfM & Media Peripherals: Prior experience with enterprise conference hardware (Chrome for Meetings), V4L2 (Video4Linux), ALSA/PipeWire, USB UVC/UAC, and HDMI-CEC display pipelines.

  • Hardware Bring-up: Experience bringing up new x86 or ARM SoC boards, modifying bootloaders (Coreboot/Depthcharge), or tuning power states.

  • Chromium Code Contribution: Active code contributions to the upstream Chromium OS or Linux Kernel projects.
