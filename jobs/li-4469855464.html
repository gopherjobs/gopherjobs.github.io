DESCRIPTION

Join our Pricing Engineering team as a Software Developer, where you’ll collaborate in an agile, cross-functional environment, owning deliverables end-to-end and ensuring top-notch quality. This is a hands-on backend role focused on designing and maintaining a Spring Boot / gRPC pricing platform with a non-trivial persistence layer and strict data-consistency requirements.

• Collaborate in an agile, cross-functional environment, owning deliverables and ensuring top-notch quality.

• Turn user stories into maintainable, well-tested code across REST and gRPC APIs.

• Design and evolve JPA entity models with correct transaction boundaries, optimistic locking, and Hibernate session/flush behavior in mind.

• Work with append-only/soft-delete data patterns (no in-place mutation of historical or config records) and schema evolution via Liquibase.

• Tackle complex challenges as an enthusiastic problem solver, particularly around data correctness under concurrency and caching.

• Promote good software engineering practices: clean service-layer design, performance-aware code on hot paths, and resilient, self-healing solutions.

REQUIREMENTS

• Strong Java and Spring / Spring Boot proficiency, including gRPC service implementation and REST APIs.

• Solid, hands-on understanding of Hibernate/JPA internals: entity lifecycle, lazy loading, transaction propagation, optimistic locking, N+1 pitfalls, and how these interact with a MySQL schema managed via Liquibase.

• Practical experience with transactional design in a microservice context — knowing when a change belongs in one transaction vs. several.

• Experience with message-driven architectures using Kafka (consumer offset management) and/or RabbitMQ.

• Comfortable with Docker and microservice infrastructure/deployment (Helm/Kubernetes is a plus).

• Experience with automated testing using JUnit 5 and/or Spock; comfortable writing both unit and integration tests.

• Familiarity with functional-style Java libraries (e.g., Vavr), mapping frameworks (e.g., MapStruct), and distributed caching (e.g., Hazelcast) is a plus.

• Our corporate language is English, please submit your application in English.
