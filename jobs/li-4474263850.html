Description

Position: Software Engineer Coding Benchmarks & RL Environments

Type: Hourly Contract

Compensation: $45-$75/hr

Location: Remote

Role Responsibilities

  • Design realistic engineering tasks for full-stack web apps on codebases that build over time.
  • Write tests that determine whether a solution is correct.
  • Create tasks involving services, APIs, backend languages such as Go, Rust or Java, gRPC and rate limiting.
  • Share lessons from other projects and flag potential improvements.

Requirements

  • Solid professional software engineering experience across backend and frontend.
  • Experience building and debugging real systems, and a strong interest in testing them well.
  • Clear written communication and comfort working independently from written documentation.
  • US and Canada preferred for timezone overlap; exceptional candidates elsewhere are welcome.
  • LinkedIn and GitHub required.
