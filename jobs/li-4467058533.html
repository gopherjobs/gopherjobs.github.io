Description: Turning on a refrigerator remotely requires the boat to be connected. However, boats are often located in archipelagos or remote areas with poor network coverage. This thesis project explores Edge Computing and investigates how logic and system states can be managed locally on the boat while synchronizing intelligently with the cloud.

Research Questions

  • How do you design a system (Digital Twin) where a user can send the command "Turn on the AC" from an app, have the command placed in a queue, and execute it automatically as soon as the boat regains network connectivity?
  • How should conflicts be handled (for example, if someone manually turned on the AC while on board)?

Objective

  • Design a robust architecture for asynchronous remote control.
