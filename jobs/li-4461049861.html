Department Overview We are seeking a Software Engineer to join our core engineering team to design and develop a high-throughput, mission-critical active-active microservice framework responsible for dynamically routing and balancing traffic across multi-site deployments based on real-time health, capacity, and geolocation metrics.

Job Description Key Responsibilities:

  • Develop the core Load Distribution engine using Finite State Machines (FSM) to manage dynamic homing, execute Weighted Average Score (WAS) algorithms, and implement hysteresis.
  • Architect high-throughput API and messaging layers using gRPC for metrics ingestion and RabbitMQ (RMQ) for event-driven communication.
  • Implement distributed leader election and consensus mechanisms utilizing Consul Raft and LockAuthority across active-active deployments.
  • Ensure system scalability to handle 3,000+ assignments per second while integrating Apache Ignite/GridGain for stateless caching and data recovery.

Required Skills & Experience

  • Deep hands-on experience in Golang (preferred) and proficiency in C, C++, or Java.
  • Strong computer science fundamentals, data structures, and algorithms.
  • Deep understanding of distributed systems, multi-threading, concurrency control, and Finite State Machines (FSM).
  • Hands-on expertise with networking and messaging protocols including gRPC, Protobuf v3, and RabbitMQ.
  • Strong background with distributed databases like Apache Ignite and GridGain, and consensus tools like Consul Raft and LockAuthority.
  • Practical knowledge of persistence and caching solutions such as PostgreSQL, Redis, and ElasticSearch.
  • Excellent written and verbal communication skills for technical documentation and explaining complex ideas.
  • Industry Experience - 1 to 10 years.

Basic Requirements

  • Proven ability to design active-active multi-site architectures handling network partitions, majority/minority quorums, and site-isolation scenarios.
  • Experience with large-volume transaction systems, data migration workflows, and end-to-end observability frameworks like OpenTelemetry and Kibana.
  • Familiarity with enterprise security tooling such as Vault and mTLS.
  • Background in automated deployments using Docker and CI/CD pipelines.
