Description

We are seeking experienced Freelance ServiceNow SecOps Developers for an initial 12-month contract with a leading client in the Netherlands. The role will involve a combination of remote working and occasional onsite work in Eindhoven.

You will be responsible for developing, configuring and enhancing ServiceNow Security Operations capabilities, supporting security processes and integrating the platform with external security tools.

Key Responsibilities

  • Configure and develop ServiceNow SecOps modules, including Security Incident Response (SIR), Vulnerability Response (VR), Threat Intelligence (TI) and Configuration Compliance (CC).
  • Develop custom applications, scripts and automated workflows using JavaScript, Flow Designer and Integration Hub.
  • Design and implement integrations between ServiceNow and external security platforms, APIs and vulnerability scanners.
  • Provide operational support, troubleshoot issues, test integrations and support platform upgrades.
  • Contribute to platform stability, security operations and continuous improvement initiatives.

Requirements

  • Strong hands-on ServiceNow SecOps development experience across SIR, VR, TI and/or CC.
  • ServiceNow Certified Application Developer (CAD) certification.
  • Proficiency in JavaScript, HTML, CSS, ServiceNow Studio and CI/CD.
  • Experience with security integrations, vulnerability management and compliance frameworks.
  • Knowledge of ITIL processes and ServiceNow ITSM.
  • Location: Netherlands-based candidates only, with occasional onsite attendance in Eindhoven.
