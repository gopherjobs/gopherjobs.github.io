👩‍💻 Responsibilities

At SEO Navigator, we’re looking for a Developer who finds issues and fixes them. This role goes beyond traditional testing: you will verify our websites, CRM automations and internal tools, then fix what you find, using Claude Code and AI to work faster. You’ll be the first line of IT support for our teams, so our Development Lead can focus on building new products and automations.

Key Responsibilities

  • Test pull requests before merge: check out the branch, run the existing test suites, try the preview deployment, and report pass/fail with clear evidence
  • Fix the issues you find, from broken redirects and missing form data to routine code bugs, and open a pull request for review
  • Run website UAT before launch and check demo links before they go to clients or prospects
  • Verify CRM and automation changes (GoHighLevel workflows, webhooks, client CRM migrations) and confirm the data lands correctly
  • Support the IT team around CRM, websites and internal tools, and resolve issues raised by other teams (SEO, Content, Design, Ads)
  • Reproduce reported bugs and document them with exact steps, expected vs. actual results, and severity
  • Write and maintain test cases and automated browser tests for our most-used flows
  • Help maintain the team’s Claude Code skills and AI automations, and flag anything that breaks
  • Escalate early when an issue needs a decision beyond a routine fix

🌋 Requirements

  • 1+ year of experience in web development, QA/testing or IT support (internships and freelance projects count)
  • Hands-on experience using AI tools for development (e.g., Claude, Claude Code, Cursor, Copilot)
  • Working knowledge of JavaScript/TypeScript: you can read code, run a test suite and fix a bug
  • Comfortable with Git and GitHub: branches, pull requests and code review
  • Able to test APIs and webhooks (Postman or curl) and write basic SQL queries to check data
  • Clear, structured bug reporting: exact steps, edge cases, not just the happy path
  • Detail-oriented and careful: you check your fix before you hand it back
  • Learning mindset: you pick up new tools and AI workflows quickly
  • Good written English

Nice to have

  • Experience with Cloudflare (Workers, Wrangler, D1/SQLite)
  • Experience with CRM or automation tools (GoHighLevel, Zapier)
  • Experience using MCP connectors with Claude
