Description

En Vermont Solutions buscamos incorporar un/a Analista Java. Un perfil con entre 2–3 años de experiencia que pueda asumir responsabilidades funcionales y técnicas , participando en la definición de requisitos de negocio y en el diseño funcional de los desarrollos del producto de uno de nuestros clientes en el sector energético.

No buscamos un perfil senior, pero sí alguien con madurez técnica, capacidad de comunicación con cliente y cierto liderazgo técnico dentro del equipo. 🛠️ Responsabilidades

  • Participar en la recogida y análisis de requisitos junto con negocio.
  • Elaborar especificaciones funcionales y colaborar en el diseño de soluciones.
  • Desarrollar y mantener componentes en Java + Spring (backend) y, en caso necesario, colaborar en tareas fullstack con Angular.
  • Asegurar la calidad del código mediante JUnit, Mockito, análisis estático y buenas prácticas.
  • Integración con Webservices (SOAP) y API REST.
  • Uso de herramientas de CI/CD como Jenkins, control de versiones con Git y análisis con Sonar.
  • Colaborar con el equipo en un entorno Agile.
  • Ejercer liderazgo técnico puntual: guiar a compañeros menos experimentados, revisar código y apoyar en decisiones técnicas.
  • Comunicación fluida con cliente y stakeholders.
  • Uso de herramientas de IA para codificación, pruebas unitarias, análisis estático y corrección de bugs.

✅ Requisitos

  • Nivel de inglés alto; mínimo un B2+ o un C1.
  • 2-3 años de experiencia en desarrollo/analítica Java.
  • Experiencia con Java en backend o en perfiles fullstack con Angular.
  • Conocimientos sólidos de Spring.
  • Experiencia con SQL.
  • Experiencia en testing con JUnit y Mockito.
  • Conocimientos de Web Services SOAP y APIs REST.
  • Experiencia con Jenkins, Git y Sonar.
  • Experiencia en liderazgo técnico de equipos (pueden haber sido pequeños equipos, momentos puntuales etc)
  • Capacidad de comunicación y experiencia en interlocución directa con clientes.
  • Experiencia utilizando herramientas de IA aplicadas al desarrollo de software

⭐ Valorable

  • Experiencia en proyectos relacionados con el vehículo eléctrico.
  • Experiencia en soluciones vinculadas a puntos de recarga.
