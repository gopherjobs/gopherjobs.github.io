Job Description Information security is an integral part of Visa’s corporate culture. It is essential to maintaining our position as an industry leader in electronic payments, and it is the responsibility of each employee to safeguard information, protect it from unauthorized access, and ensure regulatory compliance. Information security has a significant effect on privacy, consumer confidence, external reputation, and the bottom line, and it is a priority on everyone’s agenda.

The successful candidate will be part of Visa’s Business-to-Business Identity & Access Management team, which is part of the larger Cybersecurity organization. The B2B IAM team has a global focus and responds to an evolving threat landscape, regulatory compliance needs, IT security requirements, and technology architecture priorities. The team is responsible for enabling secure access to business portals and associated services.

The Senior Software Test Engineer will help ensure quality, security, release readiness, and platform stability for B2B IAM applications. This role requires hands-on experience in test engineering, test automation, full-stack application validation, security patch validation, release support, and production-like environment troubleshooting.

Essential Functions

  • Own and drive test planning, test design, execution, and automation for assigned Java, .NET Core, Python, and full-stack B2B IAM applications.
  • Develop, enhance, and maintain automated tests and test frameworks using tools such as Selenium, Playwright, Postman/Newman, JMeter, Java, Python, or similar technologies.
  • Perform functional, regression, integration, API, performance, smoke, sanity, and post-deployment validation testing.
  • Support full-stack application testing and troubleshooting across front-end, back-end, database, API, middleware, and infrastructure layers.
  • Support QA, staging, pre-production, and production-like environments by troubleshooting issues, validating configurations, and helping maintain environment stability.
  • Support security patching, vulnerability remediation, dependency upgrades, certificate renewals, middleware updates, and patch validation activities.
  • Support release management activities, including release readiness validation, deployment validation, smoke testing, regression testing, release sign-off inputs, rollback support, and post-release validation.
  • Contribute to platform stability through monitoring, log analysis, root cause analysis, defect investigation, and collaboration with development, security, and operations teams.
  • Conduct API and performance testing using tools such as Postman, SoapUI, OpenAPI/Swagger, JMeter, LoadRunner, or similar tools.
  • Work with relational databases and directory services to validate data, write SQL queries, troubleshoot issues, and support IAM workflows.
  • Collaborate with developers, product owners, QA engineers, security engineers, operations personnel, and system engineers to support secure, stable, and high-quality delivery.
  • Ensure assigned test and release activities align with Visa Development Management Methodology, Visa Technical Security Requirements, SSDLC practices, and cybersecurity requirements.
  • Use CI/CD, source control, code quality, and DevOps tools such as Jenkins, GitHub, Bitbucket, Artifactory, SonarQube, Checkmarx, Docker, Kubernetes, or similar tools.
  • Contribute to internal tools, scripts, dashboards, test utilities, and automation solutions using Java, Python, JavaScript, React, Angular, Node.js, REST APIs, SQL, HTML5, or CSS3.
  • Support the use of generative AI, agentic tools, and AI-assisted automation to improve testing, release validation, failure analysis, and support workflows.
  • Participate in Agile/Scrum ceremonies, create and maintain test documentation, share knowledge, and mentor junior engineers as needed.

This is a hybrid position. Expectation of days in the office will be confirmed by your Hiring Manager.
