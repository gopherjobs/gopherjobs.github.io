Description

  • Role: Software Engineer - Open Source (Remote)
  • Location: Remote (Work from Anywhere)

Role Overview:

We are hiring for one of our clients, seeking an experienced GitHub Contributor to work on a Full-Time basis. The role involves contributing to open-source software libraries, triaging GitHub issues, writing test cases, implementing features, and creating reproducible codebases used to train and evaluate AI coding assistants.

Key Responsibilities:

• Triage, reproduce, and resolve complex issues and bugs across active open-source GitHub repositories.

• Author high-quality pull requests with clean code, comprehensive unit tests, and thorough documentation.

• Create minimal reproducible examples, bug benchmarks, and synthetic test suites to evaluate AI coding models.

• Review code contributions and engage with maintainers and open-source communities following repo guidelines.

• Containerize code repositories using Docker to ensure reproducible build and test environments.

Required Skills & Qualifications:

• 3+ years of active software development experience with a verifiable public GitHub profile or open-source track record.

• Strong programming proficiency in at least one modern language (Python, JavaScript/TypeScript, Go, Java, C++).

• Deep expertise with Git version control, GitHub workflows, branching strategies, and CI/CD pipelines.

• Experience with unit testing frameworks, code review best practices, and Docker containerization.

• Strong written technical communication and problem-solving skills.

More About the Opportunity:

This role offers a flexible remote contract engagement working at the intersection of open-source software and artificial intelligence. You will directly influence the development and evaluation of frontier AI coding tools.

Equal Opportunity Employer:

We hire based on skills and expertise. All qualified candidates are welcome regardless of background, experience, or prior employment history. Applications are reviewed solely on demonstrated technical ability and qualifications.
