About the project:

As a Senior QA Automation Engineer , you'll join a team building quality into a complex, microservices-based surgical intelligence platform. You'll work in an AI-assisted development environment, using agentic coding tools alongside structured specifications and acceptance criteria to drive testing across distributed systems. This role requires the ability to work independently, translate ambiguous requirements into clear test approaches, and maintain rigorous documentation and traceability across manual and automated testing efforts.

What you’ll do:

  • Design, build, and maintain test automation using Python and Playwright across the platform
  • Develop and maintain BDD-style test suites using frameworks such as pytest-bdd or Behave
  • Work within AI-assisted or AI-accelerated development workflows, leveraging tools like Claude Code or similar agentic coding tools to support test creation and review
  • Translate structured specifications, requirements, and acceptance criteria into effective test coverage
  • Design and execute test strategies for microservices-based applications, including API, integration, database, and web application testing
  • Test and validate services running in Kubernetes environments, and integrate testing into CI/CD pipelines
  • Create and maintain high-quality, repeatable test documentation for both manual and automated testing
  • Maintain strong requirements traceability and defect documentation practices
  • Independently design test approaches for complex distributed systems
  • Identify ambiguous or incomplete requirements and collaborate with product and engineering teams to clarify expected behavior

What makes you a great fit:

  • 7+ years of hands-on QA, test engineering, or quality engineering experience
  • Strong test automation experience with Python and Playwright
  • Experience with BDD frameworks such as pytest-bdd or Behave
  • Proven experience working in an AI-assisted or AI-accelerated software development environment
  • Hands-on experience with Claude Code or similar agentic coding tools
  • Experience using structured specifications, requirements, and acceptance criteria to drive testing
  • Strong experience testing microservices-based applications
  • Hands-on Kubernetes experience and familiarity with CI/CD in a microservices environment
  • Strong API, integration, database, and web application testing experience
  • Demonstrated experience creating and maintaining high-quality, repeatable test documentation for both manual and automated testing
  • Strong requirements traceability and defect documentation practices
  • Ability to independently design test approaches for complex distributed systems
  • Ability to identify ambiguous or incomplete requirements and work with product and engineering teams to clarify expected behavior
  • Must be able to work independently with limited direction
