Description

Sobre a vaga

Buscamos uma pessoa desenvolvedora fullstack pleno/sênior para construir uma plataforma SaaS de atendimento com agentes de IA que conversam por voz e texto.

Trabalhamos com APIs e frontends em TypeScript e serviços em Python, rodando em containers na nuvem.

A missão do papel é entregar funcionalidades de ponta a ponta, do banco de dados à interface, com testes, telemetria e documentação técnica.

Responsabilidades

  • Desenvolver APIs HTTP em TypeScript com PostgreSQL: rotas tipadas, migrations, processamento assíncrono em filas e eventos em tempo real.
  • Construir interfaces em React reaproveitando um design system interno e documentando componentes.
  • Evoluir serviços Python assíncronos, incluindo integrações com provedores externos.
  • Integrar LLMs ao produto, com validação de saídas, guardrails e testes.
  • Manter contratos entre serviços (OpenAPI, clientes gerados) e fluxos de autenticação.
  • Escrever testes automatizados e instrumentar o código com telemetria.
  • Participar de deploys via CI/CD e investigar problemas em produção com logs e traces.
  • Escrever e revisar documentos técnicos antes de mudanças relevantes.

Requisitos obrigatórios

Esperamos domínio prático de TypeScript em backend e frontend, e Python suficiente para trabalhar com autonomia em serviços assíncronos.

Backend TypeScript

  • TypeScript avançado: genéricos, tipos inferidos, discriminated unions e validação com Zod.
  • APIs HTTP em Node ou Bun (Elysia, Fastify, Hono ou Express), com OpenAPI.
  • SQL e PostgreSQL: modelagem, índices, transações, migrations; query builder tipado (Kysely ou equivalente).
  • Filas e cache com Redis (BullMQ ou similar) e comunicação em tempo real via WebSocket.
  • Tratamento de erros explícito (Result types) e logging estruturado (Pino).

Frontend

  • React moderno com hooks, Suspense e SSR.
  • Roteamento e estado de servidor com TanStack Router/Start e TanStack Query (ou Next.js + React Query, com disposição para migrar).
  • Tailwind CSS e componentes baseados em Radix/shadcn/ui; atenção a acessibilidade.
  • Formulários complexos, tabelas e consumo de APIs tipadas geradas.

Python

  • Python 3.12+ com asyncio, FastAPI e Pydantic.
  • SQLAlchemy/Alembic ou asyncpg; tipagem estrita (basedpyright/mypy) e Ruff.
  • pytest com fixtures assíncronas.

Engenharia

  • Testes automatizados como parte da entrega: unitários, integração com containers reais (Testcontainers) e mocks de rede (MSW, respx).
  • Docker e Docker Compose no dia a dia; noções de CI/CD com GitHub Actions.
  • Git com Conventional Commits e code review assíncrono.
  • Escrita técnica clara em português; inglês para leitura de documentação.

Diferenciais

  • Voz e tempo real: frameworks de agentes de voz STT/TTS e latência de turno.
  • Telefonia: noções de SIP e provedores de telefonia em nuvem.
  • IA aplicada: LangGraph, Vercel AI SDK, RAG com busca vetorial e avaliação de agentes.
  • Arquitetura orientada a eventos: event sourcing, idempotência e máquinas de estado.
  • Colaboração em tempo real: CRDTs (Yjs) e editores ricos (TipTap/ProseMirror).
  • Observabilidade: OpenTelemetry e stack Grafana.
  • Nuvem: GCP ou equivalente em AWS/Azure.
  • Segurança: proteção de dados sensíveis e LGPD.
  • Front avançado: mapas, grafos e gráficos interativos; streaming de respostas de LLM na UI.
