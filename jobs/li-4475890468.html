Key Responsibilities

  • Craft client code that is not just efficient but also performant, testable, scalable, secure, and of the highest quality.
  • Work within an AI-driven development workflow, applying spec-driven development practices (writing clear specs/prompts that steer AI-assisted implementation) and using GitHub Copilot as a core part of the daily engineering workflow.
  • Ensure code is secure through Software Composition Analysis (SCA), and drive remediation through triaging, prioritization, remediation and verification.
  • Provide accurate status tracking, reporting, and estimation using project methods and tools.
  • Gather requirements, validate their understanding amongst the team, and create and maintain relevant documentation.
  • Design and implement scalable AI and agentic workflows using LLMs, focusing on reliability and observability.
  • Contribute to frontend features in React alongside backend services.
  • Execute activities within the current methodology and uphold the highest quality standards.
  • Partner directly with Product and Engineering leadership to translate complex business requirements into scalable technical solutions.
  • Identify and remediate technical debt to improve system stability, performance, and developer velocity.
  • Take ownership of projects, from technical design to a successful launch.
  • Participating in code reviews to maintain code quality and consistency.

Minimum Qualifications

  • Strong proficiency in modern PHP (PHP 8.5) and the Laravel framework (Laravel 13), as specified for the backend stack, or strong experience in similar modern backend frameworks like Ruby on Rails, Python/Django, or Node.js, leveraged with AI assistance
  • Proven ability to own technical features from design through to production deployment with minimal supervision.
  • Deep understanding of system design, architecture, and the ability to solve ambiguous technical challenges.
  • Expertise with Git source control tools (Github, Gitlab or others)
  • Demonstrated experience working with AI-assisted coding tools and AI-augmented delivery workflows. Because a senior engineer is responsible for reviewing and validating all AI-produced backend outputs, rigorous code review and prompt engineering skills are essential.
  • Ability to build and maintain robust APIs and integration points alongside automated parity and regression testing.
  • Experience working on legacy modernization projects, breaking down monolithic PHP applications into modular services, and executing incremental rollouts.
  • Experience in engineering software systems of medium-to-large scope and complexity.
  • Proficiency with MySQL databases.
  • Experience deploying and operating systems on AWS.
  • Familiarity with Agile software development methodologies.
  • Proficiency in the English language.

Additional Experience Desired

  • Experience working with MySQL, understanding legacy data models, handling data reconciliation without full database migrations, and ensuring backward compatibility.
  • Architectural (Microservices, Serverless etc) and Design (Factory, Singleton, Observer etc) Patterns
  • Unit Testing
  • Working in the Cloud
  • Containers using Docker/Kubernetes
  • Specific client-engagement specified technologies, which will be determined and vetted at the time of the interview.
