Who We Are

samdesk is a global disruption monitoring platform delivering real-time crisis alerts 24 hours a day, 365 days a year, powered by AI. We make sense of the world’s most valuable real-time data sources with a singular purpose: to create a safer world. Headquartered in Edmonton, Alberta, Canada, with team members distributed around the globe, we work with some of the largest brands in the world, including DoorDash, Meta, Uber, Ford, and NATO. Check us out! www.samdesk.io

About the Role

The Junior Backend Engineer on the Features Team writes the code behind the apps and APIs our customers use to access samdesk’s real-time alert data. This is a build-focused role: you will spend most of your time, roughly 85 to 90%, writing, testing, and shipping code. You will pick up well-defined tickets across our data pipeline, APIs, LLM integrations, and internal tools, and take them from first commit to production. You will work alongside senior engineers who will review your work, pair with you on harder problems, and help you grow quickly. Your code will run in production and affect alerts delivered to users around the world, so you will learn to care about quality, testing, and reliability from day one.

This role reports to the Lead Backend Engineer on the Features Team and works closely with senior engineers, machine learning, and product.

Responsibilities

Building Features

  • Implement features, bug fixes, and improvements to the microservices and APIs that power the alert pipeline and samdesk applications
  • Help add new data sources to the pipeline, including parsing, enrichment, and routing logic
  • Build and extend integrations with OpenAI and Anthropic APIs, including prompts, tool use, and response handling
  • Contribute to internal tools used by operations, ML, and QA teams

Quality and Reliability

  • Write unit and integration tests for the code you ship
  • Investigate and fix bugs, including production issues, with support from senior engineers
  • Add logging and metrics so your code can be monitored and debugged in production
  • Keep API and service documentation up to date as you make changes

Learning and Collaboration

  • Participate in code reviews, both giving and receiving feedback
  • Ask questions early, flag blockers quickly, and give honest updates on progress
  • Learn our architecture, tools, and practices, and take on larger and less defined work over time
  • Use AI coding tools effectively while understanding and owning every line you commit

Qualifications and Skills

Required

  • 1 to 2 years of professional software engineering experience, or equivalent experience through co-op terms, internships, or substantial personal or open-source projects
  • A degree or diploma in computer science, software engineering, or a related field, or equivalent practical experience
  • Solid working knowledge of Node.js (TypeScript) and/or Python
  • Understanding of REST APIs, HTTP, and basic data modelling
  • Comfort with Git and a collaborative code review workflow
  • Experience using AI coding tools as part of your day-to-day development

Nice to Have

  • Projects that call the OpenAI or Anthropic APIs, or otherwise build on LLMs
  • Exposure to Docker, cloud services (AWS preferred), or CI/CD pipelines
  • Experience with MongoDB, GraphQL, or message queues
  • Familiarity with writing automated tests

You'll Thrive Here If

  • You love building things and want to see your code in production quickly
  • You are curious about how systems work, and you dig in until you understand why
  • You take feedback well and apply it, and you are not afraid to ask questions
  • You care about doing it right, not just making it pass
  • You can point to something you built that you are proud of, and explain the trade-offs you made
