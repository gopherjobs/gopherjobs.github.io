Description

Who You’ll Be Working With

You’ll join our engineering team, collaborating closely with designers, product managers, and other developers to architect scalable, high-performing headless content management solutions. You’ll work with enterprise clients to shape technical strategy, guide best practices, and ensure seamless integration with their broader digital ecosystems.

Responsibilities

  • Designing, developing, and maintaining backend services using Python - FastAPI and frontend applications using Vue.js
  • Building and maintaining event-driven microservices, including PubSub-based messaging and asynchronous processing patterns
  • Developing and optimizing PostgreSQL data models, including revision-based/audit-trail schemas, and writing and running Alembic migrations
  • Deploying and managing services on GCP, including Cloud Run, GCS, IAM/service accounts, and Secret Manager via Terraform and Spacelift
  • Building and maintaining containerized applications with Docker, and supporting CI/CD pipelines via GitHub Actions
  • Implementing effective security protocols, data protection measures, and storage solutions
  • Writing testable, reusable, and efficient code across the stack, and integrating REST APIs between frontend and backend
  • Running diagnostic tests, troubleshooting defects, and providing technical support
  • Documenting engineering processes, including database schemas and system architecture, as well as preparing reports
  • Recommending and implementing improvements to processes and technologies

What you’ll need to be successful

  • Ideally 6+ years of engineering experience in a full-stack capacity
  • Strong hands-on experience with Python - FastAPI
  • Building responsive, component-based user interfaces with Vue.js
  • Experience with GCP services: Cloud Run, PubSub, GCS, IAM/service accounts, Secret Manager
  • Comfortable with event-driven microservice architecture (this is not a monolith-style role)
  • Experience with revision-based/audit-trail data models
  • Ability to write and run Alembic migrations
  • Working experience with PostgreSQL (AlloyDB experience a plus)
  • Familiarity with Docker and containerized deployments
  • Experience with Terraform /Spacelift and GitHub Actions a plus

Nice to have:

  • Elasticsearch experience
  • Great organizational and time management skills
  • Availability to resolve urgent application issues outside business hours occasionally

**Remote the first 3 months, then starts hybrid scheme (2-3 days per week)**
