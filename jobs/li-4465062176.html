About Us

Worldmodeldata is building the trusted data backbone for the next generation of AI: World models and embodied AI. We extract millions of multi-modal, action-conditioned trajectories from video games — safe and controlled environments where every interaction is captured — and deliver them as training-ready datasets for the next generation of AI: world models and embodied AI. We are advised strategically by our senior science advisor prof. Yann LeCun, and are a lean, high-trust, well-funded team operating at high speed.

The Role

We are looking for a Senior Software Engineer with deep expertise in game engine internals, real-time graphics pipelines, and systems-level programming. 

This is a technically demanding role that sits at the intersection of game modding, real-time graphics, windows systems programming and low-level systems development and game technology. You will write mods and native hooks that run inside our game partner’s commercial game processes, pulling out synchronised streams of rendered frames, engine-internal buffers, scene state and player inputs. You will work alongside a small, highly capable team and be expected to own and drive significant technical decisions. The work spans the full path from a running game to a published dataset — capture, tooling, packaging and pipeline. 

Skills & Experience

Core Engineering

  • 5+ years of professional software engineering experience with strong fundamentals
  • Expert-level Rust, C++ and C# proficiency; ability to write clean, performant, production-grade code
  • Strong understanding of software architecture, system design, and engineering best practices
  • Comfortable leading technical projects end to end with minimal supervision

Game Engine & Graphics

  • Deep knowledge of Unreal Engine internals; familiarity with other major engines (Unity, Godot, id Tech, or similar)
  • Strong understanding of real-time rendering pipelines, including deferred rendering, G-buffer composition, depth buffers, and post-processing stages
  • Proficiency with graphics APIs — Direct3D (DX11/DX12), Vulkan, or OpenGL
  • Understanding of camera systems, scene geometry, object transforms, velocity buffers, and how engines represent and manage scene state at runtime

Systems & Low-Level Programming

  • Experience with binary analysis, memory inspection, or working with compiled game binaries and runtime internals
  • Familiarity with hooking, instrumentation, or interception techniques at the process or graphics API level
  • Understanding of how data flows from game state through to GPU execution
  • Knowledge of how to read, extract, and work with structured data from game processes at runtime

Data & Performance Awareness

  • Solid understanding of how games manage and stream data — assets, textures, scene graphs, spatial data structures
  • Awareness of GPU memory management, bandwidth constraints, and the performance implications of data access patterns
  • Ability to reason about latency and throughput when designing data capture or processing systems

What We're Looking For

  • Curiosity and resourcefulness when working in underdocumented or constrained environments
  • Ability to translate ambiguous technical problems into concrete, well-scoped engineering work
  • Comfortable working across both research-oriented exploration and production-quality delivery

Nice to Have

  • Familiarity with shader programming (HLSL, GLSL)
  • Prior experience in game development, game tooling, or the game modding community
