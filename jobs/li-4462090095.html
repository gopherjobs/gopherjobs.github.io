Senior IoT Software Engineer at BairesDev

In this role, you'll write and maintain the software that powers a scalable Azure IoT platform for connected equipment, from edge-side code to cloud services and APIs. Building fleet management capabilities, remote update systems, and automated health tooling, you'll bring strong software engineering practices to the unique challenges of IoT development. This is your opportunity to build production software across the full IoT stack, solving problems where connected devices, cloud services, and reliability engineering intersect.

What You'll Do

  • Develop software components for a scalable Azure IoT platform supporting connected equipment.
  • Build fleet management and remote update functionality.
  • Implement edge-to-cloud pipelines and the APIs that expose them.
  • Write monitoring and automated fleet-health tooling to ensure system reliability.

What We Are Looking For

  • 5+ years of experience in software engineering.
  • Strong experience developing on the Azure IoT platform.
  • Hands-on experience building fleet management and remote update systems.
  • Experience developing edge-to-cloud pipelines and APIs.
  • Background developing for Linux edge devices and industrial protocols.
  • Advanced proficiency in English.
