Position Overview

We are seeking an experienced Software Engineer in Vietnam to design, build, integrate, and support reliable software solutions for internal initiatives and client projects. This role combines backend development, data and database work, ETL pipelines, data administration, and the development of practical web interfaces.

The successful candidate will translate business and technical requirements into maintainable solutions, collaborate with stakeholders across time zones, troubleshoot production issues, and contribute to engineering standards, documentation, and continuous improvement.

Key Responsibilities

- Design, develop, test, deploy, and maintain software for client projects and internal products

- Build and support data-driven applications, services, integrations, and automation workflows

- Develop and maintain ETL pipelines that extract, transform, validate, and load data across systems

- Design, query, optimize, and administer relational and non-relational databases

- Build and maintain secure, responsive web interfaces for operational and customer-facing use cases

- Translate requirements into technical designs, implementation plans, and dependable releases

- Investigate defects, performance issues, data-quality problems, and production incidents

- Create technical documentation, runbooks, data mappings, and implementation notes

Primary Responsibilities

- Develop backend services, APIs, scheduled jobs, and system integrations

- Perform data modeling, database design, query optimization, migration, backup, and routine data administration

- Implement ETL processes with appropriate validation, logging, monitoring, retry, and error-handling controls

- Build lightweight web interfaces, dashboards, administrative tools, and workflow screens as needed

- Integrate applications with databases, third-party APIs, cloud services, and client systems

- Write clean, modular, testable, and well-documented code

- Participate in code reviews, testing, release planning, and production deployments

- Apply secure development practices, access controls, and data-protection requirements

- Communicate progress, risks, dependencies, and technical tradeoffs clearly to project stakeholders

- Coordinate technical work with internal teams, clients, vendors, and service providers

Secondary Responsibilities

- Support data imports, exports, cleansing, reconciliation, and reporting requests

- Monitor applications, jobs, databases, and integrations for reliability and performance

- Conduct root-cause analysis for recurring software and data issues

- Contribute to cloud infrastructure, CI/CD, containerization, and deployment automation

- Assist with solution estimates, technical discovery, and architecture discussions for client projects

- Maintain development environments and support quality assurance and user acceptance testing

Required Qualifications

- Strong professional English communication skills, both written and verbal

- 4+ years of professional software engineering or application development experience

- Proficiency in at least one general-purpose programming language such as Python, C#, Java, JavaScript/TypeScript, or a comparable language

- Strong SQL skills and practical experience with relational databases such as PostgreSQL, SQL Server, or MySQL

- Experience with database design, data modeling, query optimization, migrations, and routine data administration

- Experience building or maintaining ETL pipelines, data integrations, or scheduled data-processing workflows

- Experience developing web interfaces using modern frontend technologies or server-rendered web frameworks

- Familiarity with Git, code review, automated testing, and software release practices

- Ability to independently troubleshoot application, integration, database, and data-quality issues

- Experience gathering requirements and delivering solutions for client projects or multiple stakeholders

- Excellent analytical, organizational, prioritization, documentation, and collaboration skills

- Experience with data tools or frameworks such as SQL Server Integration Services, Azure Data Factory, Airflow, dbt, pandas, or equivalent

- Experience with JavaScript/TypeScript frameworks such as React, Vue, or Angular

- Familiarity with Docker, CI/CD pipelines, infrastructure-as-code, or configuration management tools

- Knowledge of secure software development, authentication, authorization, secrets management, and data privacy practices
