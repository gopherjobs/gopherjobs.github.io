Description

En FEMSA generamos valor económico y social y buscamos ser el mejor empleador y vecino. A través de nuestras Divisiones de Proximidad, Salud y Digital y Unidades de Negocio Coca-Cola FEMSA y FEMSA Negocios Estratégicos, empleamos a más de 354 mil personas en los países donde tenemos presencia.

Título del Puesto: Líder Técnico de Plataformas Web Reporta a: Experto Diseño Técnico

Área: Desarrollo y Entrega de Soluciones

Ubicación: Monterrey, Nuevo León.

Misión Del Puesto Liderar el diseño, evolución y gobernanza de la arquitectura para soluciones web basadas en la nube. Serás el referente técnico responsable de asegurar que las aplicaciones (Java/Angular) desplegadas en Azure sean escalables, seguras y eficientes, alineando las capacidades tecnológicas con las necesidades estratégicas de negocio y garantizando la continuidad del roadmap tecnológico.

Contribuciones Principales Arquitectura de Soluciones Web: Definir y documentar arquitecturas de referencia para aplicaciones web, utilizando Spring Boot para el backend y Angular para el frontend, asegurando su correcta integración en el ecosistema de Azure.

Liderazgo Técnico en Cloud: Supervisar la implementación de servicios de Azure (App Services, Azure Functions, API Management, Azure SQL) para optimizar el rendimiento y la disponibilidad de las plataformas.

Gobernanza y Estándares: Establecer y auditar estándares de codificación, seguridad (OWASP) y mejores prácticas de diseño para el stack Java/Angular.

Estrategia DevOps: Definir y optimizar la estrategia de CI/CD (Azure DevOps) para automatizar el ciclo de vida del software, garantizando despliegues ágiles y sin fricciones.

Mentoria y Code Review: Realizar revisiones de código críticas y guiar a los equipos de desarrollo (fábricas de software) para elevar la calidad técnica de las entregas.

Evolución Tecnológica: Dictaminar cambios y actualizaciones en el roadmap de Java, Angular y servicios de Azure para evitar la obsolescencia tecnológica.

Perfil Técnico Requerido (Stack) Backend: Java 11/17+, Spring Boot (Data, Security, Cloud).

Frontend: Angular 12+ (Typescript, RxJS, State Management).

Cloud (Azure): Experiencia sólida en Azure App Services, Key Vault, Azure Service Bus, y gestión de contenedores (AKS/Docker).

Herramientas de Arquitectura: Enterprise Architect o modelado UML/C4.

Base de Datos: Oracle Database y conocimiento en bases de datos NoSQL o Azure SQL
