About The Role AspenView Technology Partners is seeking a Senior API Engineer / Architect to help build a leading omnichannel enterprise commerce platform serving large hoteliers and multi-property operators in the Travel & Hospitality sector. In this role, you will architect and build REST APIs and integrations on .NET / C# using Apigee and AWS—powering omnichannel acceptance, cross-property reconciliation, currency conversion, and split settlement. Working as an embedded, client-side collaborator aligned to U.S. Eastern (EST) hours, you will set the architectural standards that enterprise build teams rely on to deliver secure, scalable, SLA-ready services.

What You Will Do API Architecture

  • Design REST API architecture for enterprise, multi-tenant commerce.
  • Set standards for contracts, versioning, and reuse.

Enterprise Integration

  • Integrate ERP and e-commerce systems, and manage APIs with Apigee.
  • Support omnichannel acceptance and reconciliation across properties.
  • NET Services
  • Build C# / .NET enterprise B2B services on AWS.
  • Design for scale, resilience, and enterprise SLAs.

Security & Compliance

  • Apply web-service security, SSL mutual authentication, and Azure AD.
  • Work within financial-compliance platform requirements.

Success Indicators

  • Enterprise APIs are well-architected, secure, and scalable.
  • Cross-property reconciliation and settlement are reliable.
  • Integrations meet enterprise SLAs.
  • Standards are adopted across build teams.
