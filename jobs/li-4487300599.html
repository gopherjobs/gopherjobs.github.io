Description

About the Role

We are looking for a Full Stack Developer to build backend services with Java and Spring Boot, support the Angular frontend, and help move the architecture toward domain-driven design.

The mandatory requirements are strong transactional SQL expertise with Oracle or PostgreSQL on high-transaction enterprise platforms, 4+ years with Java (Spring Boot) and Angular, JPA/Hibernate, RESTful API design, object-oriented design and design patterns, and an upper-intermediate English level.

What you will do

  • Core Development: Spend the majority of your time (approx. 70-80%) designing and implementing robust backend services using Java and Spring Boot .
  • Frontend Integration: Build and maintain the supporting Angular frontend, ensuring a seamless connection between the UI and your backend logic.
  • Modernizing Architecture: Lead the transition from traditional database-centric designs toward a domain-driven structure (DDD).
  • API Excellence: Architect RESTful APIs that prioritize proper HTTP verbs and clean, scalable patterns over legacy RPC styles.
  • Collaboration: Work within cross-functional squads to deliver high-quality features while maintaining the "cohesive and proactive" spirit of the team.

Must haves

  • Core Stack: Advanced proficiency in Java (Spring Boot) and a solid working knowledge of Angular , with at least 4 years of experience .
  • Design Fundamentals: A strong grasp of Object-Oriented Design (OOD) and software design patterns.
  • API Knowledge: Deep experience building and consuming RESTful services with a clear understanding of standard API protocols.
  • Database & Advanced SQL (Strict Rejection Criteria): Experience working with relational databases ( PostgreSQL, Oracle ) and JPA/Hibernate . Candidates must have robust transactional database experience (Oracle, Postgres), strong SQL skills to navigate and optimize very complex SQL in KALC, and a thorough understanding of enterprise-level, high-transactional platforms. Lacking this specific database proficiency will be a direct reason for rejection.
  • The "Backend-Heavy" Mindset: A passion for server-side logic, performance, and architecture.
  • Upper-intermediate English level.

Nice to haves

  • Highly desirable: Experience working with spec-driven development or related (AI-Driven Software Development Life Cycle).
  • Domain Experience: Previous experience in the Loyalty or Fintech sectors.
  • Experience with cloud platforms ( AWS or Azure ) and containerization ( Docker ).
  • Knowledge of CI/CD pipelines ( Jenkins, GitLab CI ).
  • Experience refactoring legacy structures into modern, domain-driven architectures.

Perks

  • Growth without limits: build your skills through mentorship, internal TechTalks, challenging projects, and a dedicated annual learning budget
  • Competitive compensation: get recognition that reflects your skills and impact, with regular performance and compensation reviews
  • Flexibility: work 100% remotely with flexible hours that support focus, autonomy, and a healthy work rhythm
  • Meaningful, modern projects: build impactful products using modern technologies alongside global teams and leading brands
  • Collaborative culture: join a supportive environment with zero micromanagement where ideas are welcomed and contributions are recognized
  • Well-being & support: access local well-being programs and people-focused support tailored to your location
