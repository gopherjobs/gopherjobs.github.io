What we’re looking for:

  • Proficiency in Java and the Quarkus framework for application development.
  • Strong experience in designing, developing, and maintaining RESTful APIs using OpenAPI standards.
  • Solid understanding of core software engineering principles, including Clean Code, SOLID, and basic Domain Driven Design (DDD).
  • Familiarity with event-driven architecture; hands-on experience with Apache Kafka is highly advantageous.
  • Expertise in writing comprehensive unit tests and proficiency with GIT for version control.
  • Exposure to implementing observability and monitoring practices, with knowledge of OpenTelemetry being a plus.
