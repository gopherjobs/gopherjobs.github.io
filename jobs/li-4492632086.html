Introduction

Build and maintain software that connects data and AI capabilities to everyday public services. You’ll join a multidisciplinary team delivering secure, testable features for a UK public-sector organisation.

Key Responsibilities

• Develop and maintain application features, APIs and integration components for data-driven services.

• Validate requests and responses, handle service failures safely and integrate authentication, authorisation and audit logging.

• Integrate analytics or AI services where required, including human review and fallback paths for unavailable or low-confidence outputs.

• Write unit and integration tests, review code and use CI/CD pipelines to release changes across environments.

• Instrument applications with logs, metrics and traces. Diagnose defects and document operational procedures and dependencies.

Essential Skills & Experience

• Experience developing production services and integration components in C#/.NET or Python, with sound API and database design.

• REST API development and integration, including JSON, OpenAPI or equivalent API contracts, authentication and error handling.

• Practical SQL and relational database experience, including query troubleshooting and safe schema changes.

• Git, peer review and CI/CD such as Azure DevOps Pipelines, with automated unit and integration testing and experience deploying to Azure or comparable cloud infrastructure.

• Secure coding, identity integration (such as Microsoft Entra ID), secrets management and production observability.
