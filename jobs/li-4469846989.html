Role Overview

We are looking for an experienced Software Engineer to design, build, and maintain internal tooling supporting Future State Architecture (FSA) across technology platforms. The role combines backend engineering, web UI development, AI agent orchestration, and enterprise integration.

Key Responsibilities

  • Design, build and maintain production-grade internal tooling supporting Future State Architecture.
  • Develop backend services and APIs using Node.js and/or Java , integrating with PostgreSQL and other enterprise data sources.
  • Build and enhance web UI components using modern JavaScript/TypeScript frameworks .
  • Apply agentic engineering practices to orchestrate autonomous AI agents that can build, test and deploy software.
  • Implement integration patterns such as MCP, tool/function calling, and API integration .
  • Collaborate with architects, platform engineers and stakeholders to translate architecture requirements into technical solutions.
  • Ensure solutions meet standards for security, performance, resilience, testing, observability and documentation .
  • Contribute to code reviews, automation, continuous improvement and operational support for live services.

Essential Skills & Experience

  • 10+ years of software engineering experience.
  • Strong experience with Node.js and/or Java .
  • Strong PostgreSQL experience, including data modelling and query optimisation.
  • Experience with modern JavaScript/TypeScript web frameworks .
  • Knowledge of agentic application engineering and autonomous AI agent orchestration.
  • Experience with MCP, tool/function calling and API design .
  • Strong production engineering mindset covering security, resilience, performance, observability and automated testing.
  • Experience with solution design and architecture for internal platforms/tooling.
  • Strong English communication and stakeholder management skills in a global environment.
