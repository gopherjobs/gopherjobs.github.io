Responsibilities Job Summary

  • Design, build, and maintain high-performance, scalable enterprise applications from conception to production within an agile environment.
  • Leverage advanced AI tools and agents to accelerate development, including prompt engineering, automated code reviews, refactoring, and comprehensive unit testing.

Requirements And Skills

  • Bachelor’s degree in computer science or engineering related field
  • 5+ years of extensive hands-on experience in Python, combined with a commitment to employing best practices and efficient development techniques leveraging AI tools.
  • Expert in leveraging AI-driven development tools to automate code generation, perform intelligent debugging, and ensure code compliance with engineering standards.
  • Proficiency in architecting and deploying scalable, cost-optimized solutions utilizing core AWS services, including Lambda, OpenSearch, DynamoDB, RDS, and CloudFront.
  • Ability to architect fault-tolerant, and highly available systems on AWS using AWS CDK / Serverless framework
  • Having knowledge on one of the public cloud platforms (e.g. Microsoft Azure, Google Cloud) is a plus
