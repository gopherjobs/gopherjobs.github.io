Job overview

We run an AI guardrails platform — a pipeline of 20+ validators that screen text, images, documents for safety and compliance risks (toxicity, PII, NSFW, violence/self-harm, jailbreak, prompt injection, copyright, brand, language, anomaly/zero-day). Today many validators rely on external LLM/vision APIs. Your job is to build the guardrail system and ship our own models so each validator runs on models we own, control, and can optimize for cost and latency — and to write the software that serves them.

Key Responsibilities:

  • Fine-tune models for validators — intent, toxicity, sensitive topic, jailbreak, prompt injection, PII, NSFW/violence...detectors, language and anomaly detectors and embeddings for retrieval.
  • Build the model pipeline — data prep → training → evaluation (precision/recall per validator) → serving, with iteration driven by metrics, not vibes.
  • Optimize for serving — quantization, distillation, ONNX/TensorRT/vLLM, latency-vs-accuracy trade-offs so validators run fast at scale.
  • Build the backend that wraps each model behind APIs — request routing, batching, async, caching, logging.
  • Build the web frontend for configuration, validator results, evaluation, and analytics dashboards.
  • Handle multimodal — image and document inputs (transcription, OCR → downstream classifiers).

We're looking for

  • 5+ years in software, with real time spent training/tuning models or building generative AI applications.
  • Hands-on fine-tuning of transformer models — classifiers, embeddings. You can take a base model, prepare data, train, evaluate, and deploy.
  • ML & NLP frameworks — PyTorch, TensorFlow, Hugging Face, spaCy, nltk, scikit-learn. Fluent in datasets, training loops, eval, and checkpointing. Familiar with MLOps
  • Solid backend — Golang, Python (FastAPI/Flask), APIs, queues, databases, model serving.
  • Data discipline — labeling, cleaning, augmentation, versioning, and honest evaluation.
  • Deployment — Docker, a cloud (AWS/GCP), CI for both code and models.

Nice to have

  • Production content-moderation / safety experience.
  • Model serving optimization — quantization, ONNX, vLLM, TensorRT.
  • Multimodal work — image/audio/video classification.
  • Information retrieval / search / RAG.
