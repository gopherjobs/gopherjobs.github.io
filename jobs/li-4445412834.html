Role Summary The Software Engineer 2 role is focused on supporting, maintaining, and incrementally improving the automation, tooling, and release processes that help Sophos engineering teams deliver cloud-based services safely and consistently. This role is hands-on and execution-oriented, working with software engineers, platform engineers, QA, security, and release stakeholders to support CI/CD pipelines, cloud infrastructure, Kubernetes-based environments, and developer tooling. The ideal candidate has solid technical fundamentals, is eager to learn, communicates clearly, and can troubleshoot issues in Linux environments while writing practical automation in Groovy, Python, and Bash. Experience using approved AI-assisted engineering tools responsibly to improve productivity, documentation, troubleshooting, and operational insight is a plus.

What You Will Do

  • Support CI/CD pipelines and release automation for SaaS applications, microservices, and containerized workloads.
  • Support developer and release tooling such as GitHub, Jenkins, Artifactory, and related CI/CD systems.
  • Deploy, configure, and troubleshoot application builds across development, QA, and production environments.
  • Assist with Kubernetes and Amazon EKS-based deployments, environment health checks, configuration updates, and operational readiness activities.
  • Use Terraform to help provision and maintain cloud infrastructure in a consistent, repeatable, and reviewable way.
  • Write and maintain automation scripts in Groovy, Python, and Bash under guidance to reduce manual release, build, and environment-management work.
  • Work with development teams to understand build, deployment, and environment needs, then contribute to practical automation and process improvements.
  • Troubleshoot build, deployment, infrastructure, and environment issues by reviewing logs, pipeline output, Linux systems, and cloud service behavior.
  • Support secure development and DevSecOps practices, including security scanning and compliance-related tooling integrations.
  • Use approved AI tools to assist with scripting, troubleshooting, documentation, log analysis, and workflow improvement while following company security, privacy, and code-review expectations.
  • Maintain clear communication about environment state, deployed versions, release status, availability, risks, and next steps.
  • Participate in on-call or operational support rotations as needed for supported services and release infrastructure.

What You Will Bring

  • 2+ years of experience in platform engineering, DevOps, release engineering, infrastructure automation, software engineering, or a closely related role.
  • Able to complete well-scoped engineering tasks with moderate independence.
  • Familiarity with AWS cloud services, especially services commonly used for compute, identity, storage, messaging, monitoring, and container platforms. Azure experience is a plus.
  • Working knowledge of Kubernetes concepts; Amazon EKS experience is a plus.
  • Experience with Docker and container-based application delivery.
  • Strong Linux fundamentals, including command-line troubleshooting, shell scripting, process inspection, permissions, networking basics, logs, and system services.
  • Ability to investigate build failures, deployment failures, environment issues, cloud infrastructure behavior, and application runtime problems with support from senior engineers.
  • Practical scripting experience with one or more of Groovy, Python, or Bash.
  • Familiarity with CI/CD pipelines and release automation using tools such as Jenkins and GitHub Actions.
  • Familiarity with release practices such as branching, tagging, versioning, artifact promotion, rollback planning, and progressive deployments.
  • Experience with developer and artifact tooling such as GitHub and Artifactory.
  • Familiarity with common build tools such as Gradle, Maven, or npm.
  • Familiarity with infrastructure-as-code and configuration/provisioning tools such as Terraform, Ansible, Packer, and Chef; hands-on Terraform experience is strongly preferred.
  • Basic understanding of secrets management, certificates, SSL/TLS concepts, and secure automation practices.
  • Exposure to DevSecOps tools such as Black Duck, Prisma Cloud, or similar scanning platforms is a plus.
  • Experience using AI-assisted engineering tools to improve productivity, generate or review scripts, summarize logs, draft documentation, or explore technical options, with good judgment around security and accuracy.
  • Clear written and verbal communication skills, especially when coordinating releases, environment status, risks, and troubleshooting updates across teams.
