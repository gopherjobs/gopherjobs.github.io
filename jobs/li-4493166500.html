About the role

We're hiring Full-Stack Developers who own features end to end — database, API, UI and deployment.

Nexus Analytica is an energy analytics company with offices in Cairo and Amsterdam. We combine consultancy with in-house digital products for utilities, renewable energy developers, regulators and development agencies across Egypt, MENA and Africa: 50+ projects since 2019 and 7 in-house products. Our engineers work full-stack: there are no separate frontend and backend queues, and every developer ships complete features.

What you'll build

You'll work on production platforms that run real energy assets, not demo apps.

  • Renewable energy park management: live meter readings, remote commanding, automated monthly invoicing under power purchase agreements, maintenance and compliance, with role-based access for every stakeholder.
  • Real-time monitoring of solar, wind, hydro and battery sites, with ML-based fault prediction and automated reporting.
  • Carbon and greenhouse gas monitoring tools for companies and banks.
  • E-mobility tools for EV charging and charge scheduling.
  • Billing, net-metering and dashboard solutions built for utilities and project developers.

Responsibilities

  • Own features end to end: data model, Django REST API, React interface, tests and deployment.
  • Build real-time features such as live meter readings and remote commands over WebSockets, and background jobs with Celery.
  • Turn energy-domain logic — metering, PPA invoicing, KPIs — into reliable code, working closely with our energy analysts and engineers.
  • Build data-heavy dashboards and charts that work well on desktop and mobile.
  • Improve existing code: refactor, fix performance issues, add test coverage and reduce technical debt.
  • Integrate data from meters, gateways and external APIs, including time-series data.
  • Ship through CI/CD with Docker on Azure, and monitor and fix production issues.
  • Review teammates' code and keep technical documentation current.
  • Support client proposals with solution design and effort estimates.

Requirements

  • 3+ years building and shipping web applications in production, with real work on both frontend and backend.
  • Backend: Python, Django and Django REST Framework; REST API design; JWT authentication and role-based permissions.
  • Frontend: React with hooks, state and data-fetching tools (Redux Toolkit, React Query), JavaScript/TypeScript, HTML/CSS and a component library such as Material UI.
  • Databases: SQL and relational modelling (MySQL or PostgreSQL), migrations and query performance.
  • Async and real-time: Celery with Redis, and WebSockets (Django Channels).
  • Delivery: Git, Docker, CI/CD pipelines and at least one cloud platform (Azure preferred).
  • Testing: unit and integration tests (pytest, Jest or React Testing Library).
  • Hands-on experience using AI coding tools in day-to-day development.
  • Clear written and spoken English; our clients and partners are international.
  • BSc in Computer Science, Computer Engineering or a related field, or equivalent experience.

Nice to have

  • Data visualisation with D3 or similar charting libraries.
  • Time-series and IoT data: smart meters, SCADA, Modbus or MQTT.
  • Building AI features into products: LLM APIs, retrieval (RAG), agents and tool integrations.
  • Machine learning basics for forecasting and anomaly detection (pandas, scikit-learn).
  • Energy-sector knowledge: PV and wind plants, PPAs, tariffs or grid operations.
  • Azure services: Container Registry, Functions, App Service.
  • Odoo development.
  • Arabic.
