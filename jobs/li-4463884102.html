Description

Description We are seeking a Senior Software Engineer to join our Core Compute team, managing the application and orchestration layers that allow virtual machines to run seamlessly for our customers across the cloud ecosystem. We are embarking on a strategic project to integrate a new ARM-based multi-core multi-processor into our infrastructure. This initiative involves porting our orchestration stack from x86 to ARM, updating QEMU configurations, and optimizing NUMA memory allocation logic to prepare the platform for future integrations.

Requirements Preferred qualifications & skills:

  • Education & experience: Bachelor of Science in Computer Science, Engineering, or a related field, plus extensive commercial experience in cloud orchestration.
  • Core Languages: Strong proficiency in Go and Perl (Perl is the primary language for our codebase).
  • Virtualization & OS: Deep knowledge of Linux OS internals, QEMU orchestration, and CPU flag management.
  • Architecture: Understanding of ARM architecture, memory unified models, and CPU-to-CPU inter-process communications.

Nice to have skills:

  • Familiarity with Python for control plane operations.
  • Previous experience dealing with NUMA allocation logic.

Job responsibilities

  • Port and upgrade existing x86 orchestration codebases (primarily Go and Perl) to ensure full compatibility with the new ARM architecture.
  • Manage and update QEMU flag configurations and networking feature support tailored for the ARM based platform.
  • Evaluate and tune NUMA memory allocation logic in Python to maximize performance for the multi-core, multi-processor hardware.
  • Perform initial code analysis to identify and refactor architecture specific implementation
