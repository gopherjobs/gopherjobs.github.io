Description

About The Role X Shore is rebuilding operations and product development under new ownership. We are looking for a Full Stack Developer to own the software our customers see and use — the interface on board the boat, the mobile app, and the cloud environment behind them.

The emphasis is frontend: the onboard interface is a React application running on the boat’s Linux-based IoT gateway, and it is what an owner touches every time they step on board. The cloud environment, the telemetry platform, the customer API, and remote access to the fleet come with it. The whole stack is yours — you decide how it looks, how it is built, and how it runs.

The role is hybrid, with regular days on-site in Nyköping — the onboard interface has to be tried on a real gateway in a real boat, not only in a browser.

Role Purpose Own the customer-facing software stack — the onboard interface, the mobile app, the cloud environment, and the telemetry platform and API behind them — and keep it running as one coherent product.

Core Mission Make the digital side of an X Shore boat feel finished, and make the data the fleet produces something owners, customers, and colleagues can rely on.

Key Responsibilities

  • Develop and maintain the onboard user interface — a React application running on the boat’s Linux-based IoT gateway
  • Design, build, and release the X Shore mobile app for iOS and Android
  • Keep the experience consistent across boat and app, working with our external design partner on what goes out and what is faster done in-house
  • Own our cloud environment: the hosted telemetry platform, the services we run ourselves, deployments, monitoring, access control, and cost
  • Run and develop ThingsBoard as our telemetry platform — device profiles, ingestion, dashboards, retention, and upgrades
  • Own the customer-facing API: maintain and develop it, with authentication, versioning, documentation, and support for the customers integrating with it
  • Build and maintain the backend services the app, the boat interface, and the API depend on
  • Manage remote access to boats in the field
  • Take responsibility for the operation of the customer-facing services — and make sure we notice problems before customers do
  • Work with the embedded team on the boat-to-cloud boundary: what data leaves the boat, in what form, and how often

Technical Depth — What We Need The X Shore customer experience runs on three surfaces: a React application on a Linux-based IoT gateway on board, a mobile app, and a cloud environment where a hosted ThingsBoard platform collects telemetry from the fleet. Alongside it sits the remote access we use to reach boats in the field. We are open on years of experience — we hire on demonstrated skill — and we expect frontend depth first, with enough backend, cloud, and operational capability to keep the rest running properly.

  • Build production React interfaces — including for a fixed onboard screen used in sunlight, with wet hands, while driving a boat
  • Build and release a mobile app to the App Store and Google Play — we lean towards React so the app and the onboard interface share one ecosystem, but the choice is open if you can argue for something better
  • Operate our cloud services: configuration of the hosted platforms we rely on, the services we run ourselves, deployment pipelines, certificates, secrets, monitoring, and alerting
  • Run an IoT telemetry platform — ThingsBoard in our case: telemetry ingestion, dashboards, and rule chains
  • Maintain and develop the REST API that external customers depend on: authentication, versioning, rate limiting, and documentation people can work from without asking us
  • Write backend services and handle time-series data at fleet scale — storage, retention, and queries that stay fast as the fleet grows
  • Debug across the whole path: from a signal on the boat, through the gateway, to a value in a dashboard or an app screen
  • Use AI tools as a normal part of development — writing, reviewing, and analysing code — while staying accountable for what goes into production
  • Judge where effort belongs: what has to be robust, what can stay simple, and what should not be built at all

What We Offer At X Shore you get the chance to be part of an exciting journey with significant responsibility and real impact. What you build is what an owner sees every time they step on board, and what a customer sees every time they look at their fleet — with the freedom to shape the whole stack rather than one layer of it.

This is not a maintenance role. It is a building role — the interface, the app, and the platform decisions you make now will define the digital side of X Shore for years to come.
