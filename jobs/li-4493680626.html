Role Summary

We are hiring for an AI/ML Software Engineer - Localization Engineering to work on a project focused on intelligent localization systems and AI-powered translation technologies. The selected candidate will build scalable backend solutions, develop and fine-tune transformer-based models, and improve end-to-end localization workflows using modern AI/ML technologies.

Key Responsibilities

  • Design and develop AI-powered localization workflows integrating Neural Machine Translation (NMT) and Large Language Models (LLMs).
  • Build and improve translation quality estimation systems using COMET, BLEURT, and custom LLM-based evaluators.
  • Develop and fine-tune Automated Post-Editing (APE) solutions to improve translation quality, terminology accuracy, and consistency.
  • Fine-tune transformer-based models using Hugging Face and domain-specific translation memory and glossary data.
  • Build scalable backend services, APIs, and microservices to support automated localization workflows.
  • Integrate product systems, Translation Management Systems (TMS), content repositories, and CI/CD pipelines.
  • Develop automation frameworks for content extraction, file processing, translation handoff, validation, and linguistic quality assurance.
  • Optimize model performance, inference latency, and cloud deployment using AWS services such as SageMaker and Bedrock.
  • Build Python pipelines for multilingual data processing, sentence alignment, tokenization, and fuzzy matching.
  • Benchmark translation performance using BLEU, chrF++, TER, COMET, and other NLP evaluation metrics.
  • Collaborate with localization program teams, product engineering teams, and external suppliers to improve localization processes.
  • Contribute to localization engineering standards, shared tools, frameworks, and AI-enabled translation practices.

Must-Have Skills

  • 4+ years of software engineering experience, with significant backend or AI/ML experience.
  • Strong proficiency in Python.
  • Experience working with transformer-based models, including Hugging Face or similar frameworks.
  • Hands-on experience training, fine-tuning, and deploying machine learning models.
  • Experience with AWS services such as SageMaker and Bedrock.
  • Strong experience building APIs, microservices, and system integrations.
  • Strong understanding of end-to-end localization workflows, including extraction, translation, review, quality assurance, and release.
  • Experience working with Translation Management Systems such as Phrase, Passolo, or similar platforms.
  • Experience with SQL/NoSQL databases and cloud-native architectures.

Nice-to-Have Skills

  • Experience implementing reference-free Quality Estimation (QE) systems.
  • Experience developing Automated Post-Editing (APE) solutions.
  • Familiarity with LLM orchestration frameworks such as LangChain.
  • Experience integrating localization workflows into CI/CD pipelines.
  • Knowledge of automated linguistic quality assurance and validation tools.
  • Background in NLP, computational linguistics, or multilingual data engineering.
  • Experience optimizing model inference performance and cost efficiency in production environments.
