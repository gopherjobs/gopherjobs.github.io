AI Engineer Junior – Célula GenAI

Descripción del cargo:

En ConKord estamos buscando AI Engineers Junior para sumarse a nuestra Célula GenAI, participando en un proyecto de Inteligencia Artificial Generativa de alto impacto.

Buscamos personas con una sólida base técnica, interés por la IA Generativa y los agentes basados en LLM, y motivación por desarrollar soluciones que lleguen a producción.

En este rol tendrás la oportunidad de implementar agentes conversacionales, automatizaciones e integraciones utilizando Python y AWS Bedrock, siguiendo diseños técnicos definidos por el Tech Lead/Arquitecto y participando en todo el ciclo de desarrollo: implementación, pruebas, validación, despliegue y documentación.

Un aspecto fundamental del rol será asegurar que las respuestas de los agentes estén respaldadas por datos reales obtenidos desde las APIs, realizando las validaciones necesarias antes de cada entrega.

REQUISITOS

  • Experiencia comprobable desarrollando con Python, especialmente en backend, servicios o APIs.
  • Experiencia utilizando FastAPI en al menos un servicio real.
  • Experiencia práctica con Git, incluyendo ramas, pull requests y resolución de conflictos.
  • Experiencia desarrollando soluciones de IA Generativa y agentes con LLMs.
  • Conocimientos de Prompt Engineering, definición de herramientas (tool-calling) y orquestación de agentes.
  • Experiencia integrando al menos un proveedor de modelos de lenguaje, como OpenAI, Gemini, Claude o AWS Bedrock.
  • Experiencia utilizando herramientas de codificación asistida por IA, como Claude Code, Cursor, Codex o similares.
  • Capacidad para validar las respuestas generadas por los modelos y comprender el código producido mediante herramientas de IA.
  • Orientación al problema de negocio y capacidad para comprender el caso de uso antes de implementar una solución.

Será un plus si cuentas con:

  • Experiencia con arquitecturas RAG o pipelines de recuperación de información.
  • Experiencia desplegando servicios en AWS.
  • Conocimientos de AWS Bedrock.
  • Conocimientos de React, Next.js o TypeScript.
  • Experiencia participando en reuniones con usuarios o clientes para levantar y validar necesidades.
  • Inglés nivel B1.

NIVEL EDUCACIONAL

  • Formación en carreras del área de Tecnología, Informática, Computación, Ingeniería de Software o carreras afines.
  • Más que un perfil académico orientado a ciencia de datos, buscamos una persona con una base sólida de desarrollo de software y experiencia práctica construyendo soluciones de IA Generativa.

FORMACIÓN

  • Desarrollo de software y programación, con foco en Python.
  • Desarrollo de APIs y servicios backend.
  • Inteligencia Artificial Generativa y Large Language Models (LLMs).
  • Prompt Engineering y desarrollo de agentes.
  • Integración de APIs de modelos de lenguaje.
  • Tool-calling y orquestación de agentes.
  • Git y buenas prácticas de desarrollo.
  • Deseable formación o experiencia en RAG, AWS y AWS Bedrock.

FUNCIONES:

  • Implementar agentes conversacionales y flujos de tool-calling utilizando Python y AWS Bedrock.
  • Integrar APIs corporativas y bases de conocimiento necesarias para los diferentes casos de uso.
  • Desarrollar las soluciones siguiendo el diseño técnico definido por el Tech Lead/Arquitecto.
  • Ejecutar pruebas para comparar las respuestas generadas por los agentes con los datos reales entregados por las APIs.
  • Documentar casos de prueba, resultados, manejo de errores y comportamiento esperado.
  • Generar evidencia que permita validar que las respuestas de los agentes provienen de datos reales.
  • Dar soporte técnico durante las evaluaciones realizadas por el cliente y corregir los hallazgos identificados.
  • Realizar despliegues en ambientes de desarrollo, pruebas y producción, de acuerdo con las aprobaciones correspondientes.
  • Participar en la estabilización de las soluciones después de cada salida a producción.
  • Aplicar estándares de desarrollo, control de versiones y buenas prácticas mediante Git.
  • Participar en code reviews junto con los demás AI Engineers del equipo.
  • Utilizar herramientas de codificación asistida por IA de manera habitual, revisando y validando el código generado.
  • Documentar el diseño técnico, prompts, herramientas y casos de prueba asociados a cada agente.
  • Comprender el problema de negocio antes de construir la solución y levantar oportunamente cualquier desviación de alcance o diseño.
