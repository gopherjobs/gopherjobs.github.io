Description

Position: Puzzle Solver

Type: Contract

Compensation: $50 - $80/hour

Location: Remote

Commitment: 10-40 hrs/week

Role Responsibilities

  • Solve self-contained coding, logic, debugging, and technical reasoning challenges.
  • Analyze unfamiliar problems and translate their requirements into implementable solutions.
  • Select appropriate algorithms, data structures, and problem-solving strategies.
  • Work inside terminal-based development environments and existing codebases.
  • Implement correct and efficient solutions using an appropriate programming language.
  • Identify ambiguous requirements, edge cases, hidden assumptions, and failure conditions.
  • Debug incorrect behavior across code, tests, dependencies, and environment configuration.
  • Develop tests and verification methods that distinguish genuinely correct solutions from superficially plausible ones.
  • Review AI-generated solutions and identify logic errors, incomplete reasoning, and constraint violations.
  • Produce clear, reproducible solutions that can be executed and evaluated automatically.

Requirements

  • Strong algorithmic problem-solving ability.
  • Proficiency in at least one general-purpose programming language such as C++, Python, Java, Rust, Go, C#, JavaScript, or TypeScript.
  • Strong understanding of common data structures and algorithms.
  • Ability to reason carefully about constraints, complexity, edge cases, and correctness.
  • Experience debugging unfamiliar code or solving technically ambiguous problems.
  • Ability to work independently in terminal-based development environments.
  • Ability to produce reproducible, testable software solutions.
  • Clear written and verbal technical communication.
