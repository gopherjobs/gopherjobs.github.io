We hire the best software engineers, but experience in our stack can’t hurt: NinjaOne is built on Java, Kotlin, C++, Golang and Postgres, supporting millions of user endpoints and running as a scalable cloud service in AWS. Knowing large-scale datastore bottlenecks, asynchronous application design and client-server architecture is crucial for this role.

Ninja Remote is NinjaOne's remote access and control product. It gives IT teams secure, low-latency connections into managed endpoints at scale, across environments. It's a core piece of NinjaOne, tightly integrated with our broader RMM platform, and relied on daily by IT professionals to troubleshoot, support, and manage fleets of devices remotely.

The team spans C++ agent engineers, UI engineers, and backend engineers, working together on everything from the low-level agent that runs on endpoint devices to the cloud services that negotiate and sustain remote sessions in real time. On the backend side, the focus is on the signaling and session infrastructure that connects technicians to remote endpoints: connection negotiation, session state, streaming data paths, and reliability of communication between the C++ agent and the cloud backend across a distributed, multi-region environment.
