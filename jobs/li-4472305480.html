We’re Hiring: Full Stack Developer (Backend Focus), Senior-Level | Remote – Egypt

At Globant, we are working to make the world a better place, one step at a time. We enhance business development and enterprise solutions to prepare them for a digital future. With a diverse and talented team present in more than 30 countries, we are strategic partners to leading global companies in their business process transformation.

We are seeking a Full Stack Developer — Backend Focus who shares our passion for innovation and transformation. This role is critical in building scalable, reliable, and content-driven digital solutions for leading tourism platforms, with a strong focus on Python, Django, REST APIs, and PostgreSQL .

What You Will Be Doing

  • Building Django backend features — models, views, REST API endpoints, migrations
  • Designing APIs that a separate frontend team will consume
  • Writing automated tests and keeping test coverage high
  • Working in Wagtail CMS to build and configure content page types
  • Reviewing code and helping keep the codebase clean as the team grows
  • Making small changes on the frontend (React) when needed to unblock end-to-end work

Must Have

  • 3+ years of professional experience as a backend or full stack developer
  • Python + Django — at least 2 years of real, hands-on Django work: models, ORM, views, Django REST Framework
  • PostgreSQL — comfortable writing migrations and working with relational data
  • REST API design — experience building APIs that other developers or a frontend team consume in production
  • Automated testing — experience writing unit/integration tests and caring about coverage, not just writing code that "works"
  • Git — comfortable with branches, pull requests, and code review
  • Comfortable using AI coding assistants (Claude Code, GitHub Copilot, Cursor, or similar) as part of your daily workflow

Nice to Have

  • Wagtail CMS experience — most candidates won't have this, general Django knowledge transfers fine
  • Docker
  • React — enough to read frontend code and debug integration issues
  • Redis or Celery — background jobs or caching
  • Experience on large, content-heavy websites

The Stack

  • Backend: Django + Wagtail + PostgreSQL
  • Frontend: React + TypeScript
  • Testing: pytest
  • Infra: Docker + CI/CD
  • Tools: Claude Code and similar AI coding assistants
  • Communication: Slack + Google Meet

This position can be based in Egypt and is remote .
