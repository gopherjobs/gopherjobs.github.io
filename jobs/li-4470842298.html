About the Role

We are seeking an experienced Senior Full-Stack Developer with 8+ years of hands-on software development experience, building scalable web applications and cloud-native solutions.  You will support a live, feature-complete Studio product in production, with a focus on maintenance, new feature delivery, and incremental backend API improvements. The role is approximately 70% backend and 30% frontend, working mainly with Node.js, NestJS, Angular, Docker, and Docker Compose.

All services are containerised using Docker and deployed on Google Cloud Run via Artifact Registry. You will work within an existing team and codebase, following established engineering patterns and deployment processes.

Responsibilities

  • Maintain and enhance a live, customer-facing production platform

  • Design, develop, and maintain backend services using Node.js/NestJS

  • Contribute to Angular-based frontend development where required

  • Build and improve REST APIs and maintain API documentation using Swagger/OpenAPI

  • Support production systems running on Google Cloud Platform (GCP), ensuring reliability, stability, and availability

  • Manage production deployments through established CI/CD pipelines and deployment processes

  • Troubleshoot production incidents, investigate root causes, and implement appropriate resolutions

  • Work with Docker-based containerised applications and cloud-hosted services

  • Follow established development, staging, and production release processes

  • Collaborate through code reviews and follow existing engineering standards and deployment patterns

  • Independently design, document, and deliver technical solutions

  • Use AI-assisted development tools as part of the engineering workflow

Requirements

  • 4+ years of professional experience with Node.js and/or NestJS

  • 3+ years of experience with Angular

  • 1.5+ years of experience with React

  • 4+ years of experience designing and developing REST APIs

  • 3+ years of experience with Docker and containerised applications

  • 2+ years of hands-on DevOps experience supporting live production environments, including CI/CD pipelines, production deployments, monitoring, incident resolution, and operational support

  • 2+ years of hands-on experience managing customer-facing production workloads on Google Cloud Platform (GCP)

  • Experience with GCP services such as GKE, Cloud Run, Compute Engine, Cloud Storage, Pub/Sub, Cloud SQL, or equivalent

  • Experience working with automated CI/CD pipelines and deployment processes

  • Experience producing and maintaining Swagger/OpenAPI documentation

  • Experience working within microservices-based architectures

  • Ability to independently design technical solutions and APIs

  • Ability to work independently while collaborating within an established engineering team

  • 1+ year of experience using AI-assisted development tools such as Claude, MCP, LLM APIs, or similar

Nice to Have
