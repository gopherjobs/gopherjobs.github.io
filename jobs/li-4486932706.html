Description

  1. Tổng quan vai trò

Tech Lead C-GOV là vị trí kỹ thuật chủ chốt, dẫn dắt thiết kế, phát triển và vận hành nền tảng Văn phòng số thông minh C-GOV — giải pháp hợp nhất Quản lý văn bản, Workflow, Giao việc, Hành chính, Tài sản và Lịch, được tăng cường bởi AI, phục vụ khối GOV.

Vị trí chịu trách nhiệm về kiến trúc Microservices trên nền tảng .NET , định hướng sản phẩm theo mô hình SaaS multi-tenant, đồng thời phối hợp chặt chẽ với Product và Business để chuyển hóa yêu cầu nghiệp vụ thành giải pháp kỹ thuật có giá trị thực tiễn.

Ứng viên không chỉ vững về kiến trúc mà phải mạnh về System Optimization (tối ưu hệ thống) và Deployment (triển khai thực tế) trên hạ tầng Production, cả Cloud và On-Premise.

  1. Trách nhiệm chính
  • Dẫn dắt thiết kế và phát triển nền tảng C-GOV theo kiến trúc Microservices, Event-Driven (RabbitMQ làm Event Bus), với các domain service độc lập (DMS, WFS, UMS, NOTI, RPT, AGT...).
  • Thiết kế và vận hành hệ thống theo mô hình SaaS Cloud / On-Premise, hoàn thiện kiến trúc multi-tenant cho khối Enterprise, đảm bảo scalability, reliability, tenant isolation và khả năng bảo trì dài hạn.
  • Chịu trách nhiệm kiến trúc lớp nền tảng dùng chung: API Gateway (tách riêng cho Web nghiệp vụ, Web Admin và Mobile App), distributed cache (Redis), object storage (MinIO), Form Builder, Notification, Search, Dashboard, phân quyền RBAC và Audit log.
  • Thiết kế tích hợp hệ thống: ký số đa phương thức (HSM, Token, Remote Signing), LDAP/AD/SSO (Azure AD, Keycloak, Okta), Email/SMS, ERP/HRM/CRM qua REST API mở; xây dựng pre-built connector cho khối GOV.
  • Phối hợp với đội AI tích hợp các AI Smart Services (OCR, tóm tắt, phân loại, đề xuất xử lý, AI Draft, Chatbot) vào xuyên suốt quy trình nghiệp vụ của sản phẩm.
  • Phối hợp chặt chẽ với Product Manager, Product Owner và Business Analyst để chuyển hóa yêu cầu sản phẩm thành giải pháp kỹ thuật; tham gia ướng lượng effort và cam kết roadmap.
  • Làm việc cùng DevOps thiết kế CI/CD pipeline, observability và framework triển khai tinh gọn, rút ngắn thời gian deployment cho khách hàng GOV.
  • Phối hợp với Security, Compliance đảm bảo hệ thống đáp ứng chuẩn bảo mật (OWASP Top 10, mã hóa dữ liệu, 2FA/MFA), yêu cầu pháp lý về dữ liệu cá nhân và chuẩn công nghệ nội bộ.
  • Thiết lập engineering best practices, chuẩn scalability, code review và duy trì chất lượng code ở mức cao.
  • Cung cấp technical leadership, mentoring và định hướng kiến trúc cho đội kỹ thuật fullstack.
  1. Yêu cầu bắt buộc
  • Tối thiểu 7 năm kinh nghiệm software engineering, trong đó có trách nhiệm technical leadership.
  • Thành thạo hệ sinh thái .NET / .NET Core (C#) : ASP.NET Core Web API, Entity Framework Core, xây dựng và vận hành microservices trên Production.
  • Năng lực fullstack : vững backend .NET, làm việc tốt với frontend SPA hiện đại (Angular/React/Vue) và hiểu kiến trúc Mobile App (iOS/Android) giao tiếp qua API Gateway riêng.
  • Kinh nghiệm vững về: Microservices architecture; Event-driven systems với Message Queue (RabbitMQ/Kafka); Domain-Driven Design (DDD); thiết kế hệ thống phân tán và scalable; Multi-tenant architecture.
  • Kinh nghiệm thực tế thiết kế và vận hành nền tảng SaaS trên môi trường Production; kinh nghiệm triển khai song song mô hình On-Premise cho khách hàng lớn.
  • Kinh nghiệm thực tế với nền tảng cloud (AWS, GCP hoặc Azure) và hạ tầng ảo hóa.
  • Kinh nghiệm vững về DevOps, CI/CD pipelines, observability và hệ thống phân tán high-availability, DR/Backup.
  • Kinh nghiệm làm việc chặt chẽ với Product Owner hoặc Business Analyst trong môi trường product-driven.
  • Hiểu biết về thiết kế hệ thống an toàn và phát triển theo hướng tuân thủ (compliance-aware).
  1. Yêu cầu kỹ thuật cốt lõi (đặc thù Tech Lead - C-GOV)
  • Kiến trúc Microservices .NET: thiết kế, tách và quản trị các domain service (quản lý tài liệu, workflow, người dùng, thông báo, báo cáo, tích hợp) giao tiếp qua API Gateway và Event Bus; quản lý dữ liệu phân tán theo mô hình database-per-service.
  • Workflow & Form engine: kinh nghiệm xây dựng hoặc tích hợp workflow engine cấu hình động (kéo thả, đa cấp phê duyệt, điều kiện/song song, escalation) và form builder với metadata động — năng lực cốt lõi của định hướng Low-code trong roadmap sản phẩm.
  • Xử lý tải cao & bất đồng bộ: thành thạo thiết kế scale-out/scale-up, xử lý bất đồng bộ qua RabbitMQ, distributed cache với Redis, lưu trữ file/nội dung số với MinIO hoặc object storage tương đương.
  • Ký số & bảo mật: kinh nghiệm tích hợp chữ ký số (HSM, Token, Remote Signing), đáp ứng OWASP Top 10, mã hóa dữ liệu at-rest/in-transit, RBAC phân quyền sâu và audit trail đầy đủ.
  • Tích hợp AI vào sản phẩm: hiểu cách tích hợp các dịch vụ AI (OCR, LLM tóm tắt/phân loại, chatbot, RAG) vào luồng nghiệp vụ qua API một cách an toàn, kiểm soát chi phí và độ trễ.
  • Triển khai & Hạ tầng (DevOps): kinh nghiệm đóng gói và triển khai thực tế trên Docker và/hoặc Kubernetes; tách biệt môi trường UAT/Production; thiết kế cho cả SaaS Cloud, On-Premise và Hybrid.
  • Tích hợp hệ thống doanh nghiệp: kinh nghiệm tích hợp ERP/HRM/CRM, AD/LDAP, SSO, Email/SMS Gateway, Scanner qua REST API và các giao thức phổ biến.

Tóm lại, ứng viên không chỉ vững về .NET mà phải mạnh về System Optimization và Deployment trên hạ tầng PROD, với tư duy nền tảng (platform thinking) cho sản phẩm SaaS đa khách hàng.

  • Kinh nghiệm xây dựng các sản phẩm dành cho khối GOV.
  • Kinh nghiệm với cả hai hệ sinh thái .NET và Java.
  • Kiến thức chung về các mô hình AI hiện đại (LLM, OCR, Computer Vision) và cách tích hợp năng lực AI vào sản phẩm phần mềm.
