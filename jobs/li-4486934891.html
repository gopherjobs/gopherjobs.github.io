Role Overview

We are looking for an experienced Go (Golang) Developer with deep expertise in Kubernetes internal architecture to build, scale, and maintain custom Kubernetes Operators and Controllers.

In this role, you will design Custom Resource Definitions (CRDs) and write reconciliation loops that automate the lifecycle management (provisioning, scaling, auto-healing, upgrades, and backup/restore) of complex distributed systems on cloud-native platforms.

Key Responsibilities

 Operator & Controller Development: Design, build, and maintain custom Kubernetes Operators using Go, ⁠controller-runtime⁠, ⁠client-go⁠, and Operator SDK / KubeBuilder frameworks.

 CRD Schema Design: Define clean, forward-compatible Custom Resource Definitions (CRDs) and OpenAPI v3 validation schemas tailored to complex application lifecycles.

 Reconciliation Logic: Implement idempotent, thread-safe reconciliation loops handling edge-triggered and level-triggered cluster events.

 System Integration: Integrate custom controllers with cloud APIs (AWS, GCP, Azure), service meshes (Istio/Linkerd), and GitOps pipelines (Argo CD, Flux).

 Testing & Quality Assurance: Write unit, integration, and end-to-end tests for operators using tools like ⁠envtest⁠, ⁠kuttl⁠, or standard Go testing packages.

 Observability & Health: Expose custom Prometheus metrics, trace reconciliation workflows, and generate Kubernetes events for auditability.

Technical Qualifications

Must-Have Skills

 Golang Proficiency: 3+ years of professional Go development experience with strong knowledge of concurrency patterns (goroutines, channels, context management), interfaces, and memory management.

 Kubernetes Internals: Strong understanding of Kubernetes control plane architecture (API Server, ⁠etcd⁠, controller-manager, scheduler, informers, workqueues, and watch mechanics).

 Operator Frameworks: Hands-on experience with ⁠controller-runtime⁠, KubeBuilder, or Operator SDK.

 Containerization & CI/CD: Proficient with Docker, Containerd, Helm charts, and building automated CI/CD pipelines for Go binaries and container images.

  • Testing: Experience writing unit tests, table-driven tests, and integration tests for Kubernetes custom controllers.
