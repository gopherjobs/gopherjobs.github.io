Description

Senior Full Stack Engineer – Python / FastAPI / React

£550 per day | Predominantly Remote | Outside IR35 (TBC) | November Start

Primus Connect is recruiting a Senior Full Stack Engineer to support a technology consultancy delivering a software engineering project for a client operating in a highly regulated environment.

This is a hands-on engineering role, suited to someone with strong Python backend development experience who is comfortable contributing across the full application stack.

You'll work within an established engineering team, developing production-ready applications, integrating APIs and using AI-assisted development tools to accelerate delivery.

Key Responsibilities

  • Design, develop and maintain backend services using Python and FastAPI.
  • Build and integrate REST APIs, including authentication and authorisation.
  • Develop and maintain PostgreSQL databases, schemas and migrations.
  • Contribute to frontend development using React and TypeScript.
  • Write automated tests and participate in code reviews.
  • Work within established GitHub workflows, CI/CD pipelines and change control processes.
  • Use Claude Code to support day-to-day development, while reviewing and validating AI-generated code.
  • Maintain secure coding standards and address security vulnerabilities.

Essential Experience

  • Strong commercial Python development experience.
  • FastAPI, Pydantic and Alembic.
  • PostgreSQL, including data modelling and database migrations.
  • React and TypeScript.
  • Authentication technologies including SSO, JWT and RBAC.
  • Automated testing using pytest and JavaScript testing frameworks.
  • GitHub, pull requests, code reviews and CI/CD.
  • Hands-on Claude Code experience.
  • Experience developing or delivering AI-powered solutions.
  • Previous experience delivering software within heavily regulated environments.

Desirable Experience

  • Microsoft Azure, including App Service, Key Vault and Application Insights.
  • PingFederate.
  • Rules engines and workflow automation.
  • Concurrency, audit logging and data integrity.
  • Advanced Claude Code functionality.

Contract Details

  • Day Rate: Up to £550 per day
  • IR35: Outside IR35
  • Location: Fully Remote
  • Start Date: November 2026
  • Duration: Until March/April 2027
