Role Overview

The Software Engineer will build and own the native Rust agent behind the BotCity product. The agent runs on customer endpoints across all major operating systems to track and govern the code that runs there. This person will keep it fast, stable, and lightweight, and help shape its architecture. This role is built for someone with deep production Rust and systems programming experience who can own hard low-level problems from start to finish in a small team. This role reports to the VP of Engineering.

Responsibilities Develop, deploy, and maintain native applications and system-level components in Rust.

Ensure high performance, stability, and minimal resource consumption of software running on customer endpoints.

Work with product and other engineers to figure out what’s worth building and how.

Participate in technical design discussions and contribute to architecture and stack decisions for the agent.

Participate in code reviews, ensuring best practices in Rust and systems development.

Write clear technical documentation, ensuring effective collaboration across teams.
