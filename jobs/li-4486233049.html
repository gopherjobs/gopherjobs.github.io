Description

Full Stack Developer opportunities in London could involve designing and delivering scalable web applications across modern cloud platforms, working with both front-end and back-end technologies to solve complex business problems. These are contract-based positions ideal for specialists looking to apply distributed systems expertise, microservices architecture and contemporary development practices in a fast-paced environment.

Please note the content of this advert does not represent a live vacancy.

About The Opportunity This is an opportunity to register your interest in future Full Stack Developer positions based in London. Roles of this type may sit within organisations modernising their technology infrastructure across cloud platforms such as Azure, AWS and GCP. The work could involve collaborating with cross-functional teams to build resilient, scalable applications using microservices and containerised deployment, with scope to contribute to architectural decisions and technical standards across your assigned workstreams.

Typical Role Overview

  • Location: London, Greater London, England
  • Type: Contract
  • Full-time
  • Rate: £500–700 per day
  • Focus: Full-stack web application development across cloud infrastructure

What You Would Do Typical responsibilities could include:

  • Designing and implementing full-stack features across front-end and back-end layers
  • Developing RESTful APIs and microservices using technologies such as .NET, ASP.NET, Java and Spring Boot
  • Building responsive user interfaces with React and ensuring seamless integration with back-end systems
  • Implementing CI/CD pipelines and containerised deployments using Docker and Kubernetes
  • Working with cloud platforms (Azure, AWS, GCP) to deploy, scale and monitor applications
  • Collaborating with team members on code reviews, technical documentation and knowledge sharing
  • Contributing to database design and optimisation using SQL and related technologies
  • Supporting the integration of data pipelines and ensuring data quality across systems

What You Could Bring Most roles of this type require the following:

Must-have

  • Demonstrated experience in full-stack web development across multiple languages and frameworks
  • Proficiency with at least one modern front-end framework (such as React) and one back-end technology (such as .NET, ASP.NET, Java or Spring Boot)
  • Strong understanding of microservices architecture, APIs and distributed systems
  • Experience with containerisation and orchestration (Docker, Kubernetes)
  • Working knowledge of SQL and relational database design
  • Familiarity with cloud platforms (Azure, AWS or GCP) and cloud-native development practices
  • Experience implementing or working with CI/CD pipelines
  • Bachelor's degree in Computer Science or equivalent professional experience
  • Authorization to work in the United Kingdom

Nice-to-have

  • AWS Certified Developer – Associate or Microsoft Certified: Azure Developer Associate
  • Experience with infrastructure-as-code tools such as Terraform
  • Knowledge of Linux command-line tools and scripting (Bash)
  • Exposure to SAP systems (S/4HANA, ECC) or enterprise integration patterns
  • Familiarity with business process modelling (BPMN) or UML
  • Experience with data visualisation tools such as Power BI

  • Flexible contract engagement based in London with potential for remote work arrangements
