Full-stack Developer Intern — Mobile Dating App (In Development)

Romega Solutions | 180-Hour Internship

About the Project

We're building a React Native / Expo mobile dating app, currently in active development. The app connects users through profiles, real-time matching, and messaging. It's in its final pre-launch push — most core systems are built, and we're now focused on hardening, testing, and validating the product for a production release.

You'll be joining at a hands-on stage of the build: real code, a real backend, and real release blockers to help clear.

Tech Stack

  • Frontend: React Native + Expo SDK 54+, expo-router (file-based routing), NativeWind (Tailwind CSS)
  • State Management: Zustand
  • Backend: Supabase (PostgreSQL, Auth, Storage, Edge Functions)
  • Languages: TypeScript, PL/pgSQL, JavaScript

What You'll Work On

Depending on your strengths and where the project needs support, you may contribute to:

  • App features — auth flows, profile/account setup, swipe & match logic, real-time chat, notifications
  • Backend & database — Supabase migrations, RLS policies, RPC functions, storage bucket rules (PL/pgSQL)
  • Native device features — location permissions, camera/photo verification flows, deep linking
  • Testing & QA — writing and running smoke tests, validating flows on emulator/device, checking release gates
  • Release hardening — helping close out launch blockers (security policies, dependency audits, migration verification)

This is real production work on an app heading toward launch — not a sandbox project.

What We're Looking For

  • Comfortable with (or eager to learn) TypeScript and React Native
  • Basic familiarity with SQL / relational databases ; PL/pgSQL or Supabase/Postgres experience is a plus
  • Understanding of Git/GitHub workflows (branches, pull requests, code review)
  • Detail-oriented — this app handles sensitive user data (ID verification, location, private messaging), so care around security and data handling matters
  • Able to work independently, ask good questions, and communicate progress clearly
  • Comfortable navigating an existing codebase rather than starting from scratch
  • Proactive and resourceful — comfortable figuring things out and finding workarounds without waiting to be told, the way things get done at a startup
  • Willing to lean on your own knowledge and AI tools (Claude, ChatGPT, Copilot, etc.) to move fast and solve problems independently

Internship Details

  • Duration: 180 hours (flexible scheduling)
  • Format: Remote, working alongside Romega's existing developer team
  • Working style: This is a self-directed role. There is no dedicated lead developer providing step-by-step guidance — you'll be relying on your own knowledge, research, and AI tools to solve problems, alongside peer collaboration with the rest of the small dev team.

What We Provide

  • Access to the tools, codebase, and systems you need to do the work (Supabase, Vercel, GitHub, etc.)
  • Real startup experience — exposure to how a small, fast-moving team actually builds and ships product
  • Potential for absorption into the company as a longer-term role, based on performance

Why This Internship

  • Work on a real product close to launch, not a toy project
  • Exposure to the full stack: mobile frontend, backend/database, and DevOps/release practices
  • Ownership — you'll be trusted to figure things out, not just follow instructions
  • A concrete addition to your portfolio: shipped, production-bound mobile app work
