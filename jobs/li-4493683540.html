Job Description Deliver moderately complex features in an existing application. Work with a senior engineer on design choices, use coding agents to implement scoped changes, and demonstrate that each feature meets its acceptance criteria.

Core Responsibilities

  • Turn a user story into examples covering expected behavior, missing inputs, and dependency failures before implementation.
  • Give a coding agent a scoped task, review its changes line by line, and write unit and integration tests that would catch an incorrect implementation.
  • Integrate a model API into an existing workflow. For example, validate extracted fields against a schema and send incomplete records to the established review queue.
  • Package the feature, follow it through CI, and use logs to investigate failures. Bring reproducible evidence to a senior engineer when a fix crosses component boundaries.

Qualifications

  • Typically 2–5 years of professional software engineering experience. Demonstrated ability to take a feature from an agreed design through review and release.
  • Working proficiency in a production language such as Python, TypeScript, Java, or C#, plus experience with Git, APIs, and automated tests.
  • Hands-on use of an AI coding tool. Be prepared to show how you verified a generated change and explain a suggestion you rejected.
  • Bachelor’s degree in computer science or engineering, or equivalent practical experience.

Preferred Experience

  • Experience applying a foundation in front-end development, databases, analytics, DevOps, or security to a shipped feature.
  • Exposure to model evaluation or applied machine learning through a project where you compared outputs with known examples.

Technical Skills

  • Write modular code, document an API using OpenAPI, and exercise it with representative test data.
  • Build a Docker container, troubleshoot a CI job, and use basic cloud services to deploy and observe a change.

Certifications

  • Preferred AI credentials cover agentic coding, AI application architecture fundamentals, or data pipelines using tools such as Databricks. Candidates should be able to explain how they applied that training to a feature, such as testing an agent-generated change or validating records in a pipeline.
  • Relevant stack certifications from Claude, Microsoft (Azure), AWS, SUSE, or CNCF are also welcome. A credential is most useful when the candidate can describe what they personally built, deployed, or troubleshot on that stack.

Soft Skills

  • Ask specific questions when acceptance criteria are ambiguous. Use a failing test or a small example to make the issue clear.
  • Incorporate review feedback and explain implementation choices to QA, product, and engineering peers.
