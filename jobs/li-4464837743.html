Description

Senior Java Microservices & DevOps Engineer

Location: Bengaluru (Primarily Remote – Candidate should be willing to attend office when required)

Employment Type: Contract-to-Hire

Experience: 6–12 Years

Mandatory Requirement

Candidates must have started their career as a Java Developer and gained strong hands-on experience in Java application development and Microservices architecture before transitioning into DevOps, Platform Engineering, or Application Operations roles.

Please do not apply if your experience is limited to Infrastructure Administration, Cloud Operations, System Administration, or DevOps without Java development experience.

Job Summary

We are seeking an experienced Java Microservices & DevOps Engineer who combines strong application development knowledge with hands-on DevOps and platform administration expertise.

The ideal candidate will have a solid foundation in Java development, Spring Boot, and Microservices, along with experience managing CI/CD pipelines, containerized environments, Kubernetes platforms, deployments, monitoring, and production operations.

This role requires an individual who can effectively bridge Development and Operations teams, ensuring reliable application delivery, platform stability, and operational excellence.

Key Responsibilities

  • Manage and support Java and Microservices-based applications across production and non-production environments.
  • Administer and maintain CI/CD pipelines using Jenkins, Azure DevOps, Git, or similar tools.
  • Support containerized workloads running on Docker and Kubernetes platforms.
  • Troubleshoot application, deployment, and infrastructure issues across environments.
  • Collaborate with development teams to resolve application defects and performance bottlenecks.
  • Participate in release planning, deployment activities, and change management processes.
  • Monitor application health, platform performance, and system availability.
  • Perform root cause analysis (RCA) and implement preventive measures.
  • Manage incidents, service requests, and production escalations.
  • Implement automation to improve deployment efficiency and operational reliability.
  • Maintain operational documentation, deployment procedures, and support runbooks.
  • Ensure adherence to security, compliance, and operational best practices.

Required Technical Skills

Java Development & Microservices

  • Strong hands-on experience in Java development.
  • Experience with Spring Boot and Microservices architecture.
  • Strong understanding of REST APIs and distributed systems.
  • Ability to analyze application logs and troubleshoot code-related issues.
  • Good understanding of application architecture and integration patterns.

DevOps & Platform Engineering

  • Strong experience with Jenkins, Azure DevOps, Git, or similar DevOps tools.
  • Hands-on experience with CI/CD pipeline administration and support.
  • Experience with Docker containerization.
  • Strong Kubernetes administration and troubleshooting experience.
  • Experience managing deployments, releases, and environment configurations.
  • Knowledge of infrastructure automation and DevOps best practices.

Production Operations & Monitoring

  • Experience supporting enterprise applications in production environments.
  • Incident Management, Problem Management, and Change Management.
  • Root Cause Analysis (RCA).
  • ServiceNow or equivalent ITSM tools.
  • Experience with monitoring and observability platforms such as:
  • Splunk
  • ELK
  • Dynatrace
  • AppDynamics
  • Grafana
  • Prometheus

Operating Systems & Scripting

  • Linux Administration experience.
  • Shell scripting and automation experience preferred.

Preferred Skills

  • Azure Cloud experience.
  • Azure API Management (APIM).
  • Site Reliability Engineering (SRE) concepts.
  • Infrastructure as Code (Terraform, Ansible, or similar).
  • Performance tuning and capacity planning experience.

Ideal Candidate Profile

  • Started career as a Java Developer.
  • Strong background in Spring Boot and Microservices development.
  • Transitioned into DevOps, Platform Engineering, or Production Operations roles.
  • Comfortable working across Development, Operations, and Support functions.
  • Strong troubleshooting and analytical skills.
  • Experience in highly available enterprise environments.
  • Excellent communication and stakeholder management skills.
