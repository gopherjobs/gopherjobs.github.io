About the role

  • Develop, and deliver high-quality data, backend, and integration solutions with a strong focus on reliability, scalability, performance, and
  • operational excellence. Contribute to the end-to-end development of applications, APIs, data pipelines, and database solutions while
  • adhering to established engineering standards and best practices.

You will be responsible for - Develop, test, and deploy scalable data engineering, backend, and API solutions that support business and analytics needs.- Deliver end-to-end data ingestion, normalization, transformation, and integration capabilities across multiple source systems.- Develop and maintain APIs, data pipelines, and database solutions that enable secure and reliable data movement and consumption.- Translate business requirements into maintainable technical solutions aligned with data architecture, engineering standards, and best practices.- Ensure data quality, integrity, validation, and reconciliation through effective engineering controls and testing practices.- Develop high-quality, reusable, and well-documented code while ensuring compliance with security, governance, and operational requirements.- Drive continuous improvement through automation, reusable assets, process optimization, and adoption of emerging technologies.- Build strong stakeholder relationships and provide clear communication on delivery progress, risks, dependencies, and technical solutions.- Live & demonstrate Tesco values in everyday interactions.

You will need * Data engineering, backend application development, API  * engineering, database development, system integration, and data platform delivery * Python Development and Data Engineering * PostgreSQL and Relational Database Development * Data Discovery, Analysis, and Profiling * Data Ingestion, Transformation, and Normalization * REST API Development and Integration * FastAPI or Similar Backend Frameworks * Docker, Kubernetes, and Microservices Development * Backend Application Development and System Integrations * GitHub, Jira, and Confluence * Data Lakehouse and Data Warehousing Concepts * ReactJS, TypeScript, JavaScript, HTML5, and CSS3 * Azure Cloud Platform * SFTP and Third-Party System Integrations * CI/CD Pipelines and DevOps Practices * Data Quality, Validation, and Reconciliation
