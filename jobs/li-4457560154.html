Yelp's Search Engine Results Page (SERP) Platform team owns the full-stack infrastructure that powers Yelp's web and mobile site Search pages,two of the highest-traffic surfaces on the platform. As a Full Stack Engineer on this team, you will build and maintain the foundational systems that enable dozens of feature teams across Yelp to ship new search experiences quickly and reliably.

The SERP Platform spans the entire rendering pipeline across both surfaces: from server-side data hydration and view model construction in Python, through to client-side component registration and rendering in TypeScript and React. On the desktop web, you will own the frameworks that define how search results and non-result features are composed, served, and displayed to millions of users. On the mobile site, you will own a GraphQL-driven architecture where features are self-contained modules that declaratively fetch their own data and render independently. Your work directly determines the velocity and quality at which product teams can iterate on Yelp's Search experience across all web platforms.

This is a platform engineering role where you will balance building new capabilities with maintaining high standards for performance, developer ergonomics, and code quality across multiple services and frontend packages.

This opportunity is fully remote and does not require you to be located in any particular area in Canada. We welcome applicants from throughout Canada. We’d love to have you apply, even if you don’t feel you meet every single requirement in this posting. At Yelp, we’re looking for great people, not just those who simply check off all the boxes.

What You'll Do

  • Own and evolve the full-stack rendering pipeline for Yelp's WWW and mobile site Search pages, spanning server-side Python services and client-side React/TypeScript packages.
  • Design and maintain the component registration and rendering frameworks that feature teams use to add new search results and features to the Search page on both desktop and mobile site.
  • Build server-side view models and data hydration layers in Python that serve props to React components, ensuring a clean contract between backend data and frontend rendering.
  • Develop and extend GraphQL APIs to support client-side data fetching,including the mobile site's resolver-based architecture where features fetch data through a shared search context.
  • Collaborate with feature teams to guide them through the platform's patterns for adding new components; from writing client-side UX through server-side factory functions, GraphQL resolvers, and data loading.
  • Improve developer ergonomics, platform reliability, and web performance across desktop and mobile site in line with Yelp's Web Best Practices.
  • Drive architectural decisions around Search page layouts, mobile site feature composition, and the systems that determine how they are rendered and deployed.

What It Takes To Succeed

  • Ideally 5+ years of professional experience building full-stack web applications with Python on the server side and TypeScript/React on the client side.
  • Strong understanding of component-based frontend architectures, server-side rendering (SSR) patterns, and client-side data fetching with GraphQL.
  • Experience designing GraphQL schemas and resolvers, ideally with frameworks like Strawberry or similar typed Python GraphQL libraries.
  • A platform engineering mindset: you think about how other developers will use your systems and you prioritize clean abstractions, extensibility, and developer experience.
  • Comfortable working across multiple services and codebases, understanding how data flows from backend systems through view models and GraphQL resolvers to rendered UI.
  • Experience maintaining and scaling high-traffic web surfaces where performance and reliability are critical, including mobile-optimized experiences.
  • Strong collaboration skills with the ability to support and unblock other engineering teams building on your platform.
  • As part of the final panel interview for this role, you’ll complete a coding exercise using React and Flask in a code repository platform. The code repo platform offers an optional AI chatbot for syntax lookups and clarifying questions during the exercise.
