Clojure Full Stack Engineer at BairesDev

In this role, you'll own features end-to-end for a retail AI outfitting platform, from PostgreSQL schema design through Clojure API implementation to the ClojureScript review UIs colleagues use daily. Working within a team of Clojure engineers, you'll build backend services that integrate with LLM APIs, orchestrate multi-step AI operations, and power semantic search across massive product catalogs. This is your opportunity to architect solutions independently at high scale, shipping features that serve hundreds of enterprise retailers and 100M+ monthly shoppers.

What You'll Do:

- Own features end-to-end, from database schema design through backend implementation to frontend review UIs.

- Build backend services that integrate with LLM APIs to support AI-driven product features.

- Work with workflow orchestration tools to coordinate multi-step AI operations.

- Contribute to search and retrieval pipelines powering semantic search across the product catalog.

- Architect solutions and make technical decisions independently within a fast-moving team.

What we are looking for:

- 8+ years of experience in software engineering.

- Strong proficiency in Clojure.

- Hands-on experience with ClojureScript.

- Experience with PostgreSQL and SQL schema design.

- Background integrating LLM APIs in production, calling and working with them at the API level.

- Advanced proficiency in English.

- Experience with REST API design.

- Familiarity with the functional programming ecosystem including shadow-cljs, re-frame, and reagent.

- Experience with prompt engineering or handling non-deterministic outputs.
