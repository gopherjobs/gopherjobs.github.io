Description

This position is listed on behalf of a partner company, who manages all applications and next steps. Our partner is looking for a Software Engineer (Front and Back end) based in Saudi Arabia. As a Software Engineer, you’ll contribute across both frontend and backend development to build reliable, scalable applications in modern cloud environments.

You’ll work with technologies spanning Java, JavaScript, Python, web frameworks, containerization, and cloud infrastructure.

The role combines hands-on software development with deployment automation, CI/CD, and modern application delivery practices.

You’ll collaborate within an Agile development environment, contributing to technical planning, implementation, testing, and continuous improvement.

Your work will help deliver secure and resilient applications while supporting efficient deployment across complex cloud platforms.

You’ll operate in a collaborative, fast-moving environment where strong problem-solving, communication, and ownership are essential.

This opportunity is well suited to an engineer who enjoys working across the full application stack and adapting to evolving technical challenges.

Accountabilities

  • Develop and maintain software applications using Java, JavaScript, Python, or related technologies.
  • Build and enhance frontend applications using modern web technologies including HTML5, CSS3, and JavaScript ES6+.
  • Develop user interfaces with frameworks such as React, Angular, or Vue.js, including relevant state management solutions such as Redux, NgRx, or Vuex.
  • Contribute to backend application development and integration using technologies such as Java, Python, C#, and .NET.
  • Design, deploy, and maintain containerized applications using Kubernetes, Helm, Docker, Containerd, or similar technologies.
  • Support application deployment across cloud environments such as AWS, Azure, OpenStack, or OpenShift.
  • Develop and maintain CI/CD pipelines, automated build processes, deployment workflows, and configuration tools.
  • Participate in Agile development practices and use collaboration and project management tools such as JIRA and Confluence.
  • Collaborate with engineers and other stakeholders to design solutions, troubleshoot technical issues, and deliver project objectives.
  • Apply strong critical thinking and problem-solving skills to address technical challenges and improve application reliability.
  • Contribute to on-time project delivery through effective planning, prioritization, and time management.
  • Maintain clear technical communication and documentation throughout the development lifecycle.

Requirements

  • 4-year degree in Computer Science, Software Engineering, or a related technical field, or an equivalent combination of education and professional experience.
  • Professional development experience with at least one of Java, JavaScript, or Python.
  • Strong knowledge of core web technologies, including HTML5, CSS3, and modern JavaScript (ES6+).
  • Hands-on experience with at least one major frontend framework or library, such as React, Angular, or Vue.js.
  • Familiarity with frontend state management technologies such as Redux, NgRx, or Vuex.
  • Familiarity with C# and .NET is preferred.
  • Hands-on experience with application containerization using Kubernetes, Helm, Docker, Containerd, or similar technologies.
  • Experience deploying containerized applications in cloud environments such as AWS, Azure, OpenStack, or OpenShift.
  • Experience working with CI/CD deployment pipelines, automated builds, and configuration management tools.
  • Experience working in an Agile software development environment and familiarity with tools such as JIRA and Confluence.
  • Strong verbal and written communication skills, with the ability to collaborate effectively across technical teams.
  • Demonstrated ability to build strong working relationships and consistently deliver high-quality results.
  • Strong critical thinking, analytical, and problem-solving skills.
  • Ability to work effectively in a fast-paced, rapidly changing environment.
  • Strong organizational and time-management skills with a focus on meeting project deadlines.
  • Familiarity with the space domain is a plus.

Benefits

  • Remote work opportunity.
  • Opportunity to work across both frontend and backend software engineering.
  • Exposure to modern cloud platforms and containerized application environments.
  • Hands-on experience with Kubernetes, Docker, Helm, CI/CD, and Agile development practices.
  • Opportunity to work with a broad range of programming languages and modern web technologies.
  • Collaborative environment focused on technical problem-solving and project delivery.
  • Exposure to complex technology environments and, potentially, space-domain applications.
