Advanced Solutions Engineer

Role Summary

Advanced Solutions Engineer acts as the critical bridge between Customer Success and Core Engineering. You are a code-literate investigator responsible for diagnosing complex architectural issues, identifying root causes in the codebase, and ensuring high-severity incidents are resolved. This is a role for a developer who loves the "puzzle" of debugging more than the "construction" of new features.

Key Responsibilities

  • Deep-Dive Debugging: Go beyond log analysis; navigate the Java/J2EE source code to pinpoint logic flaws or integration bottlenecks.
  • Incident Triage: Lead the technical response for High-Priority/Severity incidents, providing real-time updates and technical workarounds.
  • API & Integration Mastery: Troubleshoot third-party ecosystem failures (NetSuite, Salesforce, etc.) by analyzing REST API payloads and authentication flows.
  • Documentation & Tooling: Build internal diagnostic tools or scripts and author "Root Cause Analysis" (RCA) reports to prevent recurring issues.
  • Knowledge Transfer: Mentor front-line support teams and translate complex engineering fixes into digestible knowledge base articles.
  • Operational Readiness: Participate in a 24/7 rotational shift schedule to ensure global platform stability.

Technical Requirements

  • Experience: 1–3 years in Technical Support, Sustaining Engineering, or Software Development.
  • Core Programming: Proficiency in Java is preferred, but we welcome candidates with strong coding skills in Python, Go who are willing to pivot to a Java environment.
  • Web Stack: Strong grasp of HTML5, CSS, and modern JavaScript frameworks (React, Angular, or Vue).
  • Data & APIs: Expert level in SQL (complex joins/query optimization) and deep familiarity with RESTful APIs and JSON/XML.
  • Observability: Hands-on experience with logging and monitoring tools (e.g., Splunk, ELK Stack, Datadog, New Relic).

Preferred Qualifications

  • The Dev Edge: 2+ years of professional Software Development experience.
  • SaaS Background: Experience supporting multi-tenant cloud environments.
  • Domain Expertise: Prior experience managing complex integrations with Financial (NetSuite/Xero) or CRM (Salesforce/HubSpot) platforms.
