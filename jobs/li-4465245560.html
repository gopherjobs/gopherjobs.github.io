Description

Enumerate is seeking a PHP & React Software Engineer to help modernize our core product and platform systems across our software and payments ecosystem. We're building a new mobile application on PHP and React Native, and we're looking for an engineer who can help shape it while keeping our existing web application stable and reliable for the customers who depend on it every day.

This is a hands-on role that balances two tracks: building new mobile-facing functionality and APIs, and investigating defects, troubleshooting production issues, and making incremental improvements to an existing vanilla PHP codebase. You'll work closely with Product, QA, and Support to resolve issues and ensure consistent behavior across web and mobile. This role is ideal for an experienced PHP engineer who is energized by modernization work but can also dive into legacy systems - someone who enjoys understanding complex business logic and knows that a stable foundation is what makes new development possible.

This is a remote position, but candidates must be located in LATAM.

Key Responsibilities & Deliverables Mobile & Platform Development

  • Help stand up our new React Native mobile application, from project setup through first release.
  • Build and extend the PHP APIs and services that power it.
  • Help define how the mobile app integrates with existing systems.
  • Establish patterns and conventions for mobile development that the team will build on as it grows.
  • Own features and components end to end, from design discussion through development and release
  • Identify opportunities to modernize patterns in the existing codebase as new work touches them.

Application Stability & Bug Resolution

  • Investigate, diagnose, and resolve bugs in a vanilla PHP application.
  • Debug complex issues across application logic, database interactions, and integrations.
  • Deliver safe, well-tested fixes that minimize regression risk.
  • Analyze logs, error reports, and monitoring data to identify root causes.
  • Collaborate with QA and Support to reproduce reported issues and validate fixes.
  • Assist with performance improvements and reliability enhancements.

Engineering Practices

  • Participate actively in code reviews and technical discussions.
  • Apply agreed-upon standards for code quality, testing, and deployment.
  • Use AI-assisted development tools (such as Claude, Cursor, GitHub Copilot or something similar) to accelerate development, testing, and documentation.
  • Contribute incremental improvements to shared utilities or internal tooling.

Required Qualifications Skills, Knowledge & Expertise

  • Proven experience working as a PHP engineer delivering production software.
  • Hands-on React Native experience, including at least one application shipped to the App Store and/or Google Play.
  • Experience building and consuming REST APIs that service web or mobile clients.
  • Demonstrated ability to debug and fix issues in large or legacy codebases.
  • Solid understanding of relational databases and SQL.
  • Solid understanding of modern development practices, including version control (Git), CI/CD, and automated testing.
  • Comfortable working independently in a remote role and switching context between new development and production support.
  • Strong analytical and problem-solving skills, especially when tracing complex bugs.
  • Experience using AI-assisted coding tools as part of daily development workflows.

Preferred Qualifications

  • Familiarity with PHP applications that integrate with third-party APIs.
  • Experience incrementally modernizing legacy systems without disrupting production.
  • Understanding of secure coding practices and data integrity concerns.
  • Familiarity with mobile-specific concerns such as offline behavior, push notifications, or app release cycles.
