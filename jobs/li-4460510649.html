Job Description Project Description: The team is responsible for the development & operations of Monitoring and DataAnalytics Tools for the Network Control Platform of Deutsche Telekom Germany (AAA Fixed Net Germany).

The project is responsible for controlling Internet access and managing the underlying network infrastructure for Deutsche Telekom Germany. It supports millions of concurrent user sessions while ensuring high availability, scalability, and reliability.

  • Support for all-IP services, including MagentaTV, IP telephony, and other next-generation network services.
