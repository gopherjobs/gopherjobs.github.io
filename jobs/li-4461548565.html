Senior Java Backend Engineer – E-Commerce Platform

Location

Japan – Onsite position (You have to relocate to Japan/ Visa support include)

About The Role We are looking for a highly experienced Senior Java Backend Engineer to join an engineering team developing and operating large-scale e-commerce platforms.

You will be responsible for designing, developing, and maintaining reliable backend services that support merchant-facing business operations. The role involves working on high-traffic systems, improving performance and scalability, and delivering new features while maintaining high levels of system stability.

This is an opportunity to work on technically challenging systems and contribute across backend development, system design, performance optimization, and production operations.

Responsibilities

  • Design, develop, test, and deploy scalable backend applications using Java.
  • Develop and maintain RESTful APIs and business logic.
  • Design and implement reliable services for high-traffic production environments.
  • Improve application performance, scalability, availability, and stability.
  • Participate in system architecture and technical design discussions.
  • Conduct code reviews and contribute to engineering best practices.
  • Investigate production incidents and perform root-cause analysis.
  • Support monitoring, alerting, deployment automation, and other DevOps initiatives.
  • Work closely with Product Managers, Project Managers, and other engineers.
  • Contribute to system migration and platform modernization projects.
  • Lead technical initiatives and mentor other engineers when required.
