About the project:

As a Senior Full Stack / Integration Engineer , you'll join a team building and evolving a complex, microservices-based platform end to end — from backend services and APIs through to the React frontend. You'll work in an AI-assisted development environment, using agentic coding tools alongside structured specifications and acceptance criteria to drive implementation, and you'll be expected to critically review AI-generated code for correctness, maintainability, security, and performance. This role requires the ability to take full ownership of features from requirements through production, across distributed, cloud- and edge-deployed systems.

What you’ll do:

  • Design and build backend services and REST APIs using Python and FastAPI
  • Develop and maintain frontend features using React
  • Design and evolve microservices-based systems architecture
  • Deploy, troubleshoot, and maintain distributed applications running in Kubernetes, including edge and on-premises environments
  • Work across cloud and edge/on-premises architectures, including Google Cloud Platform
  • Design, implement, and optimize data layers using PostgreSQL, MongoDB, and MySQL
  • Apply strong CI/CD, automated testing, source control, code review, and observability practices across the delivery pipeline
  • Work within AI-assisted or AI-accelerated development workflows, leveraging tools like Claude Code or similar agentic coding tools to support implementation
  • Translate structured specifications, requirements, and acceptance criteria into AI-assisted implementation
  • Critically review AI-generated code for correctness, maintainability, security, performance, and alignment with requirements
  • Take ownership of features independently, from requirements through production

What makes you a great fit:

  • Strong Python development experience
  • Experience building backend services and REST APIs with FastAPI
  • Strong experience with React
  • Extensive experience designing and developing microservices-based systems
  • Extensive hands-on Kubernetes experience, including troubleshooting distributed applications
  • Experience with cloud and edge or on-premises architectures
