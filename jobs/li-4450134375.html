Senior Backend Developer (Java)

Estamos à procura de um Senior Backend Developer (Java) para integrar projetos tecnológicos de grande dimensão, com foco no desenvolvimento de soluções backend escaláveis e na integração de Generative AI .

A posição é Full Remote em Portugal , com deslocações muito pontuais ao escritório em Coimbra.

Principais Responsabilidades

  • Desenvolver e arquitetar soluções backend escaláveis;
  • Desenvolver microserviços com Java, Spring Boot, Kafka e gRPC ;
  • Conceber e implementar REST APIs e integrações entre sistemas;
  • Implementar funcionalidades de Generative AI , recorrendo a Prompt Engineering e otimização de contexto;
  • Utilizar ferramentas de AI-assisted development como Cursor, GitHub Copilot ou Claude ;
  • Aplicar boas práticas de desenvolvimento, incluindo Clean Code, SOLID e TDD ;
  • Realizar deployments em Kubernetes ;
  • Colaborar com equipas multidisciplinares na construção de soluções robustas, seguras e escaláveis.

Requisitos Obrigatórios

  • Mínimo de 5 anos de experiência profissional em Backend Development ;
  • Experiência sólida com Java e Spring Boot ;
  • Experiência com Microservices ;
  • Experiência profissional com Apache Kafka ;
  • Experiência com Kubernetes ;
  • Experiência com gRPC ;
  • Desenvolvimento e integração de REST APIs ;
  • Experiência com ferramentas de AI-assisted development, como Cursor, GitHub Copilot ou Claude ;
  • Conhecimentos de Prompt Engineering e LLMs ;
  • Git e metodologias Agile (Scrum/Kanban);
  • Bom nível de inglês;
  • Residência atual em Portugal .

Valorizamos

  • JUnit e Mockito;
  • RAG e Vector Databases, como Pinecone, Chroma ou Milvus;
  • CI/CD;
  • AWS, Azure ou GCP;
  • Docker;
  • Prometheus, Grafana e OpenTelemetry;
  • Event-Driven Architecture;
  • Performance optimization e troubleshooting de aplicações distribuídas.

Regime

Full Remote , com deslocações muito pontuais ao escritório em Coimbra.
