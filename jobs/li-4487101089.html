Description

We are looking for a C++ Embedded Developer to join one of our projects and become part of an international team developing software for the latest generation of heating systems, including heat pumps and Smart Home solutions.

The project combines traditional heating technologies with modern IoT solutions, enabling devices to operate more energy-efficiently and conveniently for users.

The team is responsible for developing embedded software that controls heating systems and manages communication between devices within the ecosystem. The work involves collaboration with system architects and engineering teams developing various components. The project is executed using Agile methodology, with a focus on code quality, test automation, and continuous integration.

The team works in a hybrid model. Availability to work from the Katowice office 6 days per month is required.

Your tasks

  • Development and maintenance of embedded software in C++ (Embedded Linux) for heating control systems
  • Developing and extending software architecture in collaboration with architects and other teams
  • Integrating system components using the SOME/IP communication protocol
  • Creating unit tests (Google Test) and ensuring code quality and stability
  • Supporting system tests using Robot Framework and Python
  • Working in Agile teams, participating in sprint planning and project goal execution
  • Collaborating with international engineering teams

Requirements

  • Strong knowledge of C++ (object-oriented programming)
  • At least 4 years of experience in Embedded Linux software development
  • Previous experience with embedded systems
  • Familiarity with the SOME/IP communication protocol or related protocols
  • Experience working with unit testing frameworks (e.g., Google Test)
  • Experience working in Agile methodologies
  • Good command of English or German
  • Required presence in Poland and fluent Polish language skills

Nice to have

  • Previous experience with CI/CD
  • Knowledge of Simulink (MathWorks)
  • Experience with Robot Framework or Python in the context of system testing
