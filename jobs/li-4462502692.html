Description

We are looking for a skilled Senior Python Developer to join our team focused on developing cloud-native software solutions for large-scale telecommunications networks, including 5G technologies. You will participate in the entire software development lifecycle, collaborating with a diverse team of software developers, system engineers, data scientists, and telecommunications experts. This remote role offers the opportunity to work on innovative applications that analyze network data and support use cases such as RAN optimization and network self-healing.

Your tasks

  • Participating in the complete software development lifecycle, including requirements analysis, solution design, implementation, testing, and deployment
  • Developing cloud-native microservices and REST APIs
  • Processing and analyzing network configuration, performance, and telemetry data
  • Writing unit, integration, and system tests to ensure software quality
  • Troubleshooting application behavior in Linux and Kubernetes environments
  • Evaluating new technologies and contributing to research and proof-of-concept activities
  • Collaborating with cross-functional teams to deliver impactful software solutions

Requirements

  • Minimum 7 years of experience in software development with strong programming skills in modern Python 3
  • Experience in designing, implementing, and maintaining production-quality software
  • Practical knowledge of automated testing using pytest or similar frameworks
  • Experience with Linux-based software development and troubleshooting
  • Understanding of containers, Docker, and Kubernetes fundamentals
  • Experience in developing microservices or web APIs and familiarity with relational databases
  • Good problem-solving and debugging skills, along with the ability to use AI coding tools effectively
  • Advanced level of Polish and English

Nice to have

  • Experience in developing software for telecommunications systems, particularly 4G or 5G RAN
  • Knowledge of Kubernetes networking, ingress, storage, and security concepts
  • Familiarity with public or private cloud platforms and experience with data analysis or machine learning
  • Experience with message brokers or event-driven architecture
