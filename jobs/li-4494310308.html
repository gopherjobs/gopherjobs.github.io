Role Overview

This role exists within the development team, which is responsible for the development and application support of our client’s mission-critical Transfer Agency system and related interfaces. The core mission of this Database / Back-End Software Developer position is to engineer robust database applications that drive high stability, performance, and seamless service delivery. Within the first 6–12 months, the successful candidate will collaborate closely with architects and developers to build, secure, and deploy core transfer agency modules while supporting end-to-end solutions across the business.

Main Responsibilities

  • Develop, code, install, test, debug, and document database and back-end applications based on design specifications.
  • Build application interfaces utilizing database technologies, Progress ABL, SQL, and modern protocols including JSON-RPC, SOAP, and REST.
  • Ensure application security by proactively monitoring system modules and remediating software vulnerabilities.
  • Collaborate with business stakeholders , agile project managers, and technology partners to define requirements and map out end-to-end solutions.
  • Implement development methodologies spanning Agile and Waterfall frameworks to deliver quality products predictably and consistently.
  • Participate in the on-call application support rotation to uphold system performance, reliability, and back-office service delivery.
  • Inform and guide technical decisions alongside architects and peers across all stages of the software development lifecycle.

Must-have required skills and experience

  • Education: University degree, preferably in the field of Computer Science.
  • Experience: Minimum of 1–2 years of hands-on software development experience.
  • Industry Background: 6 to 12 months of experience in the Banking & Financial Services industry.
  • Database Programming: Strong understanding of relational database programming languages, specifically Progress ABL, SQL, and PostgreSQL .
  • Architecture & Protocols: Proven knowledge across all stages of software development, including building database applications with JSON-RPC, SOAP, and REST protocols.
  • Tooling & Pipelines: Practical experience using JIRA for Agile project management and working with CI/CD pipelines .
  • Version Control & Modern Tech: Hands-on experience with code versioning tools like GitHub , alongside modern AI tools .
  • Work Authorization: Current legal work authorization for Canada is strictly required.
