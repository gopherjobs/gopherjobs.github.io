Description

Clara is the leading spend management platform in Latin America. More than 40,000 businesses run on our corporate cards, bill pay, financing and B2B payments, and in 2025 the Financial Times named Clara the fastest-growing company in Latin America. We're ~400 people, backed by Kaszek, monashees, Coatue, DST Global, ICONIQ, General Catalyst and Goldman Sachs, among others.

We are looking for a Fullstack/Backend Engineer focused on QA Automation — a software engineer who builds the infrastructure, frameworks, APIs, and tooling that make automated quality possible at Clara. This is an engineering craft role (closer to SDET / SET / platform engineer than classic manual QA): you write production-grade code that enables pods and QA to generate, run, and trust automated tests.

The Role

You build and maintain the systems behind Clara's QA platform: Playwright-based frameworks, services and APIs that support test execution and reporting, CI wiring, and internal tools (e.g. test case / run persistence on Clara's React/Next stack). You collaborate with the QA Automation Lead, Pod Leads, and product engineers so automation is reusable, agent-ready, and owned as real software — not a pile of brittle scripts.

What You Own

  • Automation infrastructure — Design and implement shared frameworks and libraries for web/API automation (Playwright preferred), with stable selectors, modular architecture, and clear extension points for pods.
  • Tooling & services — Build backend APIs and fullstack components that store test cases, record run results, expose reports, and integrate with delivery workflows (e.g. Linear webhooks, Slack notifications, GitHub Actions).
  • Enablement for AI-assisted QA — Structure frameworks and contracts so agents and CLIs can generate and execute specs reliably (ticket → matrix → runnable tests → evidence).
  • CI/CD for quality — Implement and harden pipelines for smoke and regression suites; reduce flakiness; make failures diagnosable.
  • Engineering quality of test code — Treat automation as a first-class codebase: reviews, tests for helpers, versioning, documentation, and refactoring for maintainability.
  • Partnership — Work with QA engineers on adoption and with product engineers on testability (APIs, data-testid / ARIA, environments, test data hooks).

What Distinguishes This Role

  • Stronger software engineering depth than a traditional QA Engineer JD (services, APIs, data models, frontend for internal tools).
  • Focused on enabling automation at scale — not owning all manual exploratory testing for every pod.

Technical Skills

  • 4+ years of software development experience (backend and/or fullstack), with demonstrable automation or developer-tooling delivery.
  • Proficiency in TypeScript/JavaScript for Playwright (or equivalent E2E frameworks) and willingness to work in Clara's backend stack (Java / Spring Boot) where services or integrations require it.
  • Experience building and maintaining test automation frameworks (web and API); understanding of the test pyramid and when to prefer API vs UI coverage.
  • Backend fundamentals: REST APIs, relational databases, authentication basics, and clean service boundaries.
  • Fullstack comfort for internal tools: React / Next.js (or similar) for dashboards and test-management UIs is a strong fit with Clara's internal scaffold direction.
  • CI/CD experience (GitHub Actions or similar), Docker familiarity, and Git-based collaboration.
  • Ability to debug flaky tests, environment issues, and integration failures systematically.

Soft Skills

  • Builder mindset: you ship frameworks and tools that other engineers adopt.
  • Clear documentation and communication with QA and product engineering partners.
  • Comfortable with ambiguity and iterating from working prototypes to reliable platform pieces.
  • Collaborative code review habits; you raise the bar on test-code quality.
  • Good English (written and verbal); Spanish is a plus.

Nice-to-Have

  • Prior SDET / SET / Test Infrastructure Engineer experience.
  • Mobile automation (Appium) or BrowserStack.
  • Workflow orchestration (n8n), Linear/GitHub API integrations, or AI/agent tooling for test generation.
  • AWS and observability basics for running automation reliably in shared environments.
  • Fintech / payments domain exposure.
  • Experience replacing external test-management tools with internal systems.
