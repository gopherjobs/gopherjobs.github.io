An overview of this role

The Trusted Agentic Development team sits within GitLab's Developer Experience group and builds the platforms our engineers rely on every day. GitLab engineers increasingly build software with artificial intelligence agents. Agents can generate code and tests in seconds, but they can also produce passing test suites for software that doesn't work as intended. As a Senior Backend Engineer, Trusted Agentic Development, you'll own the technical thesis for closing that validation gap and build the early proof yourself. You'll rethink what validation means when the author is an agent and make the feedback loop fast, automatic, and trustworthy enough that teams choose to adopt it.

  • Validation that confirms agent-generated code does what was intended, so a passing suite means a working feature and not just a satisfied proxy.
  • Mid-loop feedback that helps an agent self-correct toward working software instead of green assertions.
  • Language-aware approaches under one shared model of what "trusted" means, starting with Rust, Ruby, and Go, while allowing the right technique to differ by language.
  • Real measurement of whether engineers trust and adopt the path, fed straight back into the platform.

What you’ll do

  • Own the technical thesis for how GitLab validates software when an agent is the author, and turn it into an architecture the team can build against.
  • Prototype the hard parts by building early versions of feedback mechanisms that catch the gap between passing tests and working software, proving what works before the team scales it.
  • Develop approaches for GitLab's primary stacks, starting with Rust, Ruby, and Go, under one shared definition of "trusted," while allowing the right technique to differ by language.
  • Design the mid-loop feedback an agent needs to self-correct toward working software rather than green assertions, and build the systems that deliver it.
  • Collaborate with engineering teams to adopt these approaches, measure adoption, engineer trust, and validation quality, and use those findings to improve the platform.
  • Set technical direction the team can build on, review designs, and help teammates grow their technical judgment.

What you’ll bring

  • Deep, current, hands-on experience building real software with artificial intelligence agents, ideally across more than one language, and a clear understanding of why agent output can pass tests yet fail in production.
  • A strong point of view on the validation gap and concrete ideas for closing it, backed by approaches you've built or tried.
  • The technical range to design systems rather than tune a single framework, and the judgment to know when a solution should be general or language-specific.
  • You prototype to learn, and you ship.
  • The ability to influence engineers across an organization without formal authority through working code and sound reasoning.
  • Strong written communication in an all-remote, asynchronous environment.
  • Alignment with GitLab's values, especially collaboration, iteration, and transparency.

This isn't a quality assurance or test automation role. We aren't looking for depth in a particular testing framework. We're looking for someone who has built with agents, experienced the validation gap firsthand, and wants to solve it.
