Description

Job Summary App Development is responsible for designing, building, testing and maintaining secure, scalable and high-performing software solutions that support business, client and operational outcomes. The discipline translates business and technical requirements into reliable applications, services, interfaces and digital capabilities that can be safely operated, enhanced and scaled over time.

Operating across software engineering, API development, database integration, testing, secure coding, DevOps and production support, App Development plays a critical role in delivering technology that is maintainable, resilient and aligned to enterprise standards. The discipline requires strong programming capability, sound engineering judgement, collaboration across technology and business teams, and the ability to balance speed of delivery with quality, security, reliability and long-term sustainability.

Key Responsibilities Solution Design & Application Development

  • Design and build software applications, interfaces, APIs and services that meet business requirements while remaining secure, scalable, maintainable and performant.
  • Translate functional and technical requirements into practical engineering solutions, selecting appropriate patterns, technologies and implementation approaches based on system context and delivery needs.
  • Develop and maintain application components across relevant technology stacks, which may include web, mobile, backend, integration, database or platform-specific environments.
  • Apply appropriate programming languages, frameworks and tools — such as Java, JavaScript, Python, Go, Kotlin, React, Angular, Android, HTML/CSS or equivalent technologies — where relevant to the application domain and platform context.

Code Quality, Testing & Engineering Standards

  • Write and maintain clean, readable, reusable and well-structured code that supports long-term maintainability and reduces avoidable technical debt.
  • Conduct and participate in code reviews to improve quality, consistency, security and adherence to engineering standards.
  • Develop and apply automated testing approaches, including unit, integration, API and regression testing, to strengthen delivery confidence and reduce defects.
  • Improve engineering practices by applying standards for version control, branching, documentation, peer review, test coverage and maintainable design.

Secure Development & Technology Risk

  • Implement secure coding practices to protect applications, data and customers from security vulnerabilities and technology risks.
  • Apply security fundamentals across application design and development, including authentication, authorisation, input validation, secrets management and secure API design where relevant.
  • Identify and remediate common application security issues, including web, mobile, API and data-related vulnerabilities.
  • Ensure development activities align with internal technology controls, software delivery standards and applicable governance requirements.

API, Integration & Data Engineering

  • Design and develop APIs, integration points and service interfaces that enable reliable data exchange between systems, platforms and digital channels.
  • Develop and optimise database structures, queries and data access patterns to support performance, scalability and reliability.
  • Apply database development and management practices across relevant database technologies, such as relational databases, MySQL or equivalent platforms, depending on application needs.
  • Support distributed system design by considering service boundaries, transaction handling, latency, resilience and dependency management.

DevOps, Deployment & Release Readiness

  • Support application deployment through CI/CD practices, automated build pipelines, version control and controlled release processes.
  • Collaborate with release, infrastructure and operations teams to ensure applications are deployment-ready and aligned to environment, configuration and operational requirements.
  • Use DevOps practices, containerisation or orchestration technologies — such as Docker, Kubernetes or equivalent platforms — where relevant to improve delivery consistency and application portability.
  • Prepare applications for production by ensuring appropriate configuration, documentation, operational handover and release readiness activities are completed.

Application Performance, Reliability & Supportability

  • Monitor and analyse application performance, errors, logs and operational metrics to identify reliability, scalability or user experience issues.
  • Troubleshoot and resolve technical issues across application code, APIs, databases, integrations, infrastructure dependencies or runtime environments.
  • Design and improve applications with supportability in mind, including observability, logging, error handling, recovery behaviour and operational diagnostics.
  • Strengthen application resilience by identifying failure points, reducing recurring incidents and improving system behaviour under real-world operating conditions.

Technical Problem Solving & Continuous Improvement

  • Investigate and resolve complex technical problems using structured analysis, debugging, experimentation and collaboration with relevant specialists.
  • Evaluate new tools, frameworks and engineering approaches where they improve maintainability, security, scalability, developer productivity or delivery efficiency.
  • Simplify and refactor systems, code and workflows to reduce complexity, improve performance and address technical debt.
  • Apply lessons learned from defects, incidents, reviews and delivery challenges to improve future engineering outcomes.

Stakeholder Collaboration & Delivery Alignment

  • Collaborate with product owners, business stakeholders, designers, testers, release teams, infrastructure teams and other engineers to align solutions with user and business needs.
  • Communicate technical options, risks, dependencies and trade-offs clearly to support effective decision-making.
  • Contribute to agile delivery practices by participating in planning, refinement, estimation, reviews and continuous improvement activities.
  • Document technical designs, implementation decisions, interfaces and support information to enable maintainability, knowledge sharing and operational continuity.
