Job Summary The Senior Full-Stack AI Engineer plays a central role in architecting and shipping end-to-end features for an advanced context-aware AI agent platform. This position bridges the gap between complex LLM architectures and highly reliable, polished full-stack user experiences across multi-channel conversations, persistent user memory, and asynchronous workflows. The ideal candidate is a hands-on engineer with deep technical expertise in modern TypeScript, React, and PostgreSQL, combined with strong backend systems thinking and functional literacy in LLM runtimes, retrieval mechanisms, and tool integration.

Responsibilities

  • Architect and ship end-to-end product features for a context-aware AI agent ecosystem.
  • Design robust REST/GraphQL APIs, performant PostgreSQL data models, and resilient asynchronous background job processing systems.
  • Build responsive, intuitive React frontend user interfaces tightly integrated with TypeScript backend services.
  • Implement, evaluate, and optimize LLM agent workflows, including prompt engineering, tool integration, retrieval architectures, and runtime execution.
  • Maintain production reliability, observability, strict data privacy boundaries, and edge-case handling across non-deterministic, complex user flows.

Qualifications And Job Requirements

  • Full-Stack Technical Depth: Strong professional experience with modern TypeScript, React, REST/GraphQL APIs, and relational database design (PostgreSQL).
  • Backend & Async Systems: Proven capability in building asynchronous background jobs, distributed queues, and conducting production-level system debugging.
  • AI/LLM Platform Literacy: Hands-on experience or deep technical fluency in LLM/agent runtime architectures, tool calling, prompt engineering, and retrieval systems (RAG).
  • Product Ownership: Demonstrated track record of converting ambiguous product requirements and user behaviors into clean systems design and polished end-user interfaces.
  • Engineering Rigor: Strong commitment to system correctness, data security/privacy boundaries, system observability, and edge-case handling.
  • Nice to Have: Background in fast-paced startup environments, experience with LLM evals/fine-tuning, or prior work on multi-channel conversational tools, persistent memory, or agentic workflow platforms.
