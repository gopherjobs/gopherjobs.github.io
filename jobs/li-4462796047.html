🚀 Founding Platform Engineer – AI Security

📍 London – Onsite

💰 Competitive Salary + Founding Equity + Bonus

We’re partnered with an early-stage AI Security company building infrastructure to secure the next generation of autonomous systems and AI agents.

Already working with high-assurance AI companies and government customers, they’re now looking for a Platform Engineer to become one of the foundational technical hires and help build the infrastructure that allows organisations to deploy AI agents safely.

This is a broad, high-ownership engineering role spanning distributed systems, backend engineering, cloud infrastructure, security and AI/ML infrastructure.

What You’ll Build 👇

  • Low-latency enforcement systems that evaluate and control AI agent activity
  • Distributed tracing and observability across agents, services, tools and model calls
  • Secure, multi-tenant backend services and data infrastructure
  • Tamper-evident audit and evidence systems
  • Event-driven and streaming infrastructure designed for reliability under load
  • Sandboxed environments for security testing and evaluation workloads
  • Model-serving infrastructure, including containerised workloads and GPU inference
  • Cloud infrastructure, deployment pipelines and production security controls

You’ll work directly with the founders and early customers, with real influence over architecture, engineering standards and product direction.

What They’re Looking For 🧠

  • Strong backend, systems or infrastructure engineering experience
  • Strong Python experience preferred
  • Distributed systems knowledge — latency, concurrency, retries, backpressure and failure handling
  • Production observability and distributed tracing experience
  • Strong PostgreSQL and multi-tenant architecture knowledge
  • Containers, cloud infrastructure and CI/CD
  • Good understanding of IAM, secrets management and infrastructure security
  • Someone comfortable owning critical systems from design through to production

Particularly Interesting ⚙️

Experience with any of the following would stand out:

PostgreSQL / RLS • OpenTelemetry • GCP • Cloud Run • Kubernetes / Containers • Distributed Systems • MLOps • GPU Inference • Sandboxing • IAM • Security Infrastructure

You don't need all of it — they're much more interested in evidence you've owned difficult production systems than someone who's collected every keyword like Pokémon cards.

Why Join? 💡

  • Join early enough to have founding-level technical influence
  • Build a systems engineering function rather than inherit one
  • Work on genuinely new infrastructure problems created by autonomous AI agents
  • Real customers and high-consequence AI deployments already using the technology
  • Direct access to founders with backgrounds across MIT, NASA, Microsoft, government and startups
  • Meaningful founding equity and a path into senior technical leadership
  • UK visa sponsorship available

If you’re a strong Platform/Systems engineer who wants to work at the intersection of distributed systems, infrastructure, security and AI, this is a seriously interesting one.
