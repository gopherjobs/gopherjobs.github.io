Senior Full-Stack Ruby & React Engineer at BairesDev

As a Senior Full-Stack Ruby & React Engineer, you will design and develop highly responsive web applications from end to end. You will connect high-performance server-side logic with intuitive frontend user interfaces to deliver seamless digital experiences.

What You'll Do

  • Architect and build robust backend APIs and scalable server-side systems.
  • Design dynamic, responsive, and highly accessible user interfaces following modern component-based architecture.
  • Integrate systems seamlessly via REST and GraphQL API structures.
  • Implement comprehensive unit and frontend testing suites to guarantee application reliability.
  • Optimize application performance and ensure compliance with security and accessibility standards.

What We Are Looking For

  • 5+ years of experience in Full-Stack Software Engineering, Ruby development, or related fields.
  • Proven expertise in frontend development using React, Next.js, and TypeScript.
  • Strong hands-on experience with state management, component architecture, and REST/GraphQL API integration.
  • Proficiency in unit and frontend testing, optimizing performance, and accessibility.
  • Advanced proficiency in English.
