Key Responsibilities:

  • Design, develop, and maintain complex, scalable, and resilient voice application architectures using Cisco CVP Call Studio.
  • Build and maintain enterprise-level VoiceXML (VXML) and call-control applications within the Cisco Unified Communications environment.
  • Architect and develop custom Java VoiceXML elements, hotlink components, and backend integration layers.
  • Design and implement REST/SOAP web service integrations connecting IVR applications with CRM, databases, core banking, and other enterprise systems.
  • Develop high-performance Java code for custom CVP elements, decision modifiers, event handling, and application logic.
  • Develop, enhance, and optimize VoiceXML applications to support reliable and efficient customer interactions.
  • Develop efficient SQL queries for integration with relational databases and backend systems.
  • Implement ASR, TTS, conversational AI, and NLP integrations to enhance IVR and voice application capabilities.
  • Manage application deployments across CVP VXML Servers, including subdialog configuration and media server setup.
  • Build and maintain CI/CD and automated deployment pipelines for Java code and Call Studio projects.
  • Troubleshoot complex call-routing issues, voice drops, application failures, and crashes by analyzing CVP VXML Server logs and application traces.
  • Optimize Java code and database queries to maintain low latency and prevent call delays.
  • Conduct code reviews and call-flow reviews to ensure adherence to Cisco best practices, security standards, and coding guidelines.
  • Provide technical guidance and mentorship to junior and mid-level contact center developers working with Java and Cisco Unified Contact Center technologies.
  • Collaborate with Business Analysts, Voice Engineers, and UX Designers to translate business requirements into intuitive and effective Voice User Interfaces (VUIs).
  • Participate in off-hours production code migrations and deployments as required.

Basic Qualifications :

  • Bachelor’s degree in Computer Science, Management Information Systems, or a related field.
  • 5+ years of experience with Cisco UCCE platforms.
  • 5+ years of IVR application development and production support using Cisco CVP/Voice, VXML, ASR, TTS, and Cisco Call Studio 10.5+.
  • 5+ years of experience with CVP Call Studio, Java, and backend integrations with databases and web services.
  • 5+ years of experience with Java 1.7+, Eclipse, Tomcat, Spring MVC, J2EE, SOAP, and REST APIs.
  • 5+ years of experience supporting QA activities and Release Management for voice/IVR applications.
  • 3+ years of experience designing and developing Advanced Speech Recognition solutions, preferably with Nuance.
  • 3+ years of experience in speech tuning, grammar analysis, and grammar development.
  • Experience designing Voice User Interfaces (VUI) with a strong understanding of caller usability and voice interaction flows.
  • Hands-on experience with CI/CD pipelines and deployment tooling, including Octopus and GitHub Actions.
  • Experience with unit testing and performance testing for voice/IVR applications.
  • Experience using Visio, MS Project, and Microsoft Office applications for technical documentation, planning, and project coordination.
  • Familiarity with Cisco third-party contact center products, such as Nuance, Finesse, Verint, or similar platforms.
