Description

Requirements

  • 2+ years of relevant professional software development experience.
  • Strong hands-on Python and FastAPI experience demonstrated through actual professional work.
  • Backend engineering must be your primary strength. AI-only profiles without real backend development experience will not be considered.
  • Experience shipping GenAI applications, RAG pipelines or AI agents in a real professional role. Internship projects and personal side projects alone do not qualify.
  • Hands-on experience with LangGraph, embeddings, vector search and LLM integrations.
  • Experience working with MongoDB and designing database schemas and indexes.
  • Understanding of asynchronous Python programming, API design and HTTP integrations.
  • Experience handling HTTP requests, media processing or integrations involving image, audio and video data.
  • Strong debugging skills, including investigating logs, identifying root causes and fixing production issues.
  • Strong code ownership. You must be able to explain the implementation and technical decisions behind your work.
  • Every technical claim and metric mentioned in your resume must be explainable and verifiable.
  • Willingness to work six days a week.
  • Willingness to work in a hybrid setup in Mumbai, with three days in the office. Remote hires must work in person for the first two months.

Responsibilities

  • Build and maintain backend services using Python and FastAPI.
  • Develop and ship production-ready AI applications, agents and RAG pipelines.
  • Build AI workflows using LangGraph, embeddings, vector search and LLM integrations.
  • Design APIs and asynchronous services that support AI-powered product experiences.
  • Integrate external APIs and handle HTTP, image, audio and video data.
  • Work with MongoDB and other databases to build efficient data models and optimise queries.
  • Debug and improve existing backend services and AI workflows.
  • Monitor application performance, investigate production issues and improve system reliability.
  • Work closely with the product and engineering teams to ship AI features from development to production.

Job Details

Mumbai, India. Hybrid, three days in office.
