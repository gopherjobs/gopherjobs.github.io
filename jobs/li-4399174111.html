Job Description HungerStation is hiring a Senior Data Engineer I to design, build, and scale our data platform and processing frameworks that power analytics, AI-driven applications, and business intelligence across the organization.

This role sits at the core of our data ecosystem focusing on scalability, reliability, and performance of data systems .

You Will Be Working On

  • Design, implement, and extend scalable data platforms and architectures
  • Build and maintain high-performance data pipelines and data models using BigQuery
  • Optimize datasets and workloads for performance and cost efficiency
  • Develop analytics-ready data models, semantic layers, and governed metrics
  • Build backend services and APIs using Python or Java to support data applications
  • Contribute to AI-enabled data use cases (e.g., automated insights, conversational analytics)
  • Improve system reliability by addressing technical debt and scaling challenges
  • Implement best practices across CI/CD, testing, monitoring, and deployment automation
  • Manage and optimize cloud infrastructure supporting the data platform
  • Collaborate with cross-functional teams to ensure data quality and engineering standards
  • Ensure compliance with data governance, privacy, and security standards
  • Improve monitoring frameworks and operational resilience of the data platform
  • Support initiatives to enhance data quality, reliability, and system stability

Qualifications

  • 5–8 years of experience in Data Engineering or similar roles
  • Bachelor’s degree in Computer Science, Engineering, or related field
  • Master’s or relevant certifications are a plus
  • Strong experience building scalable distributed data systems
  • Hands-on with GCP (BigQuery preferred)
  • Proven experience with ETL/ELT pipelines and data modeling
  • Experience with modern data stack (Airflow, dbt, Looker)
  • Strong SQL skills and understanding of relational data systems
  • Experience with Python or Java for backend/data services
  • Familiarity with Infrastructure-as-Code (Terraform preferred)
  • Experience with CI/CD, testing, and monitoring practices
  • Exposure to AI-driven data applications or LLM integrations is a plus
