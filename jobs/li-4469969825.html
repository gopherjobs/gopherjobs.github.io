Description

Job Overview

We are seeking a dynamic and detail-oriented Jr. Software Test Engineer to join our innovative technology team. In this role, you will be instrumental in ensuring the quality and reliability of our software products across various platforms, including web and mobile applications. Your energetic approach to testing will help drive continuous improvement, streamline release cycles, and enhance user satisfaction. This is an exciting opportunity for a motivated individual passionate about software quality assurance and eager to grow their skills in a fast-paced environment.

*** This is in-person job in our Exton PA office. No remote or Hybrid and no. You must be authorized to work without any

sponsorship ***

Duties

  • Develop, execute, and maintain comprehensive test cases and test plans based on detailed requirements and user stories.
  • Perform functional, system, regression, performance, and user acceptance testing (UAT) to validate software features and identify defects early in the SDLC (Software Development Life Cycle).
  • Conduct API testing using RESTful services, SOAP web services, and tools like Postman or REST-assured to verify data integrity and system integration.
  • Collaborate with developers, business analysts, and DevOps teams to troubleshoot issues through root cause analysis, debugging, and defect tracking using tools like Jira or HP ALM.
  • Support continuous integration/continuous deployment (CI/CD) pipelines with Jenkins, GitLab, or Azure DevOps to ensure smooth release management.
  • Perform mobile testing on Android and iOS platforms using emulators or real devices; validate app performance across different devices and operating systems.
  • Analyze test results using SQL queries on databases such as NO SQL or MySQL, generate detailed reports to communicate quality status effectively.
  • Participate in requirements gathering sessions to understand business needs; translate them into effective test strategies aligned with Agile or Waterfall methodologies.

Requirements

  • Bachelor’s degree in Computer Science, Information Technology, or a related field; relevant certifications are a plus.
  • Strong knowledge of programming languages such as Java, Python, JavaScript or C# for scripting automated tests.
  • Familiarity with mobile testing frameworks for Android and iOS applications; experience with Appium is preferred.
  • Hands-on experience with API testing using RESTful APIs; knowledge of JSON/XML data formats is essential.
  • Understanding of SDLC (Software Development Life Cycle), Agile practices like Scrum or Kanban, and version control systems such as Git or SVN.
  • Ability to perform SQL queries for data validation; experience with MySQL or NOSQL DB like Couchbase is preferred.
  • Excellent analytical skills for defect identification and troubleshooting; strong attention to detail in test case design and execution.
  • Knowledge of DevOps practices including CI/CD pipelines, release management tools like Jenkins or Azure DevOps is advantageous.
  • Effective communication skills to collaborate across teams; proactive attitude toward learning new testing methodologies and tools.
