YOUR ROLE

At Palo IT, every engineer is AI-Native. As an AI-Native Engineer (Software), you will design, build, and deliver production-grade applications while actively using AI and Generative AI as part of your daily engineering workflow.

You will work primarily with modern fullstack technologies for frontend and backend , with exposure to cloud platforms (Azure, AWS, GCP). You will apply Palo IT's Gen-E2 methodology to accelerate delivery, improve code quality, and build scalable, secure applications.

Key Responsibilities

Software Engineering & Development

  • Design, build, and maintain full stack applications using modern frameworks (ReactJS, NodeJS, Java, Python or equivalent)
  • Develop scalable, reliable, and secure applications following modern software engineering practices.
  • Implement CI/CD automation pipelines and understand DevOps workflows.
  • Ensure code quality through testing, code reviews, and performance optimisation .

AI-Native Engineering (Core Expectation)

  • Use Generative AI coding tools (e.g., GitHub Copilot, Cursor) as a first-class engineering assistant for:
  • Code scaffolding and refactoring
  • Code generation and optimisation
  • Test-cases and documentation generation
  • Build applications through AI-driven development practices , including:
  • AI-assisted debugging and troubleshooting
  • Intelligent code completion and pattern recognition
  • Automated documentation generation
  • Apply prompt engineering best practices for reliable, repeatable engineering outcomes.
  • Validate GenAI output (determinism checks, guardrails, fallback logic).

Collaboration & Delivery

  • Collaborate with project teams, product managers, and designers to deliver high-quality solutions.
  • Contribute to Gen-E2 practices , and internal playbooks.
  • Support solution discussions and technical discovery when required.

Must-Have Experience

  • 3+ years of hands-on software development experience. Preferred technologies include ReactJS for frontend development and NodeJS/Java for backend development.
  • Understanding of relational and non-relational databases.
  • Experience with testing frameworks and code quality practices.
  • Strong understanding of common programming patterns and principles.
  • Demonstrated use of AI tools in day-to-day engineering work (not just theoretical exposure).

AI-Native & Gen-E2 Skills (Required)

  • Hands-on experience with GitHub Copilot or equivalent AI coding assistants .
  • Ability to build and evolve applications using GenAI assistance .
  • Strong understanding of prompt engineering for technical use cases.
  • Experience validating and controlling GenAI outputs (hallucination handling, code review of AI-generated code).
  • Critical thinking to verify AI-generated code and solutions.

Good to Have

  • Experience with cloud computing platforms (Azure, AWS, GCP).
  • Experience with solution architecture principles.
  • Exposure to AI/ML services and frameworks .
  • Native mobile development (iOS, Android) or hybrid mobile development (Flutter, React Native).
  • Certification in Claude AI (Anthropic) is a plus.
