Role Overview

We’re growing our Data and Integration team in Cape Town and are looking for a Developer to help build and maintain the applications and integrations that connect our clients’ systems.

The immediate focus of this role is application and integration development – writing clean, reliable code that connects APIs, automates processes and keeps data flowing accurately between systems, as part of wider data platform and integration programmes.

You’ll work with Python, SQL, REST APIs, Azure services and Git, contributing to both new development and ongoing support, while following agile ways of working and taking pride in the quality of what you ship.

This is a consulting role, so alongside solid engineering skills, we’re looking for someone who can pick up a requirement, ask the right questions, and deliver a well-tested solution with minimal hand-holding.

You’ll work closely with our Integration, Data Engineering and Data Quality teams, and with client stakeholders, as we continue building modern, reliable data and integration solutions.

Location: This is a hybrid role based in Cape Town, with a minimum of three days per week in our Woodstock office. Candidates looking to relocate to Cape Town are welcome to apply, although any relocation costs would need to be covered personally.

What You’ll Do:

  • Design, build and maintain applications and integrations connecting client systems and data sources.
  • Develop and consume REST APIs, working with JSON/XML payloads and common authentication patterns.
  • Write clean, well-tested Python and SQL code for integration, automation and data-handling tasks.
  • Use Git for version control, following good branching, code review and release practices.
  • Build scripts and automations that remove manual effort and reduce operational risk.
  • Work within Azure services (e.g. Azure Functions, Logic Apps, Data Factory) to support integration and data flows.
  • Debug and troubleshoot issues across applications, integrations and pipelines, working through to root cause.
  • Write and maintain test cases, and support broader testing efforts to ensure solutions are reliable before release.
  • Work within an agile delivery model – participating in sprint planning, stand-ups and reviews.
  • Document technical designs, code and processes clearly for both technical and non-technical audiences.
  • Collaborate with Integration Consultants, Data Engineers and QA colleagues to deliver end-to-end solutions.

What You Bring

We’re looking for someone with solid, hands-on development experience and a collaborative, consulting mindset.

  • Strong hands-on experience with Python and SQL.
  • Practical experience building and consuming REST APIs.
  • Comfortable working with Git and standard version control workflows.
  • Experience with scripting and automation to solve practical business problems.
  • Working knowledge of Azure services used in application or integration development.
  • Confidence debugging issues across code, integrations and data flows.
  • Experience working within an agile delivery framework.
