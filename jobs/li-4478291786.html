Job Title: Full-Stack Software Engineer About The Company CoinFlip is a digital currency platform that acts as a bridge between the physical cash economy, traditional banking, and cryptocurrency.

Job Description On your first day, you will focus on security clearances, access provisioning, and setting up your local development environment. By the end of the first week, you will map out the core transaction microservices architecture. You will also ship a low-risk starter code change through the continuous integration and continuous deployment pipeline to the staging environment.

Responsibilities Of The Role

  • Build and debug modern client applications using TypeScript and React/Next.js.
  • Design, write, and debug production REST APIs in Node.js/TypeScript or Golang.
  • Write efficient SQL queries, joins, and perform basic schema design for transaction and onboarding services.
  • Own a feature from the database layer through the API and out to the user interface.
  • Consume infrastructure managed by DevOps/Platform engineers.
  • Read logs, trace errors, and read dashboards using observability tools.
  • Understand core cloud fundamentals like S3, basic networking, and environment configurations.
  • Implement real-time transaction updates using WebSockets and Webhooks.
  • Utilize Go concurrency features like Goroutines and Channels for high-throughput transaction processing.
  • Use AI-assisted tools like Cursor or Copilot for productivity.

Required Experience And Qualifications

  • 3+ years of full-stack delivery experience.
  • Proficiency in TypeScript and React/Next.js.
  • Strong backend skills in Node.js/TypeScript or Golang.
  • Experience with SQL and relational databases, specifically PostgreSQL.
  • Basic familiarity with Kubernetes, Helm, and Terraform.
  • Familiarity with observability platforms like Grafana.
  • Understanding of core AWS services (S3, networking, environment configurations).
  • C1 or C2 English level.

Preferred Skills

  • Experience with WebSockets and Webhooks.
