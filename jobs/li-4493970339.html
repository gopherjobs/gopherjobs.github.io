Description

Client: Ministry of Public and Business Service Delivery and Procurement – RQ11623

We are seeking a highly experienced Senior Systems Testing/QA Specialist with over 10 years of experience in software testing within enterprise-level IT environments and large-scale systems. The ideal candidate will have strong hands-on expertise in manual and automated testing, test strategy development, test planning, test case creation, test execution, defect management, and quality assurance. The successful candidate will be responsible for planning and executing functional, integration, system, regression, performance, stress, load, and user acceptance testing while ensuring software quality, data integrity, accessibility compliance, and adherence to industry standards and best practices.

Description Responsibilities

  • Provides advice on the testing strategy, test plans, the selection of testing tools, and the identification of resources required for testing.
  • Plans and organizes testing efforts for large systems in Graphical User Interface (GUI) and non-Graphical User Interface (GUI) environments, including the execution of systems integration tests, specialized tests, and user acceptance testing (e.g., stress tests).
  • The Quality Assurance Specialist is responsible for the development of test plans, test scripts and test cases and executing these against the various components. The tester will work with the testing lead and IT lead of each project as well as the project team members in the analysis, design, development, implementation and ongoing support of the required systems.
  • Executes functional, integration, system, and regression tests.
  • Validates that the system behaves as expected under various conditions.
  • Identifies, documents, and tracks software defects using tools like ALM, JIRA, Bugzilla, and Azure DevOps.
  • Works closely with developers to reproduce and resolve issues.
  • Develops and maintains automated test scripts using tools like Micro Focus, OpenText™ UFT, Selenium, Test Complete, or Postman.
  • Integrates automated tests into CI/CD pipelines.
  • Conducts performance, stress, and load testing to ensure the system can handle expected user traffic and data volumes.
  • Knowledge and understanding of Accessibility for Ontarians with Disability Act (AODA) and related regulations and standards.
  • Collaborates with developers, business analysts, and project managers to clarify requirements and ensure quality.
  • Participates in Agile ceremonies like sprint planning, daily stand-ups, and retrospectives.
  • Maintains detailed documentation of test results, test coverage, and quality metrics.
  • Provides input for user manuals and release notes.
  • Ensures testing processes comply with industry standards and regulatory requirements.
