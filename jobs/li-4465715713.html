Your Profile & DNA:

We are looking for an experienced API Security Engineer who will contribute to the API security strategy, standards, governance and implementation across a reputed bank, ensuring APIs meet internal security requirements and are protected against evolving threats..

Roles & Responsibilities

  • Translate API security standards, controls and best practices into practical platform policies, security controls and automated guardrails.
  • Develop and automate business logic and security policies to protect the bank’s API landscape.
  • Assess API security findings and determine their severity, criticality and business impact.
  • Translate security findings into concrete improvements to policies, controls and business rules.
  • Work closely with software engineers, architects and security specialists to embed security throughout the API lifecycle.
  • Help ensure APIs are secure, compliant, resilient and aligned with the bank’s security architecture.
  • Contribute to the continuous improvement of API security standards and governance.

Qualification & Experience

  • A Bachelor's or Master's Degree or equivalent.
  • Strong knowledge of cybersecurity principles and security architecture, including cloud and application security.
  • Deep expertise in API and application security.
  • Strong understanding of security frameworks and standards such as OWASP Top 10, MITRE and CVE.
  • Advanced knowledge of authentication and authorization, including OAuth, JWT, session management, mTLS, object-level authorization and attribute-level authorization.
  • The ability to assess security risks and translate complex findings into practical security improvements.
  • Experience translating security requirements into platform policies, automated controls and guardrails.
  • Excellent communication skills and the ability to work effectively with both technical and security stakeholders.
  • A proactive attitude with a strong sense of ownership and responsibility.

Good-to-Have Skills

  • Experience managing or working with API Security platforms, such as Akamai, Noname, Salt or Cequence.
