Description

Client: Ministry of Treasury Board Secretariat – RQ11843

We are seeking a highly experienced Senior Software Developer with strong expertise in developing, designing, implementing, and maintaining n-tier enterprise applications. The ideal candidate will have extensive hands-on experience with Java, Spring Boot, Spring Framework, React, Angular, PostgreSQL, PL/pgSQL, Azure Cosmos DB, and modern cloud technologies. The successful candidate will be responsible for translating business requirements and technical specifications into scalable, secure, and fully tested applications, developing robust backend services and responsive frontend components, designing RESTful APIs and microservices, optimizing database performance, and supporting application deployment, integration, and migration activities. The candidate should also possess strong analytical, problem-solving, communication, and collaboration skills, along with experience working in Agile development environments.

Description Responsibilities

The successful candidate will be responsible for translating technical systems specifications into working, tested applications. This includes:

  • Developing detailed programming specifications.
  • Writing and/or generating code, compiling data-driven programs, maintaining applications, and conducting unit tests.
  • Resolving and troubleshooting technical problems that arise during the use and operation of software packages, including providing technical assistance with implementation, conversion, and migrations.
  • Translating business requirements and technical specifications into scalable, secure, and fully tested full-stack applications.
  • Developing detailed technical designs and programming specifications.
  • Writing, reviewing, and maintaining clean, efficient, and maintainable code following best practices.
  • Building and enhancing data-driven applications and backend services.
  • Designing and executing unit, integration, and end-to-end tests to ensure quality and reliability.
  • Designing and implementing modern, responsive frontend components using React.
  • Developing robust backend services and APIs using Spring Boot.
  • Building and maintaining RESTful APIs and microservices architectures.
  • Troubleshooting and resolving technical issues across development, testing, and production environments.
  • Supporting application deployment, data migration, and system integration activities.
  • Collaborating with cross-functional teams through code reviews, design sessions, and Agile ceremonies.
  • Ensuring all solutions meet security, performance, scalability, and accessibility standards, including AODA compliance.
  • Contributing to the continuous improvement of development processes, tools, and standards.
  • Providing technical support for implementation, system integration, data conversion, and migration activities.

Additional Skills For Oracle Software Developer

  • Strong experience with PostgreSQL and SQL, Azure Cosmos DB.
  • Experience in schema design and normalization, query optimization and indexing, and writing database functions (PL/pgSQL preferred).
