Description

Hungerstation is part of the Delivery Hero Group, the world’s pioneering local delivery platform, our mission is to deliver an amazing experience—fast, easy, and to your door. We operate in around 65 countries worldwide. Headquartered in Berlin, Germany. Delivery Hero has been listed on the Frankfurt Stock Exchange since 2017 and is part of the MDAX stock market index.

Job Description We’re looking for an experienced Senior Security Engineer I to help strengthen our security posture across applications, cloud infrastructure, and CI/CD pipelines. You’ll work closely with engineering teams to proactively identify risks, embed security by design, and drive resilience at scale. This role will be responsible in helping improve the information security of HungerStation users, partners, and employees.

Key Responsibilities Application Security & DevSecOps (DSOMM)

  • Ensure implementation of defined secure coding standards
  • Conduct manual code and architecture reviews
  • Embed security tools and controls into CI/CD pipelines
  • Partner with engineers to identify, prioritize, and remediate vulnerabilities

Penetration Testing & Red Teaming

  • Perform white-box and black-box VAPT for web, mobile, and cloud/on-prem environments
  • Execute advanced red teaming exercises
  • Produce detailed security assessment reports and track mitigation actions to closure

Cloud Security

  • Implement and maintain relevant cloud security tools
  • Strengthen cloud infrastructure against internal and external threats
  • Enhance security monitoring and detection across cloud environments

Governance, Risk & Resilience

  • Follow established security policies, processes, and controls
  • Contribute to continuous improvement of security practices and frameworks
  • Promote a high-performance culture aligned with company values

Qualifications

  • 5–8 years of relevant experience in application, cloud, or security engineering roles
  • Bachelor’s degree in Information Security, Computer Science, or a related field
  • Master’s degree is a plus
  • Certifications in OSCP, OSCE, CDP is a plus
