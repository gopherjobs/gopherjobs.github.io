Description

Job Description As AI Automation Specialist with a strong passion for AI-native software engineering and hands-on expertise in Agentic AI, Generative AI, and autonomous development frameworks. The ideal candidate will be capable of translating business requirements into production-ready applications by leveraging AI-powered development workflows, multi-agent systems, and modern software engineering practices. This role requires the ability to rapidly design, build, test, and deploy customer-specific software solutions using a combination of strong programming skills, telecom OSS knowledge, and AI-assisted development tools.

How You Will Contribute And What You Will Learn

  • Design, develop, and deploy AI-native, cloud-native, and web-based applications using Go, Java, Python, microservices, and distributed system architectures.
  • Build end-to-end software solutions using Agentic AI frameworks, LLMs, and AI-assisted development tools to accelerate software delivery.
  • Develop scalable backend services, REST APIs, automation platforms, and enterprise applications using Spring Boot and event-driven architectures.
  • Design and orchestrate AI agents, multi-agent systems, autonomous workflows, and intelligent copilots to automate engineering and business processes.
  • Integrate Generative AI, LLMs, RAG pipelines, MCP-based integrations, and AI assistants into telecom OSS and enterprise applications.
  • Leverage AI-powered tools such as GitHub Copilot, Cursor, Claude, and ChatGPT for code generation, testing, debugging, documentation, and deployment.
  • Build scalable, secure, and resilient applications using Docker, Kubernetes, Kafka, and modern cloud-native technologies.
  • Collaborate with cross-functional teams to deliver customer-specific solutions, optimize performance and code quality, and adopt emerging AI technologies to improve productivity and innovation.

Key Skills And Experience You have:

  • Bachelor’s degree in Engineering (B.E./B.Tech) with 5–10 years of relevant software engineering experience and the ability to design, develop, and deliver production-ready software solutions.
  • Strong proficiency in Go and/or Java, with expertise in microservices, APIs, distributed systems, and cloud-native development.
  • Hands-on experience with Agentic AI, Generative AI, LLMs, AI agents, RAG, and MCP-based integrations.
  • Expertise in AI coding assistants and autonomous development tools such as GitHub Copilot, Cursor, and Claude to accelerate software development.

It would be nice if you also had:

  • Ability to build intelligent applications integrating AI-driven reasoning, orchestration, and automation with traditional software engineering.
  • Experience with Docker, Kubernetes, Kafka, cloud-native architectures, and CI/CD pipelines.
  • Strong understanding of software architecture, design patterns, scalability, engineering best practices, and end-to-end solution development.
  • Telecom OSS/BSS experience and knowledge of NETCONF, RESTCONF, YANG, network automation, and AI integration into enterprise applications are strong advantages.
