Role: API Developer

Location: Remote

Role Overview:

We are hiring an API Developer to design and build the interfaces that

connect Joveo's platform to clients, partners, and internal services.

You will create APIs that are fast, reliable, well-documented, and built

to be consumed by developers worldwide.

Key Responsibilities:

- Design, develop, and maintain RESTful and/or GraphQL APIs

- Define and enforce API standards — versioning, pagination, error handling, rate limiting

- Build API authentication and authorization layers (OAuth2, JWT, API keys)

- Write OpenAPI/Swagger documentation and maintain developer-facing API references

- Monitor API performance, latency, and reliability in production

- Work with frontend, mobile, and partner integration teams as a technical API liaison

Required Skills & Qualifications:

- Strong experience designing and building production REST and/or GraphQL APIs

- Proficiency in at least one backend language (Python, Node.js, Go, or Java)

- Deep understanding of API security — authentication, authorization, and rate limiting

- Experience with API gateway tools (Kong, AWS API Gateway, or Apigee)

- Familiarity with OpenAPI specification and API documentation best practices

- Strong understanding of HTTP, caching strategies, and performance optimization
