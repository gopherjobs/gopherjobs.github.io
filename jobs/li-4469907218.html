Description

Job Title: Senior Platform Engineer (Argo CD)

Location: Brazil (Remote)

Employment Type: Contract

Key Responsibilities:

  • Operate Kubernetes-based application platforms across EKS, OKE, and related cloud environments
  • Drive GitOps delivery using Argo CD, including ApplicationSets, app-of-apps patterns, environment-specific values, and safe production sync practices
  • Support Helm chart workflows, including shared Helm chart libraries, OCI chart publishing, chart versioning, and per-application configuration repositories
  • Improve developer experience by creating reusable platform patterns, documentation, templates, runbooks, and tooling
  • Support cloud migration initiatives, including modernization and migration of workloads from AWS infrastructure to OCI/OKE
  • Improve platform reliability through monitoring, alerting, logging, tracing, SLOs, and operational visibility
  • Contribute to infrastructure automation using Infrastructure-as-Code, CI/CD automation, Kubernetes manifests, Helm charts, and GitOps repositories
  • Support security and multi-tenancy through RBAC, namespace boundaries, AppProject policies, secret-management patterns, and secure platform access
  • Troubleshoot deployment failures, Kubernetes issues, Argo CD drift, chart rendering problems, resource health, and production reliability issues
  • Collaborate with CMS, Sports, Games, Media, QA Engineering, Shared Services, Network Engineering, and InfoSec teams

Required Qualifications:

  • Strong hands-on experience with Kubernetes in production environment
  • Experience operating Argo CD or similar GitOps deployment systems
  • Experience with Helm, Kustomize, Kubernetes YAML, and Git-based deployment workflow
  • Cloud experience with AWS, OCI, or similar cloud providers
  • Familiarity with containerized application delivery using Docker and Kubernetes
  • Experience with CI/CD systems such as GitHub Actions, Jenkins, CircleCI, or similar
  • Strong troubleshooting skills across Kubernetes workloads, networking, ingress, DNS, secrets, and deployment pipeline
  • Working knowledge of observability tools such as Prometheus, Grafana, Loki, Tempo, Datadog, CloudWatch, or OCI-native monitoring
  • Experience with Git workflows, pull requests, code reviews, and environment promotion
  • Ability to write clear documentation, operational runbooks, and platform guidance
  • Strong communication skills and experience working with distributed engineering teams.

Preferred Qualifications:

  • Experience with Argo CD ApplicationSets, AppProjects, multi-cluster deployment, and production sync strategies
  • Experience publishing and consuming OCI Helm charts, including GitHub Container Registry and OCIR
  • Experience with External Secrets Operator, AWS Secrets Manager, OCI Vault, or Vault-based secret workflows
  • Experience with Terraform, OpenTofu, Crossplane, or other Infrastructure-as-Code tools
  • Experience supporting migrations from AWS EKS to OCI OKE
  • Familiarity with ingress controllers, load balancers, WAF/CDN patterns, Fastly, Cloudflare, or similar edge infrastructure
  • Experience designing multi-tenant Kubernetes platforms with RBAC, namespaces, quotas, and policy enforcement.
  • Familiarity with Grafana LGTM Stack, OpenTelemetry, or managed observability platforms.
  • Scripting or development experience in Go, Python, Bash, TypeScript, or similar
  • Experience supporting high-traffic media, sports, CMS, or consumer digital platforms
