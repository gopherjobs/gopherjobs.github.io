Role Overview

We are hiring a Full Stack Engineer to build features end-to-end across our web application. The role spans frontend, backend, and the database underneath — partnering with product and design to ship things that work and scale.

Key Responsibilities

- Build user-facing features end-to-end, from UI through API to database

- Write clean, maintainable code with appropriate test coverage

- Design APIs and data models that hold up as the product grows

- Conduct code reviews and contribute to engineering practices

- Diagnose and resolve production issues across the stack

- Partner with product and design on feasibility and trade-offs

Required Skills and Qualifications

- 3+ years building production web applications end-to-end

- Strong proficiency in JavaScript/TypeScript and a modern frontend framework (React, Vue, or similar)

- Backend experience with Node.js, Python, Ruby, or Go

- Experience with relational databases and writing efficient SQL

- Familiarity with cloud platforms (AWS, GCP, Azure) and CI/CD

- Solid testing discipline and Git workflow experience

What You'll Bring

- Curiosity to dig into systems and turn findings into shipped improvements

- Strong written communication and ability to explain technical decisions

- A test-and-learn mindset; you ship fast, measure, and iterate

- Comfort working asynchronously across time zones

What We Offer

- Fully remote, flexible work hours

- Performance-based bonus structure

- Annual learning & development stipend

- Health and wellness benefits (varies by location)

- Opportunity to work on high-scale, real-world impact projects
