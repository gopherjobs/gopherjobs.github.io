General Summary Job Description Qualcomm IT is seeking an experienced full-stack lead with experience in the IP space. We are looking for someone who architects, designs, develops and supports custom IP analysis applications for one of the world’s largest patent portfolios. Should be able to builds custom applications using latest web technologies to deliver the data in a faster and more efficient manner to meet the dynamic needs of our legal partners.

Principal Duties And Responsibilities

  • Design, develop and support intuitive tools which helps the attorneys and engineers to analyze, manage and identify the value of the invention and to manage patent data. | Builds analytics tool for IP engineers to analyze the patent portfolio using various parameters (e.g. technology, financial standing).
  • Builds custom applications using latest web technologies (Angular / React, Java 8+, Python, Relational & NoSQL databases, Spring, Hibernate, Apache Solr, Messaging system, HTML5, CSS3, JavaScript, ES6 and TypeScript) to deliver the data in a faster and more efficient manner as our legal partners strategies change
  • Develops and supports integration tools to integrate internal invention and patent management systems with Global Patent offices.
  • Automates Legal team’s internal processes, systems and tools.
  • Automates business workflows and processes.
  • Builds and deploys all applications through automatic jobs in Cloud (AWS, Jenkins) to support 100% up time
  • Mentors / Guides the team on development standards, good design practices etc & ensure compliance as needed (frequent code reviews, spot checks etc).
  • Identify opportunities for process improvement and make constructive suggestions for change. | Manage priorities and work in a fast pace environment.
  • Should effectively communicate with business partners, analysts, project manager & team members on functional & technical aspects as needed | . Also, one or more of JavaScript frameworks like AngularJS, React.js etc.
  • Development experience in a BDD or TDD approach
  • Knowledge and experience in AWS, Cloud & Micro Services
  • Requirement analysis, design, code reviews, deployments etc along with development | Product development and unit testing frameworks
  • Strong knowledge of software development best practices, design patterns, and architectural principles
  • Familiarity with agile methodologies and experience working in an Agile/Scrum development environment.

Minimum Qualification -

  • 12+ years of experience in software development with highly reputed organizations
  • Proficiency in Java 8 or higher, Python, Groovy, Spring, Hibernate
  • Excellent problem-solving skills
  • Deep understanding of data structures and algorithms
  • Expertise in full-stack development along with proven experience on building user interfaces using technologies like Angular / React JS and other necessary web technologies
  • Proven experience in building cloud native software preferably with AWS
  • Proven experience in design and develop data models using RDBMS (Oracle, MySQL, etc.) and NoSQL (MongoDB)
  • Experience in building solutions using Apache Solr or Elastic search
