AI Platform Engineer

AI Platform Engineers build infrastructure and tools for hosting, monitoring, and serving AI models.

Apply for this roleManage an applicationBack to careers

Overview AI Platform Engineers build infrastructure and tools for hosting, monitoring, and serving AI models.

Responsibilities

  • Design serving infrastructure: Develop scalable and secure API gateways, model servers, and data pipelines.
  • Implement orchestration: Use container orchestration tools (e.g., Kubernetes) to manage deployment and scaling.
  • Monitor performance: Implement logging, metrics, and dashboards to track system health.
  • Collaborate with MLOps and backend teams: Ensure integration across research prototypes and production services.

Qualifications

  • Bachelor's degree in software engineering or related field.
  • Experience with cloud platforms, containerization, and distributed systems.
