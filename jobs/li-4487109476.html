Description

We are hiring a Full-Stack Engineer to design, build, and run production applications on Microsoft Azure, from APIs and data to the web interfaces clients use every day.

Much of the work starts with prototypes and AI-assisted builds that prove an idea but aren't ready for real clients. You'll turn them into secure, tested, observable systems that scale, working closely with AI/ML engineers, product and project managers, CX designers, and operations teams.

What You'll Do

Build backend services: Develop APIs and services with clear boundaries, automated tests, and code review.

Build frontend applications: Create client portals, internal consoles, admin screens, and dashboards.

Take prototypes to production: Review AI-generated and prototype codebases, determine what to keep or rebuild, and prepare them for real users.

Integrate AI services: Connect AI models and services, including real-time features.

Run applications on Azure: Manage infrastructure as code and CI/CD across development, staging, and production environments.

Connect third-party systems: Build integrations with CRMs, ticketing tools, and other platforms.

Maintain reliability and observability: Implement logging, metrics, tracing, alerts, and participate in an on-call rotation.

Protect data: Implement authentication, multi-tenant isolation, secure secrets management, and safe handling of personal data.

Document solutions: Maintain clear technical documentation that helps other engineers work effectively.

Our Technology Stack

Frontend: TypeScript, React, Next.js, Azure Static Web Apps, or Azure App Service.

Backend: Node.js, Python, Azure App Service, Container Apps, and Functions.

Data: PostgreSQL or Azure SQL, Cosmos DB, Redis, and Blob Storage.

Messaging: Azure Service Bus, Event Grid, and Event Hubs.

Identity and access: Microsoft Entra ID, Entra External ID, managed identities, and role-based access control (RBAC).

Security: Azure Key Vault, virtual networks, private endpoints, and Microsoft Defender for Cloud.

Delivery: Docker, Azure Container Registry, Bicep or Terraform, GitHub Actions, or Azure DevOps.

Observability: Azure Monitor, Application Insights, Log Analytics, and OpenTelemetry.

Working Environment

You’ll work remotely from Colombia or Mexico, collaborating with AI/ML engineers, project management, CX design, and BPO operations teams. Working hours are aligned with EST business hours.
