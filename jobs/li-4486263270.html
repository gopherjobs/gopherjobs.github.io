Description

About TD SYNNEX TD SYNNEX is a Fortune 500 global company operating in more than 100 countries with a diverse workforce of over 22,000 employees .

As one of the world's leading IT distributors and solutions aggregators, we connect technology vendors, resellers, and customers to deliver innovative IT solutions that power digital transformation and enable businesses to operate securely and efficiently.

In This Role You Will

  • Build, deploy and operate pro-code AI agents, tools, APIs and shared platform services in Python or C#/.NET.
  • Design secure communication between users, agents, tools and enterprise systems, using MCP and REST APIs as appropriate.
  • Create reusable components and reference implementations that other engineering teams can adopt, maintain and update.
  • Work with Cloud, Identity, Security and API teams on hosting, connectivity, gateway controls and authorization.
  • Use automated tests, infrastructure as code and CI/CD to deliver services through controlled environments.
  • Establish evaluation, monitoring, tracing, incident response and cost visibility for deployed agents.
  • Help other teams move agent solutions from prototypes to supported production services, with clear ownership and handover.

Essential Skills & Experience

  • Strong production software engineering in Python or C#/.NET (either language; both are not required).
  • Hands-on experience building agents with Microsoft Agent Framework or a comparable pro-code agent framework, including orchestration and tool use.
  • Experience designing, delivering and operating enterprise services or shared capabilities used by multiple teams.
  • Practical understanding of APIs, MCP or comparable tool-integration patterns, and versioned contracts.
  • Experience across the production SDLC: automated tests, code review, CI/CD, deployment, observability, incident troubleshooting and recovery.
  • Working knowledge of cloud infrastructure, containers, infrastructure as code, networking and secrets management.
  • Understanding of OAuth 2.0/OIDC, workload and user identities, and authorization across service boundaries.

Preferred

  • Experience with Microsoft Foundry, Azure API Management, Azure DevOps or comparable platforms.
  • Experience with gateway controls and identity integration across systems.
  • Experience enabling teams through technical documentation, examples and reusable delivery patterns.
