Description

Title: API Developer

Location: Remote

Duration: 12 month contract

Compensation: Competitive, based on experience

Work Requirements: Citizen of the country of employment or authorized to work in that country.

Schedule: Availability to work with U.S.-based stakeholders and provide coverage until approximately 12 00 AM PHT

API Developer

Responsibilities

  • Develop and Maintain Web Applications: Design, build, and maintain efficient, reusable, and reliable Java code using Spring Framework and Spring Boot.
  • API Development: Design and implement RESTful APIs, ensuring security, scalability, and performance.
  • Database Management: Write and optimize complex SQL queries, manage database schemas, and ensure data integrity and performance.
  • Integration: Integrate third-party services and APIs, working closely with front-end developers to align application functionality.
  • Code Reviews: Participate in code reviews to maintain code quality and share knowledge with team members.
  • Troubleshooting and Debugging: Identify and resolve performance bottlenecks, bugs, and other issues in the applications.
  • Performance Optimization: Optimize the application for maximum speed and scalability.
  • Collaborate with Cross-functional Teams: Work with Product Managers, QA Engineers, and other stakeholders to deliver high-quality software solutions.
  • Documentation: Write clear and concise documentation for code, APIs, and workflows.
  • Stay Updated with Industry Trends: Keep up with the latest trends and advancements in Java development and software engineering best practices.

Qualifications

  • Proficiency in Java 11+: Solid understanding of Java fundamentals and hands-on experience with Java 11 or higher.
  • Experience in Spring Framework/Spring Boot: Strong background in building web applications using Spring Framework and Spring Boot.
  • Strong SQL Skills: Expertise in writing and optimizing SQL queries; familiarity with database management systems like MySQL, PostgreSQL, or Oracle.
  • Experience with REST APIs: Deep understanding of building and securing RESTful APIs using OAuth2, Spring Security, and JWT tokens.
  • Web Security Concepts: Knowledge of best practices for securing web applications, including CORS, CSRF, XSS, and SQL injection prevention.
  • Unit Testing: Experience with testing frameworks such as JUnit and Mockito; commitment to writing automated tests to ensure software quality.
  • CI/CD Tools: Familiarity with CI/CD pipelines and tools such as Jenkins, GitLab CI, or CircleCI.
  • Experience with Docker: Understanding of containerization and experience working with Docker (preferred but not mandatory).
  • Public Cloud Experience: Experience with cloud services, with bonus points for AWS (EC2, S3, RDS, Lambda, etc.).
  • Knowledge of Microservices Architecture: Understanding of microservices design patterns, including service discovery, circuit breakers, and API gateways.
  • Proficiency in Version Control Systems: Experience with Git and Git workflows (branching, merging, pull requests).
  • Analytical and Problem-solving Skills: Ability to diagnose and troubleshoot complex issues effectively.
  • Excellent Communication Skills: Ability to articulate ideas clearly and work well within a team environment.
  • Bachelor's degree in computer science or Related Field: Preferred but not mandatory if balanced by substantial experience and expertise.
