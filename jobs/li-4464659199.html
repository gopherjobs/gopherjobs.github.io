🚀 Senior Data Engineer (Python/DataIngestion/Cybersecurity) · Remote · LATAM

At Darwoft , we’re looking for a Senior Data Engineer to join an international project in the Cybersecurity / Identity Security space.

You’ll work on a next-generation security platform that processes large volumes of identity activity, security events, logs, network telemetry, and cloud data .

This is not a traditional Data Engineering role . We’re looking for an experienced engineer who combines Python development, data ingestion, enterprise integrations, cloud, and cybersecurity knowledge .

What You’ll Be Working On

  • Design and build production-grade data ingestion pipelines, collectors, and connectors
  • Integrate enterprise security platforms including IAM, SIEM, SASE, EDR, IdPs, and cloud security tools
  • Develop backend and integration services primarily using Python
  • Build and consume complex REST APIs
  • Process and normalize security events, logs, alerts, identity activity, and network telemetry
  • Work with SQL and NoSQL databases
  • Build and operate containerized services using Docker and Kubernetes
  • Integrate solutions across AWS, Azure, and GCP
  • Troubleshoot complex issues across APIs, networking, infrastructure, applications, and data pipelines
  • Work with engineering and customer-facing teams to turn enterprise requirements into scalable integrations

What We’re Looking For

  • 10+ years of professional experience in Data Engineering, Software Engineering, Platform Engineering, or similar roles
  • Strong hands-on experience with Python
  • Proven experience building data ingestion pipelines, connectors, integration frameworks, or distributed services
  • Strong experience designing and consuming REST APIs
  • Solid knowledge of SQL and NoSQL
  • Production experience with AWS, Azure, or GCP
  • Experience with Docker, Kubernetes, Git, and CI/CD
  • Strong debugging and troubleshooting skills in distributed environments
  • Experience integrating complex third-party or enterprise platforms
  • Ability to work autonomously and solve ambiguous technical problems
  • Strong communication skills and experience working with technical stakeholders
  • English B2 / C1

Cybersecurity Background — Highly Relevant

We’re especially interested in engineers with real experience integrating enterprise security technologies such as:

  • IAM / Identity Providers: Okta, Microsoft Entra ID / Active Directory, Duo
  • SIEM: Splunk, Microsoft Sentinel, QRadar, or similar platforms
  • SASE / Zero Trust: Zscaler, Palo Alto, or similar
  • Endpoint Security / EDR: CrowdStrike, Microsoft Defender, or similar
  • Cloud Security: AWS, Azure, GCP
  • Security telemetry: logs, events, alerts, authentication activity, and network data

You don’t need experience with every platform listed. What matters is having a strong understanding of enterprise cybersecurity environments and experience transforming heterogeneous security data sources into reliable, scalable integrations .

Nice to Have

  • Go
  • Streaming or large-scale event processing
  • Connector SDKs or integration frameworks
  • Identity Security / Identity Observability
  • Authentication, authorization, service accounts, or non-human identities
  • Solution Architecture or Forward Deployed Engineering experience
  • Experience in cybersecurity SaaS companies
  • Exposure to AI/ML, LLMs, or AI-powered security products
