Department Overview Database Services Team

Job Description We are seeking a highly curious, detail-oriented Systems & Database Infrastructure Engineer who thrives on solving complex technical challenges. In this role, you will design, optimize, and maintain resilient backend services and database infrastructure.

We need a proactive engineer eager to build future-proof solutions, tackle deep system-level problems, and deliver production-ready software capable of powering mission-critical environments with zero downtime.

Basic Requirements

  • Programming & Software Development
  • Scripting & Automation: Strong programming proficiency in Python and Perl for system automation, tooling, and backend scripting.
  • Systems Programming: Hands-on experience developing with Java and C++ to build high-performance, resilient applications.
  • Operating Systems & Linux Mastery
  • Linux Systems Administration: Deep familiarity with Linux/Unix operating systems, system architecture, and command-line navigation.
  • System Troubleshooting: Ability to analyze processes, inspect system logs, diagnose resource bottlenecks (CPU, memory, disk I/O), and optimize performance.
  • Shell Environment: Comfort working directly in headless server environments via SSH and terminal interfaces.
  • Database Architecture & Technologies
  • Database Systems: Practical experience managing or interfacing with at least one major relational or in-memory database system, such as:
  • PostgreSQL
  • GridGain
  • Oracle TimesTen
  • (Or equivalent relational/in-memory data grid technologies)
  • Data Management: Strong foundational understanding of SQL, schema design, index optimization, and transaction mechanics.
  • Version Control & Collaboration
  • Git Repositories: Proficiency with Git workflows (branching strategies, merging, pull requests, code reviews, and resolving conflicts).

Preferred / Nice-to-Have Qualifications

  • Database High Availability: Understanding of physical or logical replication (e.g., PostgreSQL Streaming Replication, multi-site setups, or failover cluster configurations).
  • CI/CD Integration: Experience integrating automated test and deployment pipelines
