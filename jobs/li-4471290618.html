Software Engineer (Permanent) - Remote/Hybrid (UK)

No visa sponsorship available

This is a remote/hybrid role with fortnightly on-site collaboration in London or Surrey office.

Our client is a growing technology business within the maritime and engineering sectors, using artificial intelligence, advanced sensor equipment and cloud technologies to deliver innovative maritime situational awareness solutions. They are seeking a Software Engineer to join the Product team and develop applications that operate across edge, on-premise and cloud environments.

Key Responsibilities:

  • Writing clean, maintainable and well-tested software within .NET environments
  • Designing and implementing components that support wider product functionality
  • Developing front-end applications using Angular, TypeScript and JavaScript
  • Building and maintaining APIs, internal libraries and development tooling
  • Supporting existing platforms, investigating issues and providing effective resolutions
  • Creating test and integration plans and contributing to automated testing
  • Building, modifying and debugging Docker containers, with applications deployed to Kubernetes
  • Documenting technical solutions and working collaboratively within an Agile Kanban environment

Job Requirements:

  • Strong software development skills within .NET environments, including C#
  • Experience developing applications with Angular, TypeScript, Jasmine and JavaScript
  • Knowledge of Python and experience developing APIs
  • Understanding of SQL and Influx databases
  • Experience with event-sourced architectures and cloud technologies, particularly Microsoft Azure
  • Ability to work with Docker containers and deploy applications to Kubernetes
  • Proficiency with testing frameworks such as xUnit or Behave
  • Experience creating build and test pipelines using GitHub, Jenkins or Azure DevOps
  • Strong attention to detail, effective prioritisation skills and the ability to work independently
  • Clear written and verbal communication skills, with experience contributing effectively within a software engineering team
  • Eligibility to obtain Security Clearance following appointment

Desirable Experience:

  • A bachelor's degree in computer science or an equivalent qualification
  • Experience with TileDB or TileAH
  • Experience developing mobile applications

Benefits:

  • Bonus scheme
  • Private healthcare and healthcare cash plan
  • Life assurance and death-in-service benefit
  • Company share options
  • Opportunity to work on innovative maritime surveillance and engineering technology
  • Supportive, collaborative and technically focused working environment

If you are a Software Engineer with experience in C#, Angular, TypeScript, cloud technologies and modern software development practices, our client would be pleased to hear from you. Apply now to contribute to innovative solutions within the maritime technology sector.
