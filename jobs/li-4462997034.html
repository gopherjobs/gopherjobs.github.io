Tus funciones:

  • Desarrollo y configuración de API proxies en Apigee Edge o Apigee X.
  • Configuración y uso de policies, shared flows, flow hooks, environments, environment groups y target servers.
  • Diseño e implementación de seguridad API mediante OAuth 2.0, JWT, API keys, mTLS y controles de acceso.
  • Implementación de quotas, spike arrest, rate limiting y protección contra amenazas.
  • Conocimiento de REST, HTTP, JSON y conceptos fundamentales de integración.
  • Lectura, definición y validación de contratos OpenAPI.
  • Configuración de fault rules, error handling, timeouts y respuestas estandarizadas.
  • API testing, debugging, trace y troubleshooting.
  • Despliegue y promoción de proxies entre ambientes.
  • Manejo de configuración mediante Key Value Maps, properties, keystores, truststores y secretos.
  • Conocimiento de logging, analytics, monitoring y auditoría de APIs.
  • Integración de Apigee con backends privados, load balancers y servicios de GCP.
  • Uso de Git y automatización básica del ciclo de despliegue.
