Role Summary

As our Full Stack Developer, you'll take end-to-end ownership of both production applications and the AWS infrastructure that serves them. That means the React SPA and its build pipeline, the Django/Channels backend and its real-time WebSocket layer, our companion Node/Express CommonDB service, and the AWS hosting and DevOps practices tying it all together. You'll bring structure and modern engineering practice — version control, CI/CD, infrastructure as code — to a codebase that's currently run by the founder with AI-assisted tooling, and you'll have real autonomy to shape how it's built going forward.

What You'll Work On

  • Frontend: Maintain and evolve the React (CRA) single-page app, including its code-split bundle structure, geospatial mapping (OpenLayers), and CAD/BIM viewing integrations (Sketchfab, Autodesk APS/Forge for Revit, Navisworks, and Inventor files).
  • Backend & real-time: Develop and extend the Django backend, including the Django Channels/ASGI real-time layer that powers live WebSocket features, served through Daphne and Nginx.
  • Async processing: Own the Celery, Celery Beat, and Flower job pipeline for background and scheduled work.
  • Integrations: Maintain the Node/Express CommonDB service and external integrations including Autodesk APS/Forge, Stripe, and Google Maps.
  • Cloud & DevOps: Manage and evolve our AWS footprint in ap-southeast-1 — EC2, ALB, CloudFront/OAC, S3, ACM, Route 53 — including migrating manual deployment processes into automated, reproducible pipelines.
  • Take ownership of the source code itself: import the React and Django repositories into Git and establish a proper branching and versioning workflow.

Tech Stack You'll Work With

Frontend: React (Create React App) with code-split bundles, OpenLayers, Sketchfab viewer, Autodesk Platform Services (APS/Forge), Chart.js, Bootstrap 4, Font Awesome, animate.css, toastr, jQuery, Stripe.js, Google Maps, Google Analytics, and custom i18n (English, Malay, Indonesian, German, Portuguese, Spanish, French)

Backend & real-time: Django, Django Channels (ASGI), Daphne, Nginx reverse proxy, Django REST Framework token auth, Django admin

Async / jobs: Celery, Celery Beat, Flower, Redis/ElastiCache broker

Other services: CommonDB (Node.js/Express API on EC2), Autodesk APS/Forge OAuth integration

AWS / hosting: EC2, EBS (GP2→GP3), VPC/subnets/security groups, Application Load Balancer, ACM, CloudFront (OAC, CloudFront Functions), S3, Route 53

DevOps & tooling: Git, AWS CloudShell, AWS Budgets & Cost Anomaly Detection, S3 Intelligent-Tiering (current state); GitHub Actions/OIDC, Terraform/CloudFormation (target state)

Must-Have Skills

  • Strong React experience, including Create React App projects: code-splitting, hashed asset builds, and client-side SPA routing.
  • Solid Python/Django experience; familiarity with Django Channels, ASGI, and WebSockets is a strong plus.
  • Working knowledge of core AWS services: EC2, S3, CloudFront, ALB, ACM, IAM, VPC, and Route 53.
  • Proficiency with Git and standard branching/versioning workflows.
  • A security-minded approach to frontend builds — comfortable identifying and removing browser-exposed secrets, fixing mixed-content issues, and excluding source maps from production.

Nice-to-Have / Bonus

  • Experience with Autodesk Platform Services / Forge, or CAD/BIM file formats (Revit, Navisworks, Inventor).
  • 3D/WebGL experience, particularly three.js.
  • Celery, Celery Beat, and Flower for async job orchestration.
  • Infrastructure as Code with Terraform or CloudFormation.
  • CI/CD pipeline design, especially GitHub Actions with OIDC.
  • Payment integration experience (Stripe).
  • Geospatial mapping (OpenLayers) and multi-language i18n at scale.
  • Node.js/Express experience.
  • Containerization (Docker).
  • AWS Cognito, or AWS cost-optimization practices (Budgets, Cost Anomaly Detection, S3 Intelligent-Tiering).

Who You Are

  • You take genuine ownership — you don't wait to be told what to fix next.
  • You're security-minded by default, not just when prompted.
  • You're pragmatic: comfortable balancing shipping speed against technical debt in an early-stage environment.
  • You communicate clearly and directly with a non-DevOps founder, translating technical tradeoffs into plain language.
  • You're comfortable working alongside AI-assisted development and DevOps workflows.

Why Join Us

This is a rare opportunity to take a live, revenue-generating SaaS product and architect its engineering foundations from the ground up — building the CI/CD pipeline, introducing Infrastructure as Code, and hardening production security — with full visibility into your impact and high autonomy over how the work gets done. You won't be one of many engineers maintaining someone else's system; you'll be the engineer who defines how this system is built and run going forward.
