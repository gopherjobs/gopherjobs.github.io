Description

MODALITY - EMPLOYEE- CLT

Key Responsibilities

  • Design, develop, and optimize backend services using Java and Node.js. Implement RESTful APIs and micro‑service architectures with Spring Boot.
  • Manage data storage, retrieval, and indexing in MongoDB. Deploy, monitor, and troubleshoot applications on AWS cloud infrastructure. Participate in Agile ceremonies (sprint planning, daily stand‑ups, retrospectives).

  • Solid experience working with NoSQL databases, specifically MongoDB. Proven track record of delivering projects using Agile methodologies.
  • Upper‑Intermediate English (B2) to communicate effectively with distributed teams and stakeholders.
  • Bachelor’s degree in Computer Science, Engineering, or a related field (or equivalent practical experience).

💡 Preferred Skills

  • Containerization and orchestration tools such as Docker and Kubernetes. CI/CD pipelines using Jenkins, GitLab CI, or GitHub Actions.
  • Experience with message brokers (Kafka, RabbitMQ). Knowledge of testing frameworks (JUnit, Mocha, Jest) and test‑driven development.
  • Familiarity with infrastructure‑as‑code tools like Terraform or CloudFormation. Understanding of security best practices (OAuth, JWT, OWASP)
