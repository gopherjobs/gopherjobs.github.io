About the Program

At Nexal IIT, we're doing things differently. This isn't a traditional job or a standard internship—it’s an open collaboration program designed for aspiring Application Developers to gain hands-on, real-world experience. If you are self-taught, a boot-camp graduate, a student, or transitioning careers, this is a space for you to build functional applications, solve real-world problems, develop practical projects, and learn by doing alongside our team.

What You’ll Do

  • Develop Applications: Design and develop functional, user-friendly, and scalable applications based on project requirements.
  • Build User Interfaces: Create intuitive and responsive application interfaces that provide a smooth user experience.
  • Work with Application Logic: Develop and implement application features, functionality, and business logic.
  • Integrate APIs & Services: Connect applications with APIs, databases, and third-party services to create dynamic and functional solutions.
  • Debug & Test Applications: Identify bugs, troubleshoot technical issues, test application features, and improve overall performance.
  • Manage Data: Work with databases and data storage solutions to manage application information efficiently and securely.
  • Collaborate on Code: Use Git and GitHub for version control, manage code updates, and collaborate with team members on application development projects.

Who You Are

  • Passionate about Application Development and eager to learn (no specific technical or computer science degree required).
  • Basic understanding of programming concepts and problem-solving.
  • Familiar with at least one programming language such as Java, Python, JavaScript, Kotlin, or C#.
  • Basic understanding of application development concepts, APIs, and databases is an advantage.
  • Bonus Points: If you have hands-on experience with Android Studio, Flutter, React Native, Java, Kotlin, Python, Firebase, REST APIs, Git, or GitHub.
  • Curious, creative, driven, and comfortable asking questions.

What You Get

  • Remote & Flexible: Contribute from anywhere, on a schedule that works for you.
  • Real Portfolio Projects: Build functional applications, integrate APIs and databases, and create practical projects that can strengthen your portfolio.
  • Direct Mentorship: Get valuable feedback, technical guidance, and support from our mentors and development team.
  • Hands-On Experience: Gain practical exposure to application development tools, frameworks, APIs, databases, and real-world development workflows.
  • Proof of Impact: A certificate of completion and a strong letter of recommendation for active contributors.
