Your Mission We are hiring a Fullstack Developer who knows the Gemini platform from the inside how Gemini Enterprise is administered, how agents, data connectors, extensions and Gems are built, registered, scoped and distributed, and how access and permissions actually flow through them.

You will be embedded with a large enterprise client as part of a small engineering pod, alongside engineers who own other enterprise AI platforms. You will own the path by which new data connectors, agents and skills reach users: from intake through access group creation, identity provider synchronisation, connector registration, per-tool permission scoping, testing, documentation and closure with the requester. You will review third-party components for security and quality before release, and replace manual console work with automated, repeatable pipelines.

This is not an administration role. Most of your time goes into building: the backend services, data mappings and integrations that wire the platform into the client's systems, and the internal tooling that gives platform owners visibility and control over how AI capabilities are being used. You should be as strong in the backend APIs, identity, data, infrastructure as code as you are in the UI.

You won't wait for a refined backlog or a separate platform team. You will take a vague request, work out what is actually needed, build it, and stand it up in production yourself. This is a builder role for engineers who combine solid fullstack fundamentals with a deep, practical understanding of the Gemini platform and its extension model.

What You'll Do Build & Integrate

  • Design and build the backend services, APIs and data mappings that connect Gemini to enterprise systems identity, data sources, ticketing and the connectors in between.
  • Build internal tooling and admin interfaces (React / Next.js over Python or TypeScript backends) that give platform owners visibility into usage and control over which capabilities are available to whom.
  • Build or integrate agents and extensions for the client's own use cases Agent Designer, ADK, Gemini CLI extensions, or LLM-powered services and agents on whichever orchestration framework fits (LangGraph, Google ADK, AutoGen, Semantic Kernel, OpenAI Agents SDK or similar), integrating models through APIs, tool calling / MCP and structured outputs and register them in Gemini Enterprise so the right people can use them.
  • Take a vague request from a business or platform owner, work out what is actually needed, ship a working version quickly, and harden what survives contact with real users.

Own Connector & Agent Requests End to End

  • Own data connector, agent and skill requests for the enterprise Gemini platform from intake through to closure with the requester.
  • Create access groups and manage identity provider synchronisation (SSO / SCIM with Okta, Entra ID or Google Cloud Identity) so access follows existing team and group structures.
  • Register connectors and data stores and apply per-tool permission scoping, granting only the access each capability needs.
  • Test each connector and agent before release, document what it does and how to use it, and close the loop with the requester.

Configure, Distribute & Review Platform Capabilities

  • Configure and distribute agents, skills, extensions and Gems to the right audience enterprise-wide, group-scoped or on request with a clear understanding of the scoping controls and what each one actually gates.
  • Conduct security and quality reviews of third-party and externally authored agents, extensions and connectors before release: dependencies, bundled scripts, and exposure to prompt injection or data exfiltration.
  • Define remediation or approval decisions and document them so the standard is repeatable.

Automate Provisioning

  • Automate setup, registration and provisioning through CI/CD pipelines and infrastructure as code (Terraform) in place of manual console configuration.
  • Build parameterised deployments across development, staging and production environments.
  • Turn recurring manual requests into reusable, version-controlled automation.

What You Bring

  • 5+ years building production fullstack applications in Python and TypeScript APIs, integrations and modern web frameworks (FastAPI, Node / Fastify, React / Next.js). You are backend-strong: data mappings, integration plumbing and wiring systems together is where you spend most of your time, not just the UI.
  • Deep, hands-on knowledge of the Gemini platform: Gemini Enterprise administration (data connectors and data stores, agent registration, end-user feature controls, IdP-synced groups and access) and the Gemini API, plus Gemini for Google Workspace (Gems and admin controls) where it is in use. You know how capabilities are packaged, scoped and distributed and where the sharp edges are. Familiarity with Vertex AI and the agent stack (ADK, Agent Runtime, Agent Registry, A2A) is useful rather than essential.
  • Hands-on experience with Gemini function calling / tool use and MCP servers, including tool permissions and capability scoping.
  • Hands-on experience building agents or LLM integrations with at least one orchestration framework (LangGraph, Google ADK, AutoGen, Semantic Kernel, OpenAI Agents SDK or similar), and comfortable switching the team's framework is not fixed.
  • Security-minded reviewing of code and AI components: dependency analysis, script review, and a practical understanding of prompt injection and data exfiltration risks.
  • CI/CD pipelines (GitHub Actions, Azure DevOps, Cloud Build or similar) and infrastructure as code with Terraform across AWS, Google Cloud or Azure, including parameterised multi-environment deployments.
  • Structured, disciplined use of AI-assisted development (Gemini CLI, Claude Code or similar) with review, not on autopilot.
