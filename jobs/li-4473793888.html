Role Overview:

We are looking for a Data Engineer – GCP to integrate our teams, contributing to the design, development, and evolution of modern data platforms. In this role, you will help build scalable and high-performance data solutions, enabling efficient data storage, processing, orchestration, and analytics across complex and distributed environments.

What you will do:

  • Design, build, and maintain scalable and reliable data platforms in cloud environments;
  • Develop robust data pipelines and workflows using technologies such as Spark and Apache Beam;
  • Collect, process, and analyse large and complex datasets from multiple sources (databases, APIs, file systems);
  • Implement data integration solutions ensuring high data quality and efficient data flow;
  • Collaborate with cross-functional teams to ensure data accuracy, consistency, and availability;
  • Ensure data security and privacy through proper access controls and encryption mechanisms;
  • Monitor system performance and optimise solutions for scalability, reliability, and high availability;
  • Contribute to the evolution of data architectures and best practices across the data ecosystem.

What you are like:

  • Proficient in cloud platforms for data engineering, particularly GCP, with familiarity in AWS or Azure services;
  • Experienced in programming languages such as Python, Java, or Scala;
  • Strong hands-on knowledge of big data and streaming technologies (e.g., Spark, Flink, Kafka, Hadoop ecosystem tools);
  • Solid understanding of data modelling, database design, and both relational and NoSQL databases;
  • Skilled in SQL and experienced in building and optimising queries for large-scale data processing;
  • Familiar with data integration and ETL tools and frameworks (e.g., Kafka, Talend);
  • Knowledgeable in distributed systems and modern data processing architectures;
  • Comfortable using version control systems such as Git;
  • Analytical, detail-oriented, and collaborative, with a proactive mindset and strong problem-solving skills.Fluent in English, with strong professional communication skills;Fluent in English (written and spoken).
