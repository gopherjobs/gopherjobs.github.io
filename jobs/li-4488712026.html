Job Title Backend AI Developer (Smart Home & Agentic Systems) About The Client Our client is a Dubai-based real estate developer building technology-led, future-ready living environments. They combine design, advanced engineering and intelligent systems to create smarter homes and communities. Innovation, local-first AI and data-driven living sit at the core of how they build. They are now establishing a specialist engineering team to bring agentic intelligence into the physical home.

Role Overview We are seeking a highly skilled and innovative Backend AI Developer to lead the design, development and orchestration of our next-generation agentic smart home platform. In this role, you will bridge the gap between physical smart home hardware, modern local data lakes, and cutting-edge local and cloud AI models. You will be responsible for creating autonomous, context-aware digital twins and agentic assistants that make spaces truly intelligent.

If you are passionate about local-first AI, edge computing, smart home automation, and rapid prototyping workflows using modern AI-augmented coding tools, this role is designed for you.

Technical Stack & Ecosystem

  • AI & Agents: OpenClaw, Nous Hermes (LLMs), ElevenLabs (voice synthesis), vision frameworks (OpenCV, Vision LLMs), Claude, Cursor, Ollama, LMStudio, OpenCode
  • Smart Home: Home Assistant (custom integrations, Assist pipeline, WebSocket APIs, AppDaemon)
  • Languages: Python (core backend), React JS (dashboard and control interfaces), TypeScript
  • Data Engineering: DuckDB, Apache Parquet (local analytical data lakes)
  • Infrastructure: Docker, Proxmox VE (LXC, VM provisioning, GPU passthrough), Linux systems

Key Responsibilities

  • AI & Agentic Orchestration
  • Design, deploy and refine multi-agent systems using frameworks like OpenClaw and open-source models like Hermes, running locally via Ollama or LMStudio
  • Integrate multi-modal vision frameworks (e.g., OpenCV, vision-capable LLMs) to process security cameras, identify contextual events and generate real-time situational awareness
  • Implement lifelike, low-latency conversational voice interfaces using ElevenLabs APIs and streaming audio pipelines
  • Leverage AI-assisted coding tools like Cursor and Claude to accelerate engineering velocity and maintain high-quality code
  • Smart Home Automation & Integration
  • Build deep integrations and custom components for Home Assistant to orchestrate sensors, switches, climate control and media devices
  • Extend Home Assistant's native Assist pipeline, or develop standalone custom agents that interact natively with the home's state
  • Work with real-time communication protocols, including MQTT, WebSockets and HTTP REST APIs
  • Local Data Lake & Engineering
  • Architect a local, high-performance data lake using DuckDB and Parquet to ingest, store and analyze thousands of sensor data points and telemetry events
  • Implement analysis pipelines to detect anomalies, optimize energy usage and predict environmental and behavioral trends
  • Create vector databases and retrieval-augmented generation (RAG) indices to feed local, home-specific context directly into agent memory
  • Infrastructure & DevOps
  • Manage a self-hosted server environment virtualized under Proxmox VE, utilizing LXC containers and VMs
  • Containerize applications using Docker and manage multi-container orchestration
  • Configure hardware passthrough (e.g., GPU passthrough for local LLM inference, Coral USB TPU for vision processing)
  • Frontend & UI Support
  • Develop clean, high-performance, responsive custom dashboards and configuration portals in React JS to visualize agent states, telemetry and system controls

  • Core Languages: Deep expertise in Python (asyncio, FastAPI, Pydantic) and comfort with React JS for building functional user interfaces
